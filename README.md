| 方法 | 手順 |

## 無料サーバーで公開する（Cloudflare）

ゲーム画面・API・データベースがすべて Cloudflare の無料プランに収まります。
必要なのは Cloudflare の無料アカウントと、この GitHub リポジトリだけです。

1. [Cloudflare に無料登録](https://dash.cloudflare.com/sign-up) してログイン
2. 左のメニュー **Workers & Pages** →「**作成（Create）**」→「**リポジトリをインポート（Import a repository）**」
3. GitHub と連携して `Special-Casino-2026` を選ぶ
4. 設定画面ではプロジェクト名を **`blockbuster-reels`** のままにし、ビルドコマンドは空欄、デプロイコマンドは `npx wrangler deploy`（初期値）のまま
   - 公開に使うブランチ（本番ブランチ）は、この作業をした `claude/epic-gates-fmo9j7` を選ぶか、先に GitHub で main に取り込んで（マージして）ください
5. 「**デプロイ**」を押す → 1〜2 分で `https://blockbuster-reels.<あなたのアカウント名>.workers.dev` が公開 URL になります

これで完成です。以後は GitHub のブランチを更新するたびに自動で再デプロイされ、**プレイヤーのデータはそのまま残ります**。

> 絶対に変えないでください: `wrangler.jsonc` の `"name"`（`blockbuster-reels`）と `"migrations"` の行。
> 全プレイヤーのアカウントとお金はこの名前に結び付いたデータベース（Durable Object）に保存されています。

- パソコンからコマンドで公開する場合: Node.js を入れて `npm install` → `npx wrangler login` → `npm run deploy`
- 自分のパソコンで試す場合: `npm install` → `npm run dev` → http://localhost:8787
- 独自ドメインを使う場合: Cloudflare の Worker の「設定 → ドメインとルート」から追加できます

### 保管庫を R2 につなぐ（50GB）

開発者専用保管庫のファイルは、つなぐ前はゲームのデータベースに入ります（Workers Paid で全体 3GB まで。データベースはプレイヤーのデータと共用のため）。
Cloudflare の **R2**（ファイル置き場）につなぐと **全体 50GB・1 ファイル 2000MB** まで入り、データベースは軽いままです（8MB ずつ送るので速くなります）。

| 料金（月） | 内容 |
| --- | --- |
| R2 | 10GB まで無料、それ以上は 1GB あたり 0.015 ドル（50GB 使い切りで約 0.6 ドル、80GB で約 1.05 ドル）。取り出しの通信料は無料 |

1. Cloudflare の **Workers & Pages → プラン** で **Workers Paid**（済み）
2. **R2** を有効にして、**バケットを作成**（名前は `blockbuster-reels-vault`、ほかは初期値）
3. `wrangler.jsonc` に `"r2_buckets": [{ "binding": "VAULT", "bucket_name": "blockbuster-reels-vault" }]` を追加して main に反映
   - バケットを作る前に追加すると、デプロイが失敗します（ゲームは前の版のまま動き続けます）
4. 運営サイトで保管庫を開くと、データベースにあったファイルが自動で R2 に移ります（「R2 へ移動」の表示が出ます）

保管庫のファイルが自動で消えることはありません（消せるのは開発者の「削除」だけ）。

### 開発者支援（課金）を始める

決済は **Stripe**（PayPay・コンビニ決済に対応した決済代行会社）を使います。設定するまでは購入画面に「準備中」と出て、購入はできません。

1. [Stripe](https://stripe.com/jp) でアカウントを作り、本人確認と **売上の振込先（開発者の銀行口座）** を登録
2. ダッシュボードの「設定 → 決済手段」で **PayPay** と **コンビニ決済** を申請して有効にする（どちらも審査があります。下の注意）
3. 「開発者 → API キー」で **制限付きキー** を作る。権限は **Checkout Sessions：書き込み** と **PaymentIntents：読み取り** だけ（万一漏れても被害が小さくなります）
4. 「開発者 → Webhook」でエンドポイントを追加：URL は `https://（公開URL）/api/pay/webhook`、イベントは
   `checkout.session.completed`・`checkout.session.async_payment_succeeded`・`checkout.session.async_payment_failed`・`checkout.session.expired`・`charge.refunded`。
   表示される **署名シークレット**（`whsec_…`）を控える
5. Cloudflare の Worker の「設定 → 変数とシークレット」に、シークレットとして `STRIPE_SECRET_KEY`・`STRIPE_WEBHOOK_SECRET`、
   変数として `PUBLIC_URL` と `SELLER_NAME`・`SELLER_ADDRESS`・`SELLER_PHONE`・`SELLER_EMAIL`（必要なら `SELLER_HEAD`・`SELLER_HOURS`）を入れて再デプロイ
6. 最初は **テスト用のキー**（`rk_test_…` とテスト用の `whsec_…`）で試すと、本物のお金を動かさずに最後まで確かめられます（購入画面と運営サイトに「テストモード」と出ます）
7. 運営サイトの **「課金」タブ**（開発者だけに表示）のいちばん上で、設定が正しいか・Webhook の送信先を確認できます

安全のための仕組み:

- 支払いは Stripe のお支払いページで行うので、PayPay のログイン情報などはこのサーバーに届きません。金額はサーバーだけが決めます（ブラウザから送られた金額は使いません）
- ロイヤルコインは **Stripe に問い合わせて確認できた支払いにだけ**、**1 回だけ** 付与します。Webhook は署名（HMAC-SHA256・受け取ったままのデータで照合・5 分以内）を確かめ、そのうえでサーバーが Stripe に注文の中身（注文番号・金額・円・本番 / テスト）を問い合わせて一致したときだけ付与。一致しない注文は付与せず「確認中」にして運営ログに残します。Webhook が届かなかった場合も、プレイヤーが画面を開いたときや定期処理で Stripe に確認します
- 注文番号はランダムな 128 ビット、ほかの人の注文は見られません。返金されるとその分のロイヤルコインを回収します
- 18 歳以上のみ・1 人 24 時間で 10,000 円まで・支払い待ちの注文の数の上限・回数の制限。BAN 中は購入できません
- 注文・入金・コンビニの支払い番号・返金・不一致・不正な通知・開発者の返信は、すべて運営ログ（改ざん検知つき）に記録されます。注文はバックアップにも含まれます
- 秘密の鍵は Cloudflare のシークレットにだけ置き、リポジトリには書きません

注意:

- **最低金額**：PayPay は合計 50 円から、コンビニ決済は合計 120 円から（Stripe の決まり）。開発者支援I だけなら PayPay は 5 口・コンビニは 12 口から買えます（画面で案内します）
- **コンビニ決済の手数料** は 1 件あたり 3.6%・最低 120 円なので、少額の購入では手数料で売上がほとんど残りません。PayPay だけにするなら `PAY_METHODS=paypay`
- **コンビニ決済の返金** は 1 件 275 円の手数料がかかります（返金は Stripe のダッシュボードから。返金されるとロイヤルコインは自動で回収されます）
- **審査**：PayPay とコンビニ決済には Stripe と提携先の審査があります。どちらも商品・画像・価格が日本語でサイトに載っていて、トップページから特定商取引法に基づく表記へのリンクがあることが条件です。
  PayPay は事業者名・住所・法人番号が国税庁の法人番号公表サイトと一致している必要があります（主に法人向け）。
  コンビニ決済は審査に約 30 日かかり、「開業から 3 年未満の個人事業主」「ギャンブル」などは対象外と明記されているため、カジノを題材にしたゲームは審査に通らない可能性があります
- 特定商取引法に基づく表記はログインなしで `https://（公開URL）/law` から見られ、タイトル画面の左下からもリンクしています（審査の申請にも使えます）。`SELLER_*` を設定してください

### サーバー運営サイト

`https://（公開URL）/ops/` を開き、運営者のアカウント（既定は **TAKU**、`OPERATORS` で変更）の名前とパスワードで
ログインします（入力は最初の 1 回だけ。そのブラウザに記憶されます。それ以外のアカウントはログインできません）。
**名前かパスワードを続けて 2 回間違えると入力制限**になり、そのブラウザは 5 分間入力できません（そのあとまた 2 回間違えると 10 分、20 分、40 分…と倍になり、ログインできるか、間違いのないまま 1 日たつと元に戻ります。ブラウザを変えて回避されないよう、同じ回線〔IP アドレス〕から合わせて 10 回間違えると回線ごと同じように待ちになります。この制限はログに残しません）。白を基調にした画面で、

- **プレイヤー**: プレイヤー名・オンライン状況・資産（トークン・$・コインと $ 換算の合計）・18歳以上（はい / いいえ / 未回答）・引き継ぎコード・パスワード・処分。名前で検索、オンライン / 返信待ち / 検知あり / 処分中で絞り込み、並べ替え（15 秒ごとに更新、返信待ちの人が先頭）。アイコンに **「返信待ち」**（公式へのメッセージに未返信）と **「検知」**（チャットの不適切な言葉）の印
- **アイコンをタップ**: そのプレイヤーと **Ice Smoker公式の本物のチャット画面**（開くとプレイヤーのメッセージに既読がつきます）。送るメッセージは「【件名】／〇〇様／要件（文字数無制限）／Ice Smoker公式より」の形（送られる文面を確認してから送信）。「送金」で公式から **$0〜$10,000,000**（1 万〜1,000 万のボタンと金額入力、ひとこと付き）。2 日以上返信がないと、そのメッセージに既読をつけて公式が自動で返信します
- **行をタップ（詳細）**: 登録日・18歳以上の答えと日時・遊んでいる累計時間・最長連続オンライン日（日本時間 6:00 区切りで続けてログインした日数の最長）・今の連続日数・ログイン日数・レベル・通報の件数・検知・記録・使った端末と同じ端末のほかのアカウント
- 詳細には **ゲームのバージョン**（最新なら「最新」、古いなら「DEV7（最新は DEV8）」のように、ビルド・端末〔Android・iPhone・Windows など〕・確認した日時つき）
- 操作: アクセス禁止（1 週間）・BAN（30 日）・永久BAN・処分の解除・端末の BAN から外す・引き継ぎコードの再発行・パスワードの再設定。
  処分するとそのプレイヤーのゲームは **すぐにタイトル画面に戻り、解除されるまでそこから先へ進めません**（「Ice Smoker公式より／あなたは〇〇（日時）に公式よりアクセス禁止されました／期間」を表示。読み込み直しても同じ。ログインは保ったままなので、解除されるか期間が終わると 20 秒ほどで「解除されました」→「ゲームに戻る」）。
  公式から **「【アクセス禁止のお知らせ】…あなたは〇〇に公式よりアクセス禁止されました。期間：…」** が届き、解除したとき・期間が終わったときも **「【…解除のお知らせ】」** が届きます。処分中は、同じ端末で新しいアカウントも作れません（アクセス禁止も含む）
- **通報**: 日時・通報した人・対象・種類・内容と、対象の情報（レベル・所持金・登録日・オンライン・18歳以上・処分）・ふたりの関係・最近のメッセージ・検知。**受理**（公式から通報者へ $60万 / $120万 / $240万 と「ありがとうございます！…受理されました！運営一同心から協力に感謝いたします！」）か **受理しない**
- **検知**: 送った人・相手（グループ・ホーム・ハブ）・日時と、**原文（検知した言葉を赤で表示）**。確認済みにすると印が消えます
- **報告・意見案**: 公式に届いた報告・意見案と、星のフィードバック。チャットで返信・対応済み。意見案は **「採用する」** で、公式からその人へ **50,000 スピントークン** と感謝のメッセージ（1 つの意見案につき 1 回、対応済みにもなります）
- **アーカイブ**（プレイヤーアーカイブ）: **永久BAN** と **アカウント削除** をしたプレイヤーは一覧からここに移り、**入った瞬間から 90 日後にその人のデータがすべて自動で完全削除** されます（アカウント・ログイン・端末・送金や車の記録・チャット〔その人が送ったものと 1 対 1 の会話〕・フレンド・アイテム・通報など。法律で 7 年残す決まりがある開発者支援の支払い記録と、書き換えられない運営ログだけは残ります）。永久BAN は運営が解除でき、解除すると一覧に戻ってタイマーも消えます。長くオフラインなだけのプレイヤーは消えません
- **アカウント削除**（プレイヤーの詳細の一番下。**開発者のアカウントにだけ表示**）: 開発者コードを入れると、そのプレイヤーと **同じ端末（端末 ID）のサブ垢** がすぐにすべての端末でログアウトされ、アーカイブへ移ります。**削除は開発者でも取り消せません**（ログインもできなくなります）。運営者のアカウントは削除できません。削除は運営ログ（セキュリティ）に残ります
- **運営チャット**: 運営者だけの連絡用。運営者の一覧（**緑＝運営サイトにいる・青＝ゲーム中**、ほかは **最終オンラインの日時**）、いま何人オンラインか、**全体チャット**（運営者全員）と **個人チャット**（1 対 1、既読つき）。未読はタブの数字。送ったメッセージは取り消せません。**開発者はほかの運営者どうしの個人チャットも閲覧できます**（ページにもそう表示）
- **サーバー**（運営者全員）: サーバーの今をリアルタイムで。プレイヤーの接続数・運営者のオンライン数・1 秒あたりのリクエストと送信量（帯域）・ライブ通信・今日の合計、**直近 5 分のグラフ（1 秒ごと）**、契約中のプランの中身、**今月の料金の目安**（込みの分と使った分）、データベースの大きさと件数、保管庫、Cloudflare の集計（`CF_ACCOUNT_ID` / `CF_API_TOKEN` を入れたとき）
- **バックアップ**（サーバータブの下。**開発者のアカウントにだけ表示**）: 保管庫以外の全データ（全プレイヤー・お金・チャット・ログなど）を **5 時間ごと・12 時間ごと・1 日ごと・手動のみ** から選んで自動でバックアップ（自動のものは新しい 10 / 30 / 100 個かすべてを残す。手動のものは削除するまで残る）。**開く・設定・実行・ダウンロード・削除のすべてに開発者コードが必要**で、開発者以外には画面すら出ません。中身は開発者のブラウザで作った鍵（ECDH P-256）で暗号化され、その鍵は開発者コードでしか開けない形（PBKDF2 60 万回 + AES-GCM）でだけサーバーにあるので、**サーバーの管理者やデータベースを見た人でも中身を読めません**。ダウンロードはブラウザの中で開いて JSON ファイルとして保存（管理コマンドの `import` で復元できます）。保存先は R2（つないだとき）かデータベース。開発者コードを変えると鍵も新しいコードにかけ直します。すべて運営ログ（セキュリティ）に記録
- **緊急停止**: 保管庫を除くサーバーの使用量（リクエスト・送信量・ライブ通信・データベースの増え方。運営サイトの分は別にも）を 1 分ごとに **ふだん（直近 1 日ほどの平均）** と比べ、**10 倍以上かつ下限（リクエスト 2 万回/分・送信 500MB/分・ライブ通信 3 万件/分・データベース 30MB/分、運営サイトは 3,000 回/分・150MB/分。ふつうに人が増えたくらいでは止まらない量）以上の状態が 2 分続くと**、取得できる限りの情報（毎分の数字・ふだんの値・多かったアドレス / アカウント / API・データベース）を緊急ログに書いてから **サーバーを全停止** します（制限で弾いたアクセスは数えないので、1 か所からの連打だけでは止まりません）。停止中はプレイヤーにメンテナンス表示、運営者にも停止中の画面が出て、**開発者だけが入れて緊急ログを見て、開発者コードで解除** できます（再起動やデプロイでも停止は続きます。解除後 30 分は自動停止しません）。開発者はサーバータブから手動でも止められます
- **セキュリティ**（運営者全員）: すべての API リクエストを最初に点検する **セキュリティシールド**（`server/core/shield.js`）の状況をリアルタイムで。直近 5 分の攻撃・探索・フラッド・ログイン失敗・ブロック数、脅威レベル、脅威スコアの高いアドレス、ブロック中の一覧。シールドは、ゲームが決して送らないもの（パストラバーサル、SQL／スクリプト／テンプレートのインジェクション、スキャナー／攻撃ツール、他ソフトへの探索、人の操作ではありえない連打）を遮断し、攻撃元のアドレス・アカウント・端末を自動でブロックします（戻ってくるたび時間が倍に。ロードバランサ／プロキシ経由の実際の接続元で判断し、同じ回線の大勢のプレイヤーは巻き込みません）。**ロックダウンに至らない攻撃は、このタブから運営が手動でブロック・解除** できます（記録に残ります）。ブロックはデータベースに保存され、再起動しても忘れません
- **ロックダウン**（最終手段）: シールドが **防御の突破**（多数のアドレスからの同時攻撃や、サーバーの鍵〔管理トークン・開発者コード〕への総当たり）を検知すると、または運営が security HOME から手動で、**ロックダウン** を発動します。発動すると全員（プレイヤーは「緊急メンテナンス」・運営者・開発者も）が締め出され、サーバーは **ログ以外を停止**、**外部通信を遮断**（Stripe・Cloudflare・通知・TURN を呼ばない）、取得できる限りの攻撃情報と運営ログの整合性チェックを **緊急ログ** に記録し、鍵があれば暗号化バックアップを取って **重要な情報をできる限り守ります**。**最長 1 か月で自動解除**、運営者はいつでも手動で解除できます。既存の緊急停止・メンテナンス表示など数々の緊急システムと統合されています
- **security HOME**（`/sec/`、運営者だけ）: TWO STATE とは独立した HTML 環境の、運営の **最終安全基地**。最も厳しい CSP で、外部への読み込みはいっさいありません。サーバーとTWO STATE のセキュリティ状況をリアルタイムに表示（左）、運営サイトと同じ運営ログ（右）、運営者どうしの **暗号化された連絡チャンネル**（メッセージはサーバーに封印して保存。データベースを直接見ても読めません）を備え、**ロックダウンの発動・解除だけ** ができます（プレイヤー管理・送金・保管庫などの主要な運営操作はできません）。ロックダウン中もここだけは使えます。運営サイトからログインしたのと同じ運営者アカウントで入れます
- **更新頻度**（右上）: **極めて高い**（一覧 3 秒・サーバーとチャット 1 秒ごと）/ **高い**（5 秒・2 秒）/ **通常**（15 秒・5 秒）/ **遅い**（60 秒・15 秒）。ブラウザごとに記憶
- **運営者**: 運営者の一覧（`OPERATORS` と、運営サイトで付与・剥奪した人）。**運営権の付与（プレイヤー名を入れて「運営権を付与」）と剥奪には、開発者だけが知っている「開発者コード」が毎回必要**です。
  リポジトリは公開されているので、コードはどこにも書かれていません：**最初に一度だけ、開発者のアカウントでこのタブの「開発者コードを登録」から登録**してください（サーバーにはパスワードと同じく元に戻せない形でだけ保存。変更は今のコードが必要）。間違ったコードは 1 時間に同じ接続から 5 回・全体で 30 回までで、すべて運営ログに残ります。
  **剥奪** すると、その人は **すぐにすべての端末でログアウト** され（ゲームでは「運営権が剥奪されたため、ログアウトされました」）、**運営サイトにはログインできなくなります**（ゲームには一般のプレイヤーとしてログインできます）。開発者の運営権は剥奪できません。付与・剥奪・コードの登録と入力ミスは運営ログに記録
- **ログ**: **プレイヤー**（登録・ログイン・パスワード変更・引き継ぎコード・送金・通報・報告 / 意見案・購入）・**運営**（サイトを開いた・メッセージ・送金・処分・パスワード・引き継ぎコード・通報の処理・検知の確認・意見案の採用・自動返信と **DEV の更新**）・**セキュリティ**（開発者コード・運営権・アカウント削除・完全削除・バックアップ・不正な決済通知・管理コマンド）・**保管庫**・**緊急**（緊急停止とその解除）に分けて、新しい順に 1 行で（何をしたか一目でわかる要約。分類ごとに絞り込めます）。タップすると日時（日本時間 / UTC・ミリ秒まで）・実行した人・対象・IP アドレス・ブラウザ / 端末・アクセス元・内容のすべて・前後のハッシュを表示。**記録は消すことも書き換えることもできません**（データベースが削除・変更を拒否し、各記録が前の記録のハッシュを持つので、裏で消されたり書き換えられたりするとログの上に「改ざんチェック」の異常が出ます。最新の記録の番号とハッシュはデータベースの外〔Cloudflare のオブジェクト自身の保存領域と Workers Logs〕にも控えているので、ログを最初から作り直したり後ろを切り取ったりしても見つかります。記録は操作と同じリクエストの中ですぐに書かれ、バックアップからの復元や時点への巻き戻しでも残ります）
- **課金**（開発者のアカウントだけに表示）: 開発者支援を購入した人が **返信待ち** として並びます（買ったもの・口数・金額の合計・ロイヤルコイン・購入日時）。返信を書いて「返信して一覧から消す」（送られる文面を確認してから送信）と、Ice Smoker公式から「【開発者からのメッセージ】〇〇様 … Two state 開発者 TAKU」として届き、**その人だけが一覧から消えます**（あとでまた購入すると、もう一度載ります）。「すべての注文」で状態（支払い待ち・完了・期限切れ・返金など）と返信を確認。上には決済の設定の状態（本番 / テスト / 停止中と足りない設定）、開発費のメーター、今月と累計の売上
- **保管庫**（開発者のアカウントだけに表示）: **開発者専用保管庫**。開くたびに開発者コードが必要（30 分で自動的に閉じます）。3D モデルなどの大きなファイルを保存でき（**R2 につなぐと全体 50GB・1 ファイル 2000MB まで**。つなぐ前は全体 3GB〔無料プランは 1GB〕。上の「保管庫を R2 につなぐ」）、1MB（R2 では 8MB）ずつ送って 1 つずつ SHA-256 で確かめます。**止まったアップロードは自動で続きから**（保管庫がいっぱい → 空きができしだい、通信が切れた → 戻りしだい、保管庫が閉じた → 開きしだい。このページを開いている間。閉じたあとは同じファイルを選び直すと続きから）。一覧は **1 ページ 10 件**（すべて / 未実装 / 実装済み）、各ファイルに **送信日時・保存完了日時**。**AI 用リンク**（リンクを作るときに選ぶ）では、AI がファイルを取ると「AIが取得」、AI が作業を書くと「AIのラベル」が付き、AI が **ゲームに入れたと報告すると「実装済み」** になってリンクから外れます（素材が混ざらないように。消えずに残り、「実装済みから戻す」もできます）。**保管庫のファイルが自動で消えることはありません**。**フォルダ**を作ってまとめられます（フォルダの中にフォルダも 8 階層まで。名前の変更・移動・削除〔中身はひとつ上へ〕、ファイルはチェックして「フォルダへ移動」、開いているフォルダにアップロード）。**3D モデル**（glb・gltf・obj・fbx・stl・ply）は入れるとブラウザの中で自動的に **4 方向（前 +Z・右 +X・上 +Y・斜め）の画像**（640px・WebP）・**モデルの情報**（三角形・頂点・メッシュ・マテリアル・テクスチャ・大きさ・アニメーション）・**軽量版**（4MB を超えるモデル：6 万三角形・テクスチャ 512px の GLB）が作られ、一覧に表示されます（「3Dで見る」で軽量版を回して見られます）。ダウンロード（全部のハッシュを確かめてから保存）、**期限付きの読み取り専用リンク**（1・6・24・72 時間。ログインなしで取り出せる。いつでも停止）は **1 ファイルごと** か **保管庫全体**（一覧・画像・情報・軽量版も取り出せる）、削除。`/ops/#vault` で保管庫が直接開きます。ファイルは開いたり実行したりされず、バックアップには含まれません。保存・フォルダ・移動・リンク・取り出し・削除はすべて運営ログに記録。
  「＋ テキストを作る」で文章もアイテムとして保存でき（中身の始めが一覧に出ます）、画像は小さく表示、種類（3Dモデル・テキスト・画像・動画・音声・圧縮・その他）のタグ付き。どれも 1 件として数えます。各アイテムに **短期間メッセージ**（1・3・7・30 日か期限なし）を残せ、AI 用リンクでは期限までのメッセージを AI も読めます（期限が過ぎてもメッセージは消えずに残り、AI には見えなくなります）
- スマホでは最初のタップで **全画面・横向き** になります（Android の Chrome。ホーム画面に追加すると最初から横向き全画面）。横向きにできない端末で縦に持っているときは、サイト全体が横向きに回転して表示されます

**パスワードは表示できません。** 安全のため元に戻せない形（ハッシュ）でだけ保存しているので、運営者にもデータベースにも元のパスワードはありません。
忘れた人には新しいパスワードを設定してください。引き継ぎコードは暗号化（HMAC-SHA256 による暗号化と改ざん検知、鍵はサーバーの秘密値から作成）して保存しているので一覧で見られます。
この仕組みを入れる前に発行されたコードは「未取得（再発行で表示）」と出ます（本人が「引き継ぎコード発行」をするか、運営が再発行すると表示されます）。

### 管理コマンド

`ADMIN_TOKEN` を設定したあと、Node.js の入ったパソコンから実行します。

```sh
export ADMIN_TOKEN=設定した合言葉
URL=https://blockbuster-reels.あなたのアカウント名.workers.dev
node server/node/admin-cli.js --remote $URL stats                 # 全体の数字
node server/node/admin-cli.js --remote $URL users [検索語]        # プレイヤー一覧
node server/node/admin-cli.js --remote $URL show たけし           # 1 人の詳細
node server/node/admin-cli.js --remote $URL ban たけし            # 永久BAN（unban で解除。期限付きは運営サイトから）
node server/node/admin-cli.js --remote $URL grant たけし dollars 100000   # 残高を増減（マイナスで減らす）
node server/node/admin-cli.js --remote $URL rename たけし たけし2  # 名前の変更
node server/node/admin-cli.js --remote $URL recovery たけし       # 引き継ぎコードを再発行（本人確認のうえで）
node server/node/admin-cli.js --remote $URL password たけし 新しいパスワード  # パスワードを設定し直す（本人確認のうえで）
node server/node/admin-cli.js --remote $URL backup backup.json    # 全データをファイルに保存
node server/node/admin-cli.js --remote $URL quota                 # 今日のリクエスト数・送信量（DAILY_* を設定した場合）
```

- もしもの時の巻き戻し: Cloudflare はデータベースの過去 30 日分を保持しています。
  `node server/node/admin-cli.js --remote $URL restore-time 2026-10-17T12:00:00Z` でその時点の状態に戻せます（通常は不要です）。
  運営ログだけは巻き戻らず、そのまま残ります（コマンドが巻き戻しの前に取り出して、あとで戻します）。
- 管理コマンドで変更したこと（BAN・残高の変更・名前の変更・再発行・パスワード・ログイン解除・削除・バックアップ・復元・巻き戻し）も、運営サイトのログに残ります。

## アプリとして配布する（無料）

| 端末 | 入れ方 | 更新 |
| --- | --- | --- |
| Android | ゲームのサイトから **アプリ（APK）** をダウンロードしてインストール、または Chrome の「アプリをインストール」 | アプリの中に出る **「アップデート」** ボタン |
| iPhone / iPad | Safari の共有ボタン →「**ホーム画面に追加**」→「Web アプリとして開く」→「追加」 | 自動。開いている間に新しい版が出ると「アップデート」ボタン |

起動画面の右上の「アプリで遊ぶ」に、使っている端末に合わせた手順とダウンロードボタンが出ます（`https://公開URL/?install` を友達に送ると、その画面から開きます）。
iPhone・iPad では Android 用のアプリ（APK）は開けないため、「ホーム画面に追加」の手順だけが表示されます。
どちらもホーム画面のアイコンから全画面・横向きで起動し、マイク（ホーム通話）も使えます。アプリでも同じユーザー名とパスワードでログインすれば、同じ残高・フレンドのまま遊べます。

- iPhone 用に App Store で配るには Apple の開発者登録（年 99 ドル）が必要なため、無料で配れる形は「ホーム画面に追加」（Web アプリ）だけです。見た目と動きはアプリと同じです。
- スマホ通知: ホーム画面に追加した Web アプリ（iPhone は iOS 16.4 以降）とブラウザは、ゲームを閉じていても通知が届きます（Web Push）。Android アプリは、アプリがバックグラウンドで動いている間にアプリ自身が通知します（アプリを完全に終了しているときは届きません。届くようにするには Firebase の設定が別に必要です）。
- Android アプリは Google Play を通さない配布なので、ダウンロードやインストールのときに Android の注意が表示されます（「ダウンロード」「この提供元のアプリを許可」で進めます）。
  Google はストア外のアプリにも開発者登録を求める方針を発表しており、国ごとに順次始まります。その場合でも Chrome の「アプリをインストール」は使えます。

### Android アプリ（APK）を作る（最初に 1 回だけ）

アプリは GitHub が無料で自動作成し、ゲームのサイト（`/download/`）に置きます。

1. **署名の合言葉を登録する**: GitHub のこのリポジトリ → Settings → Secrets and variables → Actions →
   New repository secret → Name に `APP_SIGNING_KEY`、Secret に好きな長い文字列（30 文字以上。パスワード生成サイトで作ったもので OK）→ Add secret
   - **一度決めたら変えないでください。** アプリの更新は同じ合言葉で作ったアプリにしかできません。
2. **アプリを作る**: GitHub の **Actions** タブ →「Android app」→「Run workflow」→「Run workflow」
   - ゲームの URL（`https://blockbuster-reels.sc8z-35a.workers.dev/`）は `app/app-url.txt` に記入済みです。URL が変わったときはこのファイルを書き換えると作り直されます
3. 3〜5 分でアプリができ、ゲームのサイトに自動で置かれます（Cloudflare の自動デプロイ後に使えます）。
   起動画面の「アプリで遊ぶ」→「アプリをダウンロード」から入れられます
   - 合言葉が未登録のうちはアプリは作られるだけで公開されません（Actions の結果に案内が出ます）

### アップデートの仕組み

- **ゲームの中身**（画面・機能・バランスなど）は、サーバーを更新するだけで全員に届きます（ブラウザ・iPhone のホーム画面アプリ・Android アプリ共通）。
  開いているゲームは 2 分ごと・画面に戻ってきたときに新しい版を確かめ、**タイトル画面にいるときや戻ってきたときは自動で最新版に切り替わります**。
  遊んでいる途中（スピン中・通話中・入力中など）はホームに「新しいバージョン（DEV6）があります」と「今すぐアップデート」が出て、1 タップで最新版になります
  （サービスワーカーの古いキャッシュを消してから読み込み直します）。Dev News には各版の DEV 番号・公開日時とこのゲームのバージョンを表示します。
- アップデートを配るときは `js/game/news.js` の先頭に次の番号の Dev News を書きます。その番号が新しい版の印になり、
  古い版の人には更新のお知らせ、更新した人には感謝料 $250,000 が 1 回届きます（何回分かたまっていた人には回数分）。
  公開するときに `date` と `time`（日本時間）を公開した日時にします（サーバーの記録があればそちらが表示されます）。
- **Android アプリ本体**を作り直したとき（URL を変えた・アプリ部分を直した）は、アプリの中に「アップデート」ボタンが出ます。
  押すとダウンロード → インストールまでアプリの中で進み、最後に Android の確認画面で「更新」を押すだけです
  （初回だけ「この提供元のアプリを許可」をオンにする画面が出ます）。
- アプリ本体は GitHub の Actions →「Android app」→「Run workflow」に URL を入れて手動で作り直すこともできます。

## 自分のサーバー（VPS / Docker）で公開する場合

## ルール（ゲーム内「ルール」タブと同じ）

- 「SPIN」をタップして開始します。
- スピンごとにベットが引かれます。賞金はベットと、中央ラインにそろったシンボルの種類と数で決まります（並び順は問いません）。
- 当たりの組み合わせが複数あれば、報酬は加算されます。
- スピン中に終了すると、ベットは戻りません。
- 1 日の購入上限: 10,000,000 スピントークン（毎日 00:00 UTC にリセット）。
- 1 スピントークン = 10 $。「トークンを入手」で $ と交換、「トークンを交換」で $ に戻せます。毎日 1 回、無料トークン（1,000）を受け取れます。
- **サブアカウントの禁止**：ひとりで 2 つ目以降のアカウントを作る・使うことは禁止です。違反はアクセス禁止・BAN の対象です（登録画面にも表示）。

### 配当表（ベットに対する倍率）

| シンボル | 確率 | 友達と稼ぐ中 | 1/5 | 2/5 | 3/5 | 4/5 | 5/5 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| リボルバー | 45.2% | 35% ▼ | | | | x1.5 | x3 |
| 金塊 | 22.7% | 26% | | | x2 | x4 | x10 |
| ダイヤ | 21.2% | 24.3% | | | x2.5 | x5 | x20 |
| スター | 4.5% | 5.2% | | x3 | x10 | x20 | x100 |
| BAR | 3.9% | 4.5% | | x4 | x15 | x50 | x500 |
| 7 | 2.1% | 4% ▲ | | x10 | x20 | x100 | x1000 |
| 女神像 | 0.4% | 1% ▲ | x2 | x10 | x100 | x1000 | x10000 |

この設定での理論還元率（RTP）は **82.0%**、当選確率は約 33.5% です（各リール位置は上表の確率で独立に抽選。以前は約 89.5% / 33.8%）。
この配当表では、リボルバー 4 つ（×1.5）と女神像 1 つ（×2）の小さな当たりが当選の大半を占めるため、確率だけで当選確率を大きく下げることはできません
（82% のまま当選確率を最も下げた組み合わせに近い設定です）。
友達と稼ぐ中は、女神像 1%・7 4%・銃 35% にして残りを通常の比率で分けた確率で約 108%、ダイヤ確定と 777 ×1.5 を入れて約 127%、
共有コンボの倍率（3 回外れるまで続く・平均 ×1.42 ほど）まで入れると約 181% になります（ハブの全員がもうかる設定です）。

### 当たり演出

| 演出 | 条件 | 内容 |
| --- | --- | --- |
| WIN | 合計 5 倍未満 | 画面を覆う演出はなし。当たりのシンボルが光の放射の中で弾み、ラインを光が走り、チップが飛び出して財布（所持金の表示）にチャリチャリと飛び込みます |
| BIG WIN | 5 倍以上 15 倍未満 | タイトルが画面に叩きつけられる瞬間の一瞬の静止（ヒットストップ）と衝撃波・画面の揺れ、回転する放射光とスポットライト、チップの噴水、カウントアップ、最後に紙吹雪の大砲。終わるとチップが財布に流れ込みます |
| SUPER BIG WIN | 15 倍以上 | BIG WIN からカウント途中で「SUPER」が飛び込み、画面がガラスのように割れて虹の光線・稲妻・花火・紙吹雪 |

WIN・BIG WIN・SUPER BIG WIN の文字は **回転する 3D の文字**（`img/3d/*.glb`、three.js で表示）。正面を向いたときはゆっくり、裏側はすばやく回ります。WIN はリールの上に 1.6 秒、BIG WIN は回転しながら叩きつけられ、SUPER BIG WIN はカウント途中で 3D の SUPER BIG WIN に切り替わります。モデルはゲームが始まったあとにオンラインのときだけ裏で読み込み（モデル 4 つで約 3.2 MB と three.js 約 0.8 MB、一度読めばキャッシュ）、読み込むまで・WebGL のない端末・演出設定の「3Dの当たり文字」がオフ・動きが重い端末（自動で判定）では従来の文字で表示します。**77777（7 が 5 つ）のときだけ** は SUPER BIG WIN の代わりに虹色の **ULTRA BIG WIN**（3D、従来の文字では虹色の「ULTRA」）。

リールの回転は途中で止められません。BIG WIN 以上の演出中は画面をタップするとカウントを飛ばせます。あと 1 つで 20 倍以上になる場面では残りのリールが減速して炎に包まれ、「チャンス！」「激アツ！！」と稲妻の「リーチ演出」が入ります。

### そのほかの演出（js/render/juice.js・slotfx.js・css/juice.css）

- リールのまわりの電飾：待機中はゆっくり光の波、回転中は光が走り、リーチでは赤く高速に、当たりでは点滅
- 回すとき：SPIN ボタンから衝撃波と光、リールを光が横切る。止まるたびにリールの上下が光って揺れ、火花が散る
- お金・コインが入るときは、出どころ（当たったシンボル・ログインボーナスのカード・クエストの「受け取る」・感謝料・届いた送金の通知など）からコインが財布へ次々に飛び込み、1 枚ごとに「チャリン」と鳴って、最後に「+金額」。ダイアログの上でも財布が手前に出てきて受け取ります
- リールが止まるたびに、そろったシンボルが光の枠で囲まれていく（あと何個で当たりかが見える）。7・BAR・女神像が止まると専用の演出
- 当たりの演出はシンボルごと：7 は炎、女神像は光の柱、ダイヤは虹色のきらめき、スターは回転、BAR は光沢、金塊は四隅のきらめき、銃は発砲と硝煙。当たったシンボル同士は稲妻でつながる
- 5 回連続で当たると FEVER：画面のふちが燃え、炎と火の粉が上がり、リールの右上に FEVER の看板、電飾は炎の色に（外れると煙とともに鎮火）
- タイトル画面からスロットに入ると赤い幕が開く。何もしていないときもシンボルがきらめき、15 秒放っておくと電飾と SPIN ボタンが誘う
- レベルアップでは経験値バーが満タンになってから次のレベルへ切り替わる
- コンボ・レベルアップ（LEVEL UP!）・ログインボーナス・購入・フレンド対決の勝敗・協力ボーナス・観戦ベットの的中にもそれぞれの演出
- 画面の切り替え、ダイアログ（ぽんと着地）、通知、ボタン（押すとへこんで戻る・光が流れる）、リスト（順番に登場）、メッセージ（ぽんと出る）
- 端末で「視差効果を減らす」を選んでいる人には、常に動き続ける飾りの動きと揺れを控えめにします
