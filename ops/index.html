プレイヤーアーカイブ

    
永久BANとアカウント削除をしたプレイヤーです。ここに入って90日たつと、その人のデータ（ログイン・端末・お金・車・フレンドなど）は自動で削除されます。会話とログは無期限で保存され、名前は「〇〇（削除済み）」として残ります。永久BANは解除するとプレイヤー一覧に戻ります。削除したアカウントは誰も元に戻せません。

運営ログ

      
      
    

    

      
    

    

    
プレイヤー・運営・セキュリティ・保管庫・緊急に分けて自動で記録されます（プレイヤーアクティビティは、プレイヤーの登録・削除・処分・パスワードや権限の変更などをまとめたものです）。消去も書き換えもできず、最新の記録のハッシュはデータベースの外にも控えているので、書き換えや作り直しは「改ざんチェック」に出ます。行をタップすると関連する場所（プレイヤー・通報・保管庫など）が開き、「詳細」で記録のすべてを表示します。

    

    
  


  
  

    

      
運営者

      

        
        
        
      

    

    
権限の付与と剥奪は開発者だけが「開発者コード」でできます。運営権を剥奪された人はすぐ全端末でログアウトされ、運営サイトに入れなくなります。開発者は剥奪・アクセス禁止・BANできません。

    

      

      
    

    

    
閲覧者

    
運営サイトと security HOME を見ることだけができる人です（プレイヤー一覧・アーカイブ・保管庫・チャット・バックアップ・課金は見られず、操作は一切できません）。剥奪するとその場で運営サイトと security HOME からログアウトされます（ゲームはそのまま）。

    

    

      
ログインログ 開発者だけ

      
開発者・運営者・閲覧者がその日はじめて運営サイトに入った記録です（日本時間で1日1回。「ログイン」ボタンか、パスワードでのログイン）。開発者だけが見られます。

      

      
    

  


  
  

    

      
課金（開発者支援）

      

        
        
      

    

    

    

    
購入した人は、開発者が返信するまでここに残ります（返信は「【開発者からのメッセージ】」として公式から届きます）。ロイヤルコインは入金の確認後に自動で届いています。

    

  


  
  

    
運営チャット

    
運営者だけの連絡用です。緑は運営サイトにいる人、青はゲーム中の人。送ったメッセージは取り消せません。個人チャットは開発者も見られます。「＠」でプレイヤーや @開発者（開発者にすぐ知らせます）を、「ログ」で運営ログの記録を引用できます。全体チャットでは人数・時間の制限なしで高音質のグループ通話ができます。
