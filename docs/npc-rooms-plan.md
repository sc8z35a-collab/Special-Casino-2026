## 1. 料金

### 1.1 決まり（Cloudflareの公式の料金表）

- 部屋が起きている間の料金は、使ったメモリではなく**部屋1つにつき128MB**で数えます。込みの分（月40万GB秒）はアカウント全体で1つです。
- 休める状態の部屋（タイマー・見回り・届いた呼び出しがない部屋）は数えません。
- 計算の量（CPU）は別に数えません。起きている5時間のうちは、たくさん計算しても料金は同じです。
- Workers AIは、毎日1万Neuronsまで無料（00:00 UTCに戻る）。それを越えると1,000Neuronsごとに$0.011です。

### 1.2 見積もり（31日の月）

| 項目 | 月の額 |
| --- | ---: |
| 人の部屋15個（1部屋 0.125GB × 18,000秒 × 31日 ＝ 69,750GB秒） | 約¥1,370（運営が1日1時間見る）〜¥1,420（3時間） |
| 選ばれし300人のAI | 上限¥1,450から部屋の分を引いた残り（部屋ができる前は¥1,450まで） |
| リクエスト・書き込み・保存の容量 | 込みの分の中（プレイヤーがいないため） |

- 部屋の数はNPC_ROOMSで本体に知らせます。AIのお金は自動で「¥1,450 − 部屋の数×¥131」になります（NPC_AI_YENで上書きできる）。
- カジノを開くと本体が1日中起きるので、15部屋は約¥1,840になって越えます。開くときは10部屋に戻します。

## 2. 人口：人手が足りるぎりぎり

- 新しい暮らしの決まりでは、人口の**約97%が働ける年齢**（18〜59歳）です（今までは約70%）。
- ヴェルノアの会社・テネシスリサーチ・地元企業が必要とする人は、ルールの数で22,210人。経済の規模0.4倍で**8,884人**です。
- ほかに公務員・自営業・小さな店（人口の約5.5%）と、仕事を変える途中の人（働く人の約3%）がいるので、
  8,884 ÷（0.9735 × 0.97 − 0.055）≈ **10,000人**がぎりぎりです。
- アスカは必ず2倍なので**2万人**。働ける人約19,500人に対し、会社（経済の規模0.267倍）約4,950人・地元の商売6,000人（人口の30%）で、残りをATSUKA Visionが雇います（約7,900人。最低1,500人）。

## 3. 部屋の分け方

- 本体（今のCasino）：会社・株の市場・両国の国の帳簿・お金の台帳・人の写し・運営サイト。
- 人の部屋15個（それぞれ別のWorker：同じWorkerの部屋は1つの入れ物に入って128MBを分け合うことがあるため）。

| 部屋 | 区 | 人数 |
| --- | --- | ---: |
| npc-v1〜v5 | ヴェルノアの5つの区（1区1部屋） | 2,000ずつ |
| npc-a1〜a10 | アスカの5つの区（1区2部屋） | 2,000ずつ |

- 世帯は必ず同じ部屋。人の部屋は本体とだけ話し（星形）、お金は番号付きの送り状で運び、毎日22:00にずれ$0を確かめます。
- 送り状は送る前に保存し、部屋が落ちたら最後の保存から戻して当て直します。本体は番号で二重に受け取りません。

## 4. 一日の流れ（人の部屋ができてから）

| 時刻 | すること |
| --- | --- |
| 17:00 | 部屋を開き、保存から全員を読み込む |
| 17:00〜17:05 | 昼の要約（前の晩22:00〜17:00の生活を、夕方と同じ頭で1時間刻みに計算） |
| 17:05〜21:45 | **10秒ごと**の生活（全員が10秒以内に周りの出来事に反応する） |
| 21:45〜21:55 | 夜の振り返り（答え合わせ・教訓・日記・思い出の整理） |
| 21:55 | 全員を保存し、身分証明書・プロフィールの写しを本体へ送る |
| 22:00 | タイマーを全部消して眠る（料金が止まる） |

本体は時間外に人の部屋を呼ばず、人の部屋には外から入る道を作りません。

## 5. メモリと計算（1部屋2,000人）

| 中身 | 大きさ |
| --- | ---: |
| プログラム・部屋の状態・作業用 | 約26MB |
| 人（2,000人 × 約40KB） | 約82MB |
| **合計** | **約108MB**（上限128MB） |

- 保存は列ごとに2MBずつ（全員を1つにつなげない）。
- 考える時間：1分のうち**50秒**（残りはやり取りと保存）。1人1分あたり約25ミリ秒。重い先読みはWebAssemblyにして2〜3倍速くし、実質50〜75ミリ秒分。
- 1人の頭（約40KB）の中身：身分と基本・性格と価値観・スキルと理解度・体と心・お金と家計簿（直近300回・24か月）・見通し・学んだこと（選択肢150種×場面8つ）・目標と長い計画・思い出（最近の2,000件）・人間関係（150人）・心のモデル（親しい30人）・決断と理由（最近の300件）・仕事・ヴェルノアだけの株・車・政治・遊び。

## 6. 頭の賢さ（市民：AIなし）

- **選択肢の目録**：できることを全部（約150種類）並べて比べる。決まりは全部わかっていて、わからないのは将来だけ。
- **二手先まで読む**：大きな決断は「今選ぶ→結果→次にどうするか」まで、1,024通り以上試す。
- **相手の出方を読む**：交渉や申し込みは、相手の心のモデルで答えを試してから。
- **理由を持って答え合わせ**：決断ごとに理由を残し、結果で学ぶ。場面ごと・似た経験からも学ぶ。
- **自分を知る**：弱みを見つけ、自分でルールを作って守る（例：給料日の前はカジノに行かない）。
- **長い計画**：人生の目標→1年→月→今日。事情が変わったら立て直す。
- **人と一緒に考える**：話して見通しを交換し（うわさは間違うこともある）、家族で相談して決める。値動きを読む。

## 7. AI（選ばれし300人・アルファ90人・会議の10人）

| 層 | 人数 | 何をAIで決めるか | モデル |
| --- | ---: | --- | --- |
| 選ばれし300人 | 300 | 今日の予定2つとその理由（性格・気持ち・お金・人生の教訓に沿って） | qwen3-30b-a3b（安くて賢い） |
| アルファの90人 | 90 | 上に加えて、上場企業ごとの見通し（−2〜+2）。株の注文はこれに従う | qwen3-30b-a3b |
| 会議の10人 | 10 | 上に加えて、アルファの会議の発言と結論（グループの決まりの中で。90人の見通しの平均とこれまでの損益も見て） | gemma-4-26b-a4b（より強い） |

- 300人は、地位（役員・区長・組合の代表）とお金で月1回選び直します。1万人の国で300人（小さい国ほど少ない）。
- AIは選ぶだけで、お金を動かすのはエンジンです。AIが選んだ予定は、その日と次の日、エンジンの予定より優先されます。
- AIのお金：無料の1万Neurons（UTCの日ごと）と、上乗せの上限の残り。人が動く時間に合わせて少しずつ使い、使い切れるように番が回る間隔を自動で縮めます（最短で10人が1分ごと、90人が2分ごと、残りが4分ごと）。
- 市民のAIはなくしました（新事業の告知は決まった文。区長の演説・CEOの心の声と経営判断は、その人が300人のときだけAI）。

## 8. 人口とお金の再編（実装済み）

- 一度だけ、次の日の締めで行います（`server/core/npc-reorg.js`）。
- 62歳以上の人は存在ごと消え、残りを世帯ごとにヴェルノア1万人まで減らします（役員・区長・組合の代表の世帯が先）。アスカは2万人。
- 移住する人は自分のお金を持って出ます（借金を先に返し、残りは銀行の損）。株は同じ株を持つ人へ持ち株に比例して分けます。
- 国のお金（国庫・年金の積立金・国の銀行・ATSUKA Vision・企業誘致の資金・地元の商売）も人口の割合で減らします。
- 減った額は台帳に1回だけ記録し、毎日のずれ$0の確認はそのまま通ります。
- 人の番号を詰め直し、人を指すものを全部付け替えます（世帯・配偶者・人間関係・会社の役職・区長・組合・請願・株の注文・アルファ・病院の順番待ち・記録など）。
- 残った学生と家事中心の人は仕事を探し、60〜61歳の人は引退します。
- 経済の規模を小さくします（ヴェルノア0.4倍・アスカ0.267倍）。プレイヤーのお金・株、上場企業の現金には触りません。
