- 新しい決まりでは、人口の**約97%が働ける年齢**です。
- ヴェルノアの会社が必要な人は、ルールの数22,210人に経済の規模0.4倍をかけて**8,884人**。公務員・自営業・小さな店（人口の約5.5%）と、転職中の人（約3%）を合わせて、**約1万人**がぎりぎりです。

## 3. 人の部屋

### 3.1 しくみ

- **体は本体、頭は部屋**。お金・仕事・家・気持ちと経済全体は本体に残し、一人一人の頭（思い出・学んだこと・決断・見通し・目標・自分のルール）だけを部屋に置きます。
- **部屋にお金は一切渡りません**。そのためお金の台帳は部屋の影響を受けず、部屋が落ちてもお金はずれません。
- 部屋の分け方：ヴェルノアの人は番号を5で割った余りで5部屋、アスカの人は10で割った余りで10部屋（1部屋約2,000人）。番号が変わらないので、人が部屋を移ることはありません。
- 部屋は1つずつ別のWorker（`npc-room-1`〜`npc-room-15`）。同じWorkerの部屋は1つの入れ物で128MBを分け合うことがあるからです。外からは入れず、本体からだけ呼べます。

### 3.2 一日の流れ

| 時刻 | 本体 | 部屋 |
| --- | --- | --- |
| 17:00 | 15部屋を開く（人の世代と性格を渡す） | 保存から頭を読み込む。新しく生まれた人には新しい頭 |
| 17:00〜22:00 | 1分ごとに、各部屋の人の体（お金・仕事・気持ち・欲求など24の数）とその1分の出来事を渡し、返ってきた「したいこと」をエンジンで実行（お金と信用を確かめる。300人のAIが今日決めたことが優先） | 10秒のリズムで（6分の1ずつ）全員が考え、変わった人の「したいこと」を返す |
| 22:00 | 部屋を閉じる。返ってきたプロフィールを保存（部屋が眠っている間はこれを見る） | 夜の振り返り（決断の答え合わせ・学ぶ・自分のルールを作る）、プロフィールを作り、頭を保存して眠る |

### 3.3 1人の頭（33,061バイト）

| 中身 | 大きさ |
| --- | ---: |
| 思い出 3,000件 | 24KB |
| 決断と答え合わせ 300件 | 7.2KB |
| 学んだこと（予定9種＋大きな行動7種 × 場面8種の価値と回数） | 768B |
| 見通し（給料の伸び・物価・各社の値動きなど16） | 64B |
| よく知る人 30人 | 240B |
| 60日分の暮らしの記録（純資産・現金・気分） | 720B |
| 性格・目標・自分のルール 8つ・その他 | 約70B |

### 3.4 考え方

- **予定**：足りないもの・性格・その場面で以前うまくいったか・自分のルールで、今日の予定を2つまで選ぶ。
- **大きな行動**（1日1回まで）：転職・車・株の売買・借りる・返す・何もしない を、自分の見通しで1年先を**4,096通り**試して比べ、慎重さに応じて危なさを差し引き、何もしないより十分良いときだけ選ぶ。
- **会社の見通し**：各社の最近の値動きとニュースへの関心から、−2〜+2。株の注文に使われる。
- **夜の振り返り**：1〜7日前の決断を、純資産と気分の変化で答え合わせして学ぶ（学ぶ速さは「学び好き」で変わる）。3回以上損をした行動は、その場面では「しない」と自分のルールにする。

### 3.5 測った値（1部屋2,000人）

| 項目 | 値 |
| --- | ---: |
| メモリ | 63MB（上限128MB） |
| 1分の考える時間 | 平均14ミリ秒（最初の1分だけ0.24秒） |
| 閉じる（振り返り・保存） | 0.27秒 |
| 保存 | 1MBずつ67行 |

## 4. 労働と動く時間

- 動く時間は毎日17:00〜22:00。働くのはその最初の4時間（17:00〜21:00。遅番は最後の4時間）で、1時間ごとに40分働いて20分休憩（休憩中は自由に行動し、終わると仕事に戻る）。
- 会社の生産力は、この働く時間（1人1日2時間40分）を基準に測るので落ちません。

## 6. 人口とお金の再編

- 一度だけ、次の日の締めで行います（`server/core/npc-reorg.js`）。
- 62歳以上は存在ごと消え、世帯ごとにヴェルノア1万人・アスカ2万人まで減らします（役員・区長・組合の代表の世帯が先）。
- 移住する人は自分のお金を持って出ます。株は同じ株を持つ人へ分けます。国のお金も人口の割合で減らし、台帳に1回だけ記録します。
- 人を指すものは全部付け替えます。経済の規模はヴェルノア0.4倍・アスカ0.267倍。プレイヤーのお金・株、上場企業の現金には触りません。

## 7. 保存

- 人の体は列ごとに1.5MBずつ、頭は1MBずつ、作りながら書き、読むときも1行ずつ。保存の瞬間のメモリの増え方は約39MBから3.3MBに。
