# NPCの街の計画 第2版（20万人が暮らし、働き、遊ぶ経済）

> 状態：計画（未実装）。第2版：2026-10-31。
> 第1版（社員枠4万＋住民6万・使用量はできるだけ少なく）から、**ご指定の使用量の上限まで使ってよい**前提で作り直しました。
> ご指定の上限：**書き込み行は込みの分の70%まで、リクエストは80%まで、そのほか（動いている時間・保存量・読み取りなど）は6〜8割まで**。
> 数値は仮の初期値です。負荷の数字は、手元で作った**使い捨ての試作2つ**を測ったものです（§11）。
> お金の単位はゲーム内の $ です（「35M」＝ $35,000,000）。
> 関連：[経済システムの計画](economy-plan.md)・[企業（決算・商品・ビジネス友好度）](handbook/39.md)・[投資](handbook/37.md)

## 0. 結論

- **20万人、動かせます。** 街を**4つの地区**に分け、地区ごとに専用のDurable Object（サーバーの部屋）で5万人ずつ動かします。今のサーバー（本体）は、市場・会社・在庫・プレイヤーを受け持ち、**1分ごとに各地区とやり取り**します。
- 使用量は、ご指定の上限の中に余裕をもって収まります（標準構成、§2）。

  | 使用量 | ご指定の上限 | 見込み |
  | --- | ---: | ---: |
  | リクエスト（Durable Objects） | 80% | 約22% |
  | 書き込み行 | 70% | 約15% |
  | 保存量 | 6〜8割 | 約50% |
  | 動いている時間 | 6〜8割 | 1〜3% |

  さらに豊かにする最大構成（8地区・記録多め）でも、リクエスト約39%・書き込み約40%に収まります。プレイヤーが増えても上限を超えないよう、**使用量の自動ブレーキ**を付けます。
- **全市民が社員になれます。** 社員枠の上限をなくし、15歳以上の誰でも、10社の求人に応募して入社できます。今の社員27,750人は、最初からNPCとして各社で働いています。
- **1人1人がプロフィールを持ちます**（アカウントではありません）。名前・年齢・家族・学歴・職歴・性格・価値観・趣味・好み・夢・健康・評判・人間関係・思い出。
- **より人間らしく動きます。** 家族で家計を考え、友達と話して口コミが広がり、感情で選び方が変わり、何か月もかけた目標を立て、失敗から学び、人間らしい思い込みもします。
- **手元の試作で確認しました。** 1人約790バイトの豊かな頭（1日40回行動・人付き合い・思い出）を5万人で動かしても、1日分の計算は**約8.6秒**です。毎日1人1行の記録（5万行）は0.1秒、全員の写しは約38MBでした。20万人を1つの部屋に入れると約150MBになり、1部屋の上限128MBを超えます。だから地区に分けます。

## 2. 使用量の予算

### 2.1 標準構成（4地区×5万人・1分ごとのやり取り）

| 使用量 | 込みの分（月） | ご指定の上限 | NPCの見込み | 割合 |
| --- | ---: | ---: | --- | ---: |
| Durable Objectsのリクエスト | 100万回 | 80% | 本体の1分ごとの見回り 4.3万回＋地区への呼び出し 17.3万回 | **約22%** |
| Workersのリクエスト | 1,000万回 | 80% | ほぼ増えない（NPCは端末を持たない。画面で見るときだけ） | ほぼ0% |
| 書き込み行 | 5,000万行 | 70% | 1人1日の記録600万＋地区の差分17万＋見回りの予約4.3万＋1人1か月の要約20万＋市場・街の声・人事など100万 | **約15%**（約740万行） |
| 読み取り行 | 250億行 | 6〜8割 | 写しの読み込み・運営サイトの表示・分析で数千万行 | 1%未満 |
| 動いている時間 | 40万GB秒 | 6〜8割 | 本体約1千＋地区約1千GB秒。地区が毎回読み直しになる最悪の場合でも約1万 | **0.5〜3%** |
| 保存量 | 5GB | 6〜8割 | 地区の写し0.3GB＋1人1日の記録30日分1.2GB＋月ごとの要約・市場・街の声で年0.8GB＋今のゲームのデータ | **約50%**（1年目） |

※ Cloudflareの料金の決まり（公式の料金ページで確認）：休める状態のDurable Objectは、待っている間は「動いている時間」に数えられません。見回り（アラーム）は1回がリクエスト1回で、予約するたびに書き込み1行です。別の部屋を呼ぶと、呼ばれた側でリクエスト1回です。

### 2.2 間隔と構成を変えたときのリクエスト

| 構成 | 1分ごと | 2分ごと | 5分ごと | 20分ごと |
| --- | ---: | ---: | ---: | ---: |
| 4地区（標準） | 約22% | 約11% | 約4% | 約1% |
| 8地区（最大） | 約39% | 約19% | 約8% | 約2% |

- **最大構成**：8地区×2.5万人で、1人の中身を約2.5KBにします（思い出128件・人間関係100人・職歴と人生の出来事を細かく）。重要な出来事を1件1行で残し（1日30万行・30日分）、株の約定もすべて残します。書き込みは約40%、保存は約70%です（保持日数はブレーキで調整）。
- どちらも、プレイヤーの使用量のための余裕を残しています。

### 2.3 使用量の自動ブレーキ

- **見るもの**：NPCが自分で使った量（呼び出しの回数・書き込んだ行・保存量・処理時間）は正確に数えます。ゲーム全体の使用量は、今の運営サイトの「サーバー」タブの見積もりと、70%・90%の通知（`server/core/usagealert.js`）、Cloudflareの集計（トークンがあれば）で見ます。
- **予測**：今月の使用量 ×（月の日数 ÷ 経過日数）。
- **段階**：

| 段階 | 条件（どれか1つの項目が） | NPCの動き |
| --- | --- | --- |
| 0 | ご指定の上限の60%未満の見込み | すべて標準 |
| 1 | 60%以上 | やり取りを2分ごとに、街の声を半分に |
| 2 | 上限に届く見込み | やり取りを5分ごとに、1人1日の記録は「出来事があった人」だけに、写しを減らす |
| 3 | 上限の95% | 新しい記録を止め、NPCの経済は「まとめ計算」だけに。Discordで知らせる |
| 4 | 今の緊急停止 | NPCも止める |

- 見込みが下がれば、自動で元の段階に戻ります。上限の値は運営サイトで変えられます（今はご指定の70%・80%・70%）。

## 3. 全体のしくみ（本体と地区）

### 3.1 役割分担

| 部屋 | 受け持つもの |
| --- | --- |
| **本体**（今のサーバー） | プレイヤー全員・10社の帳簿（`server/core/corp-model.js`）・株の板と約定・車とSHOPの在庫・求人と社員名簿・ニュース・街全体の集計・地区とのやり取りと時計 |
| **地区**（新しい部屋×4。東・西・南・北） | 5万人ずつの暮らし：その日の予定・頭の中・家計・家族・人間関係・思い出・勤務・プロフィールの保存・1人1日の記録 |

- 1人のNPCのすべては、その人が住む**1つの地区**にあります（頭の中が部屋をまたがない）。
- 地区をまたぐ友達や家族もいます。会話や伝言は本体を通って、次の1分に相手の地区へ届きます（口コミが地区をまたいで広がる）。

### 3.2 1分ごとのやり取り

本体の見回り（1分ごと）が、4つの地区を順に呼びます。1回の呼び出しで、行きと帰りをまとめて運びます。

| 本体 → 地区 | 地区 → 本体 |
| --- | --- |
| 今の値段（株・車・SHOP）とセール、在庫 | その1分の買い物（商品ごとの数と金額） |
| ニュース（決算・新作・値上げなど） | カジノの結果（賭け金・払い戻し・手数料） |
| 求人・面接の結果・内定 | 応募・退職・転職の届け |
| 給料・配当・約定の結果・ローンの審査結果 | 株の注文（指値・成行）とキャンセル |
| 他の地区からの伝言・会話 | 勤務の量（会社ごと・部署ごとの働き） |
| 運営からの指示（つまみ・ブレーキの段階） | ローンの申し込み・街の声（投稿）・地区の集計 |

### 3.3 順番と、同じ結果になること

- 1分（m分目）ごとに、①本体がm分目の状態を送る → ②各地区がm分目に予定のある人を動かす（判断にはm分目の状態を使う）→ ③地区の行動を本体が反映する（在庫は「プレイヤーが先、NPCは決まった順」）→ ④NPCの株の注文をその1分でまとめて約定し、次の1分の株価に反映。
- 日本時間9:00（UTC 0:00）に、その日の地区の集計で会社の1日を締めます（今の企業の仕組み）。
- 各部屋は、受け取ったメッセージを記録しておけば、同じ計算をやり直しても同じ結果になります（乱数はサーバーの秘密の鍵から作る）。
- 地区は人間と同じく「1分遅れで値段を知る」ので、株の反応にも自然な遅れが出ます。

### 3.4 保存

| 何を | どこに | どれくらい |
| --- | --- | --- |
| 全員の写し | 各地区（2MB以下の行に分ける） | 3時間ごと。5万人で約38MB（約20行） |
| 変化の差分 | 各地区 | 1分ごとに1行 |
| 1人1日の生活記録（資産・気分・その日の出来事） | 各地区 | 毎日4:00に1人1行。30日分 |
| 1人1か月の要約 | 各地区 | 毎月1人1行。ずっと |
| 株の1分ごとの集計・大口の約定・街の声・人事の出来事 | 本体 | 1日数万行 |

起動したら、地区は「最新の写し＋その後の差分」を読んで、止まる前の状態に戻ります。

### 3.5 うまくいかなかったとき

- 地区が答えないときは、本体はその地区を待たずに進みます。次の呼び出しで、地区は止まっていた分をまとめて計算して返します（番号付きで、同じものが二重に入らない）。
- 地区の計算が重くなったら、1回の呼び出しで進める分を区切ります（上限時間を超えない）。

## 4. 20万人の街

### 4.1 年齢・世帯・地区

| 年齢 | 人数 | ようす |
| --- | ---: | --- |
| 0〜14歳 | 24,000 | 家族の一員。学校・遊び・ゲーム。お小遣い |
| 15〜24歳 | 22,000 | 高校・大学（約1.6万）と社会人。15〜17歳はバイトだけ |
| 25〜64歳 | 106,000 | 働く人の中心 |
| 65歳以上 | 48,000 | 退職者が多い。再雇用・パートもある |

- **世帯**は約9万（平均2.2人）。家計をまとめ、車や大きな買い物は家族で決めます。
- **地区**は東・西・南・北（それぞれ約5万人）。地区ごとに街の雰囲気（若者が多い・お金持ちが多い・工場の近く）を少し変えます。

### 4.2 仕事（全市民が社員になれる）

| 状態 | 人数（はじめ） |
| --- | ---: |
| 10社の社員 | 27,750（今の各社の社員数どおり。テネシス12,000・MAGITA 6,000・ジンクス3,000・カーオーナー2,500・Ice Smoker 1,600・シティーワーク900・スピーディード500・RIRU 450・DAIZIN 400・Dtrade 400） |
| 街のその他の職場（お店・役所・病院・学校・街の外へ通勤） | 約62,000 |
| 自営業 | 約6,000 |
| 家事中心 | 約6,000 |
| 仕事を探している | 約4,250（失業率 約4%） |
| 学生・退職者・子ども | 残り |

- 15歳以上なら誰でも、10社の求人に応募できます（15〜17歳はバイトだけ、65歳以上は再雇用・パート）。
- 「その他の職場」は帳簿のない職場で、給料は街の外から入るお金として扱います。これで、10社だけでは足りない働き口と収入が本物らしくなります。

### 4.3 資産と収入

- 資産は対数正規分布（中央値 約$30M）に、上位約2%だけ長い裾（$1B〜$50B）。ジニ係数0.6〜0.7を目安。
- 収入：10社の給料（年$108B）、その他の職場（約$155B）、自営業、年金（約$48B）、配当・利息、バイト。

### 4.4 人口の入れ替わり（第6段階）

1年に1歳ずつ年をとります。4月に新卒が社会人になり、65歳前後で退職します。結婚・出産・引っ越し・亡くなる人があり、引っ越してくる人で20万人前後を保ちます。

お金（現金・テネシスの預金・借金・Dtradeの証券口座）、持ち物（車・SHOPの品）、8つの欲求、感情（気分・ストレス・幸福度）、体力、仕事のようす、目標の進み、習慣の強さ、各社や車種への印象、株の見通し、人間関係の親密度、思い出。

| 構成 | 1人 | 1地区 |
| --- | ---: | ---: |
| 標準（思い出32件・人間関係30人） | 約790バイト | 5万人で約38MB（＋作業用で約60MB） |

## 6. 頭の中（より人間らしく）

### 6.1 流れ

1. **朝の計画**：その日の時間割（仕事・学校・用事・自由時間）を、習慣・曜日・予定・体調・目標から作る。
2. **空き時間の選択**：自由時間が来るたびに、今いちばんやりたいことを選ぶ（§6.3）。
3. **目標**：何か月もかかる目標を、小さな手順に分けて進める（§6.4）。
4. **人付き合い**：家族・友達・同僚と過ごし、話し、影響し合う（§6.6）。
5. **振り返り**：結果を思い出に残し、見通しや好みを更新する（§6.5）。

### 6.2 欲求と感情

| 欲求 | 満たす行動 |
| --- | --- |
| 楽しみ | ゲーム・買い物・外出 |
| 刺激 | カジノ・短期の株の売買 |
| 見栄 | 高級車・VIP・高級品 |
| 安心 | 貯金・配当株・借金の返済 |
| 移動 | 車・ガソリン |
| 人づきあい | 家族や友達と過ごす |
| 休息 | 睡眠・休み |
| 達成 | 仕事の成果・昇進・投資の利益・目標の達成 |

- 欲求は時間とともに減り、足りないものほど満たしたくなります（必要なときだけ計算）。
- **感情**：気分（楽しい↔つらい）・高ぶり・ストレス・幸福度。うれしい出来事やつらい出来事で動き、少しずつ元に戻ります。気分がよいと気前よく買い、高ぶると大胆に賭け、ストレスがたまると休みたくなる（人によっては買い物やカジノで発散する）。友達の気分も少しうつります。

### 6.3 行動の選び方（ユーティリティAI）

ゲームのAIでよく使われるやり方で、行動ごとに「考える材料」を0〜1の数にして掛け合わせます。

例：カジノに行くか

| 考える材料 | 曲線 |
| --- | --- |
| 刺激の欲求の不足 | 足りないほど高い |
| 気分と高ぶり | 高いほど高い |
| 今月のカジノの予算の残り | 少ないと急に下がる |
| 時間帯と明日の予定 | 夜・休みの前は高い |
| 最近の勝ち負けの思い出 | 大負けの直後は低い（熱くなる人は逆に高い） |
| 友達に誘われたか | 誘われると高い |
| 家族の目 | 家計を気にする家族がいると下がる |

全部の行動の点数から、点数の高いものほど選ばれやすい確率で選びます（衝動的な人ほど気まぐれ）。行動は約20種類（買い物・車を見る・カジノ・株を見る・ゲーム・VIP・家族と過ごす・友達と会う・勉強・副業・休む…）。

### 6.4 目標と計画

目標は何段階もの計画になります。例：「MAGITA GT-Rを買う」

1. 予算を決める（年収・貯金・家族の意見）
2. 毎月の積立を増やす、残業を増やす
3. セールを待つか、テネシスの自動車ローンを申し込む
4. 買う → 見栄が満たされる → しばらくして慣れる

状況が変わると目標をあきらめたり、変えたりします（失業・病気・家族が増えた・株で大損）。ほかに「昇進」「転職」「資産を増やす」「借金を返す」「新作ゲームを全部遊ぶ」など。

### 6.5 思い出と学習

- **出来事の思い出**：最近の出来事（車が壊れた・売り切れで買えなかった・大当たり・決算で大損・昇進）を、感情の重みと一緒に覚えます。時間とともに薄れ、大きな出来事は「人生の出来事」として残ります。
- **知識**：各社・各車種・ゲームのジャンルへの印象と信頼。自分の体験・ニュース・友達の話で更新します。
- **習慣**：くり返した行動ほど自然にやるようになり、しばらくやらないと弱まります。
- **株の戦略**：うまくいっている戦略へ少しずつ乗り換えます。
- 例：売り切れで買えなかった人は、次は早めに買う。大当たりの記憶はギャンブル気質を少し強める。修理が続いた車種は避ける。

### 6.6 人間関係と会話

- **相手**：家族（同じ世帯・別の世帯の親や子）・友達（10〜40人）・同僚・近所・ライバル。
- **会う**：家族の夕食、職場の昼休み、休日に友達と出かける、カジノに誘う、車を一緒に見に行く。
- **話す**：車・ゲーム・株・カジノ・仕事・家族の話題。話すと、①気分がうつる、②意見が近づく（意見が離れすぎている相手からは影響を受けない）、③おすすめが伝わる（「ICEの新作、面白いよ」）、④親密度が上下する。
- **会話の文**：運営サイトでは、記録された出来事から、ひな形で会話を作って見られます（例：「田中：MAGITAの値上げ、きついよね」）。

### 6.7 口コミ・流行・ニュースの広がり

- 新作ゲームや車は、「最初に試す人」と「周りが買ったから買う人」で広がります（バス拡散モデル）。街の住民が買った割合を世界の縮図として、ゲームの世界での売れ方も決めます。だから「街での評判」から株価を予想できます。
- 決算や値上げのニュースは、ニュースをよく見る人から、会話を通って数日かけて広がります（発表直後に動いて、数日かけて落ち着く）。
- **街の声**（SNSのような投稿）：出来事があった人がときどき投稿し、それを見た人が影響されます。

### 6.8 人間らしい思い込みと失敗

- 損を得より約2.25倍重く感じる。含み損は持ち続け、利益はすぐ確定する。
- 勝つと自信過剰、負けが続くと取り返そうとする（熱くなる）。
- 給料日の直後に使いすぎる、面倒なことを先延ばしにする。
- 「ずっと外れているから次は当たる」と思う。
- みんなが買っていると買いたくなる。
- 高い物を買った直後はうれしいが、だんだん慣れる。

### 6.9 プレイヤーっぽさ

- 自由時間に**ゲームを開く**（数分〜数十分）。ホーム→スロット→投資→SHOP…と画面を行き来する。
- スロットは、プレイヤーと同じベットの段階から、資金と気分で選んでAUTOのように回す。負け幅や勝ち幅でやめる。
- 株は、プレイヤーと同じチャート（移動平均5・25）と同じニュースを見て判断する。手数料（片道1.8%）も同じ。
- セールやイベントに集まり、給料日に気が大きくなる。
- ルールもプレイヤーと同じ（2,000トークン以上で当たれば勝利金の6%がDtradeへ、トークンの交換は$40,000の手数料など）。

## 8. 仕事

### 8.1 求人から入社まで（全市民が対象）

1. **求人**：会社が採用の目標（今の企業の計算の`target`に、需要で忙しいかどうかを加える）から、部署・職種・年収の幅・必要なスキルを出す。中途は毎月1日、新卒は4月1日の入社。
2. **応募**：15歳以上の誰でも（失業中・学生・その他の職場で働く人・他社の社員）。年収・会社の印象・やりがい・友達の評判で応募するかを決める。求人2社（シティーワーク・スピーディード）経由なら、入社が決まると**人材紹介料**（初年度年収の約30%）が求人サイトの売上になる。
3. **選考**：スキル・経験・面接（性格の相性と運）で会社が選ぶ。
4. **内定と入社**：受けるかどうかを本人が決め、退職の手続きを経て入社する。

### 8.2 勤務と働き指数 → 会社の業績

- 1人の1時間の働き ＝ 職種のスキル × やる気 × 体力 × 経験（入社直後は低い）× 上司の力。
- 会社の**働き指数** ＝ 社員全員の働きの合計 ÷ 基準（NPCを入れた日の社員で1.00）。

| 会社 | 効くところ |
| --- | --- |
| カーオーナー・ジンクス・DAIZIN | 売れる量の上限、接客の質 → リピート |
| MAGITA | 生産台数、不良、研究（A1・T1・MOL1・RIMU TAG）の速さ、T1の成功率 |
| RIRU・Ice Smoker | 開発の進み、ゲームの品質（チームの平均スキル）、クランチ（速いが燃え尽きる） |
| テネシス | 審査の力で貸し倒れが減る、運用の力 |
| 求人2社・Dtrade | 売上の上限、システムの安定 |
| 全社 | 事務の力で「その他の経費」が減る |

指数はふつう±15%くらいで動きます。優秀な人が辞める・新人が多い・クランチ明け、で本当に業績が上下します。

### 8.3 給料

- **月給＝年収÷12を毎月25日**にテネシスの口座へ。会社は社会保険などの会社負担も払います（例：テネシスは1人年$7.0M−年収$4.8M）。
- 1人1人の年収は会社の平均の前後にばらつかせ、合計が会社の人件費と合うようにします。
- 今の企業の帳簿は「年収を16に分け、12を毎月・4を6月と12月の賞与」です。年収÷12にすると賞与がなくなるので、「会社が業績予想を超えた年だけ特別賞与」を足すのがおすすめです（§14）。
- 昇給は4月（会社の業績と本人の評価）、昇進は評価と年数で決めます。

### 8.4 離職・転職・定年

- 満足度は、給料が相場より高いか・賞与・残業とストレス・会社の好調・上司・同僚との仲で決まります。満足度が低いほど辞めやすくなります。
- 他社の求人がよければ転職します（スピーディードとシティーワークの社員の取り合い、など）。
- 65歳前後で定年になり、退職金を受け取ります。再雇用やパートで働き続ける人もいます。

### 8.5 経営者NPC

各社の社長・役員もNPCです（社内のベテランから選ばれる）。社長の性格が、業績予想の強気さ・採用の積極さ・研究への投資・配当の多さに少し効きます。社長は業績や年齢で交代し、交代するとニュースになって方針が変わります。

### 8.6 その他の職場

お店・役所・病院・学校・街の外への通勤など、10社以外の職場です。帳簿は持たず、給料は街の外から入ってくるお金として扱います。そこで働く人も、10社の求人があれば応募できます。

### 9.3 株（板・出来高・1日35Mまで）

- NPCの**買いは1日（日本時間9:00区切り）1人$35,000,000まで（手数料込み）**。売りは持っている分まで。

- 出来高・板・歩み値（約定の流れ）を、プレイヤーの投資画面に出せます。
- 配当は、NPCの株主にも持っていた分だけ入ります。

### 9.4 銀行と金利（街の安定装置）

- NPCのお金はほぼテネシスの預金です。自動車ローン・生活ローン・信用の点数・返せないときの貸し倒れがあります。
- **テネシスが毎月、金利を決めます**（テイラー則：金利＝中立の金利＋0.5×（物価上昇−目標）＋0.5×（景気のずれ））。

### 9.5 暴走しないために

- 1か月に使うお金 ＝ 収入×(0.5〜0.95) ＋ 資産×(年1〜5%)÷12。資産が増えれば使い、減れば控えます。
- テネシスの金利、1日35Mの上限、借りられる額、1回のカジノの資金に上限があります。
- 運営サイトで、物価・失業率・平均年収・お金の総量・ジニ係数・貯蓄率を見張り、範囲を外れたら知らせます。NPCの経済だけを止めるスイッチもあります。

## 14. 決めてほしいこと（おすすめつき）
