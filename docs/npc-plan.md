# NPCの街の計画（10万人の住民と社員が回す経済）

> 状態：計画（未実装）。2026-10-31 作成。
> 数値は仮の初期値です。負荷の数字は、手元で作った**使い捨ての試作**（判断の中身は本番より単純）を測ったものです。
> お金の単位はゲーム内の $ です。「35M」＝ $35,000,000。
> 関連：[経済システムの計画](economy-plan.md)・[企業（決算・商品・ビジネス友好度）](handbook/39.md)

## 0. 結論

- **できます。10万人（社員枠4万＋住民6万）を、今と同じ1つのDurable Objectの中で動かせます。** 手元の試作では、10万人が1日に約104万回行動しても、計算は約2秒（本番の中身なら約6秒の見込み）でした。
- **NPCが何万人いても、通信（リクエスト）は1回も増えません。** NPCは本物の端末ではなく、サーバーの中の計算だからです。増やしてよいのは「1時間ごとの見回り」（任意。月720回＝込みの分の0.07%）だけです。
- 今の経済（[handbook/39.md](handbook/39.md)）の「NPCのお客」は、会社ごとの売上をまとめて計算しているだけです。これを**1人1人のNPCの本当の行動**に置き換えます。給料をもらい、買い物をし、車を買い替え、株を売り買いし、カジノで遊び、会社で働きます。会社の売上・株価・業績は、その合計から生まれます。
- 社員枠4万人のうち2万7,750人は、今の10社の社員数ぶんを最初に配属します。残りは**ふだんは働かない住民**として暮らし、会社が採用するときにその中から入社します。社員は勤務・休憩・残業・休みの時間割で働き、その**働きぶりと能力が会社の業績を上下**させます。給料は**年収÷12を毎月**受け取ります。
- 大きな人数を軽く動かす要点は4つです。
  1. 1人1人を「オブジェクト」ではなく、**全員分の数字を並べた列（型付き配列）**で持つ（10万人で約12MB）
  2. 全員を毎分動かさず、**その人の予定の時刻にだけ動かす**（イベント駆動）
  3. 誰かが見たとき・見回りのときに、**止まっていた時間をまとめて追いつく**（結果は毎分動かした場合と同じ）
  4. 保存は「**全員の写し（数時間ごと）＋変化の差分（数分ごとに1行）**」。1人ごとの行は作らない
- 一度に全部は作りません。**社員4万人 → 住民2万人 → 住民6万人**の順に増やします（§14）。

## 2. なぜリクエストが増えないか

| 通信 | NPCで増えるか |
| --- | --- |
| 端末→サーバー（API・WebSocket） | **増えない**。NPCは端末を持たない、サーバーの中の計算 |
| サーバー→端末（WebSocket） | 無料。出来高や売れ筋を画面に送るときだけ（見ている人にだけ） |
| アラーム | **増えない**。6時間ごとの定期処理に相乗り。より滑らかにしたいときだけ1時間ごと（月720回、込みの100万回の0.07%） |
| 別のDurable Objectとの通信 | 使わない（分けると通信がリクエストとして数えられるため、同じオブジェクトの中で動かす） |

増えるのは「計算時間」「メモリ」「保存の量」だけで、どれも込みの分のごく一部です（§12）。

## 4. 1人のNPCが持っているもの

1人ずつのオブジェクトにはせず、全員の同じ項目を1本の列（型付き配列）に並べます。10万人で約12MBです。

| まとまり | 項目 | 大きさ |
| --- | --- | ---: |
| 身元 | 種類・年齢・誕生日・名前の種・住んでいる地区 | 8バイト |
| 性格 | リスク許容・衝動性・倹約・見栄・勤勉・社交・ギャンブル気質・辛抱強さ・学習の速さ・会社への忠誠・車好き・ゲーム好き（各0〜255） | 12バイト |
| 仕事 | 会社・部署・職種・役職・年収・入社日・経験・能力（技術/営業/管理/創作）・やる気・体力・ストレス・残業時間・評価 | 約24バイト |
| お金 | 現金・テネシスの預金・借入・今月の収入・今月の残り予算・今日の投資額（35M上限用）・純資産 | 約48バイト |
| 株 | RIRU・Ice Smokerの株数と平均取得単価、注文中のもの | 約20バイト |
| 車 | 持っている車（最大4台：車種・状態・取得日・買った値段） | 持っている人だけ別の表 |
| 欲求 | 楽しみ・刺激・見栄・安心・移動・人づきあい・休息・達成（各0〜1）と最後に更新した時刻 | 約16バイト |

## 5. 1日の流れ（ルーティーン）

### 5.1 予定の作り方

- 毎朝4:00（日本時間）、その日の予定を1人ずつ作ります。材料は「時間割の型」「曜日（平日・土日・祝日・連休）」「その人の性格と欲求」「サーバーの秘密の鍵から作るその人・その日の乱数」です。
- 予定は「何時何分に何をするか」の短い並びです（1人1日10回前後）。毎分全員を動かすのではなく、**予定の時刻が来た人だけ**が動きます。
- 予定には習慣が入ります（例：「毎朝7時半に株価を見る」「金曜の夜はカジノ」）。くり返すほど習慣は強くなり、しばらくやらないと弱くなります。
- 給料日（毎月25日）・Car Ownerのセール・SHOPのセール（1日5時間）・決算発表（15:00）・新作ゲームの発売日には、その予定に反応する人が増えます。

### 5.2 社員の時間割（例）

| 職場 | 勤務 | 休憩 | そのほか |
| --- | --- | --- | --- |
| テネシス（銀行） | 8:45〜17:30 | 12:00〜13:00 | 月末・四半期末は残業 |
| 事務・IT（シティーワーク・スピーディード・Dtrade・DAIZINの本社） | 9:00〜18:00 | 12:00〜13:00 | 繁忙期に残業 |
| 店舗（ジンクス・カーオーナー） | 早番10:00〜19:00 / 遅番13:00〜22:00 | 1時間 | 土日も営業。休みは平日に週2日 |
| 工場（MAGITA） | 早番6:00〜15:00 / 遅番14:00〜23:00 | 45分 | 需要が多いと残業・休日出勤 |
| スタジオ（RIRU・Ice Smoker） | フレックス10:00〜19:00 | 1時間 | 発売前2か月はクランチ（〜24:00、休日出勤） |

- 通勤（車の人はガソリンが減る）→ 勤務 → 昼休み（スマホで株価を見る・昼ごはんを買う）→ 勤務 → 残業（あれば）→ 帰宅後の自由時間（買い物・カジノ・ゲーム・投資）→ 就寝。
- 有給・病欠（体力が落ちると休みやすい）・祝日・連休があります。

| 種類 | 1日のようす |
| --- | --- |
| 退職者 | 5:30起床・朝の散歩・9:00にニュースと株価・10〜12時に買い物・午後は休息・ときどき昼のカジノ・21:00就寝 |
| 学生 | 平日は8:30〜15:30学校・夕方にバイト・夜はゲーム・1:00就寝。土日は自由 |
| 家事中心 | 朝の家事・10時と16時に買い物・昼に株価・夕方の送り迎えで車 |
| 富裕層 | 9:00起床・昼から株・午後はVIPラウンジ・夜はカジノ（高額）・高級品の買い物 |
| ギャンブル好き | 昼前に起床・午後から夜にカジノ・負けが込むと早くやめる人と、取り返そうとする人 |
| 個人投資家 | 8:30〜15:30は30分おきに株価・決算発表の15:00に張り付く・夜はニュース |

## 6. 考える仕組み（NPCの頭の中）

### 6.1 7つの層

| 層 | 役目 |
| --- | --- |
| 習慣 | 時間割とくり返しの行動。迷わずやること |
| 欲求 | 時間とともに減る8つの欲求。足りないものほど満たしたくなる |
| 目標 | 数か月単位の目標（「次はMAGITA GT-Rを買う」「資産を1億に」「昇進したい」「転職したい」「借金を返す」）。貯金の仕方や残業に効く |
| 選択 | 空いた時間に何をするかを、効用（うれしさ）で選ぶ |
| 学習 | 結果から見通しや戦略を変える。かたよりもある |
| 人づきあい | 職場・近所・趣味のグループの評判や流行に流される |
| 制約 | お金・時間・年齢・1日35Mの投資上限・借りられる額 |

### 6.2 欲求

| 欲求 | 満たす行動 | 減る速さ（半分になるまで） |
| --- | --- | --- |
| 楽しみ | ゲーム・買い物・外出 | 約1日 |
| 刺激 | カジノ・短期の株の売買 | 約2日（ギャンブル気質で短く） |
| 見栄 | 高級車・VIP・高級品 | 約2〜3か月（買った直後は満たされ、だんだん慣れる） |
| 安心 | 貯金・配当株・借金の返済 | 収入と資産で決まる |
| 移動 | 車を持つ・ガソリン | 車がないと大きい |
| 人づきあい | グループでの会話・遊び | 約3日 |
| 休息 | 睡眠・休み | 勤務と残業で減る |
| 達成 | 仕事の成果・昇進・投資の利益 | 約1か月 |

減り方は「満たされ度 × e^(−経過時間/時定数)」で、最後に更新した時刻から必要なときだけ計算します（毎分は計算しない）。

### 6.3 選び方（効用とロジット）

空き時間のたびに、できる行動それぞれの「うれしさ」を足し算します。

効用 ＝ Σ（欲求の不足 × その行動が満たす量）＋ 性格による好み ＋ 習慣の強さ ＋ 周りの流行 − 値段の痛み（収入・資産に対して）＋ ゆらぎ

そのうえで「効用が高いほど選ばれやすい」確率（ロジット：exp(効用/温度) の割合）で選びます。温度は衝動性で、衝動的な人ほど気まぐれに選びます。

### 6.4 性格

リスク許容・衝動性・倹約・見栄・勤勉・社交・ギャンブル気質・辛抱強さ（セールを待てる、長期で持てる）・学習の速さ・会社への忠誠・車好き・ゲーム好きの12項目。種類（§3）ごとに傾向を持たせ、1人1人は乱数でばらつかせます。

### 6.5 学習と、人間らしいかたより

- **見通しの更新**：株の見通しは、新しい情報で少しずつ変わる（変わる速さは学習の速さ）。
- **損失回避**：同じ額なら、得より損を約2.25倍重く感じる。
- **含み損を持ち続ける・利益をすぐ確定する**（気質効果）。
- **勝つと自信過剰**、負けが続くと取り返そうとする（カジノの「熱くなる」状態。冷静な人はやめる）。
- **見慣れ**：高級車を買った直後は見栄が満たされるが、慣れると次が欲しくなる（買い替えの周期）。
- **戦略の乗り換え**：株の戦略（§7.3）は、最近うまくいっている戦略へ少しずつ乗り換える。全員が同じ方向に乗り換えると、行き過ぎ（バブル）と反動が起きる。
- **口コミ**：ゲーム・車・カジノの大当たり・株の噂は、グループの中で広がる。

### 6.6 プレイヤーっぽさ

- **セッション**：自由時間にはゲームを「開く」。1回のセッションは数分〜数十分で、ホーム→スロット→投資→SHOP…と画面を行き来する（性格と欲求で行き先が変わる）。
- **スロットの遊び方**：プレイヤーと同じベットの段階（100〜100,000トークン）から資金に合わせて選び、AUTOのように何回も回す。負け幅・勝ち幅でやめる。熱くなるとベットを上げる人もいる。
- **投資の見方**：プレイヤーの画面と同じチャート（移動平均5・25）や、同じ決算ニュースを見て判断する。手数料（片道1.8%）も同じ。
- **セールへの反応**：Car Ownerの極セールやSHOPのセールに気づいた人が集まり、在庫が減る。
- **NPCは同じルールで遊ぶ**：2,000トークン以上のベットで当たれば勝利金の6%がDtradeへ、トークンの交換は$40,000の手数料、など。

## 7. 行動ごとのしくみ

### 7.1 買い物（SHOP・日用品）

- **ガソリン**：車を持っている人が、通勤や外出で走った分だけ減り、少なくなると給油（ジンクス）。
- **オイル**：約3か月ごと。**修理キット**：車の古さで故障の確率が上がり、壊れたら買う。**エンジン（V1〜V3）**：車好きが買う。
- **セーフティースロット**：カジノの常連が負けた後に買う。
- **日用品**：毎日の生活費（ジンクスの一般商品と、街の外）。
- 値段への反応：セール中は多く買い、品切れなら別の品か後日に回す（在庫は第4段階）。

### 7.2 車（買う・売る・中古）

- **買う理由**：車がない（移動）、見栄（資産に比べて今の車が安い）、古い・故障が多い、セール中。
- **選ぶ車種**：値段・見栄の満たし方・好み（スポーツ/高級）・セールの割引・**MAGITAの値上げ（+$3M）**で選ぶ。高いと借入（テネシスの自動車ローン）も使う。
- **時期**：辛抱強い人はセールを待つ。
- **売る**：買い替え・お金に困ったとき・古くなったとき。Car Ownerの買い取り（今の買い取りルール）→ Car Ownerが中古車として売る。
- 目安：今のカーオーナーの新車販売は年3,785台・$56.6B。これを10万人の本当の購入で作る（1年に約3.8%の人が新車を買う）。

### 7.3 投資（株・預金・外の資産）

- **1日の上限**：NPC 1人が1日（日本時間9:00区切り、プレイヤーの取引日と同じ）に**買える額は手数料込みで$35,000,000まで**。売りは持っている分まで。
- **お金の置き場**：テネシスの預金・RIRUとIce Smokerの株・「外の株式（指数）」の3つ。外の指数があることで、全員が2社の株に集まらない。
- **戦略**（人によって違い、成績で乗り換える）：

| 戦略 | 考え方 |
| --- | --- |
| 積立 | 給料日に収入の一定割合を買う（日付は人ごとに少しずらす） |
| 割安買い | 自分の見積もった価値（決算と配当から）より安ければ買い、高ければ売る |
| 順張り | 上がっているものを買う（移動平均を見る） |
| 逆張り | 下がりすぎたら買う |
| ニュース | 決算発表・業績予想の修正・ヒット/不振に反応（すぐ反応する人と翌日の人がいる） |
| 短期売買 | 1日の中で売り買いする（往復3.6%の手数料で損をしやすく、だんだん減る） |
| 気まぐれ | 理由なく売り買いする |

- **株価のでき方**（§10）：1分ごとにNPCの注文をまとめて、買いと売りの差で株価が動く。
- **配当**：NPCの株主にも、持っていた分だけ配当が入る。
- **プレイヤーとの関係**：プレイヤーの買いは今までどおり会社の新株発行（会社のお金になる）。NPCどうしの売買は株主が入れ替わるだけ（会社の株数は変わらない）。
- 目安：Dtradeの受入手数料（年$5.4B、片道1.8%）に合わせると、NPCの売買代金は1日約$820M（2社の時価総額の約0.9%）。

### 7.4 カジノ（Dtrade）

- スロットの払い戻し率は実測で**約82%**（200万回の試し回し。当たりの確率33%、BIG WIN以上1.6%）。店の取り分は約18%。
- 1回ずつ回さず、セッション（例：35回）の結果を、本物の払い戻しの分布から一度に引きます（大当たりはまれな出来事として別に引くので、まれな大勝ちも起きる）。
- 資金の決め方・やめどき（負けがX%・倍になったら）・熱くなる人・大当たりの噂で客が増える、などを入れます。
- 目安：Dtradeのカジノ収入（年約$9.9B）に合わせると、NPCの賭け金は1日約$150M。
- **月$1Mの使用料**をNPCにもかけると、遊ぶNPCが数千人いるだけでDtradeの売上が何倍にもなるので、NPCにはかけない（または常連だけ）のがおすすめです（§16）。

### 7.5 VIP（DAIZIN）

富裕層が見栄で入会・更新し、資産が減るとやめます。DAIZINの会員収入（年約$8.4B）を、少数の富裕層NPCの本当の会員費で作ります。

### 7.6 ゲーム（RIRU・Ice Smoker）

- ゲーム好き・学生を中心に、ジャンルの好み・値段・評価・**口コミ**で発売後に買う人が増える（バス拡散モデル：最初に買う人と、周りが買ったから買う人）。
- Ice ONLINEなど運営型には、毎月お金を使う人がいる。
- ゲームの売上は世界中なので、**街の住民は世界の縮図**として使います：街で何%の人が買ったか × 世界のゲーム人口 ＝ 世界での販売本数。これで、じわじわ売れる名作や、出だしだけの作品が自然に生まれ、プレイヤーは「街での評判」から株価を予想できるようになります。

### 7.7 バイト（求人2社）

- 学生・フリーター・待機中の社員枠の人が、シティーワークとスピーディードでバイトを探して働く（今のシェアのまま）。
- 雇い主（ジンクスやカーオーナーの店舗など）が給料を払い、給料の25%を求人サイトへ掲載料として払う。
- 求人2社の売上（年$23B）の大半は街の外の企業の求人広告で、街のバイトはその一部です。

### 7.8 銀行（テネシス）

- NPCのお金はほぼすべてテネシスの預金。預金の利息・自動車ローン・生活ローン・返せないときの貸し倒れ（テネシスの与信関係費用）。
- **テネシスの金利**を毎月、物価と景気で動かす（テイラー則：金利＝中立の金利＋0.5×（物価上昇−目標）＋0.5×（景気のずれ））。「金融の絶対支配者」として街の景気を整える役目で、経済が暴走しないための安全装置にもなる。

## 8. 社員（社員枠4万）と会社の業績

### 8.1 配属

- NPCの仕組みを有効にした日に、10社のその日の社員数（今は合計27,750人）ぶんを社員枠から配属します。会社・職種ごとに能力の分布を変えます（銀行とスタジオは専門職が多い、など）。
- 1人1人の年収は会社の平均（例：テネシス$4.8M）の前後にばらつかせ、合計が会社の人件費とぴったり合うように調整します（会社の数字が変わらないように）。

### 8.2 職種

| 会社 | 主な職種 |
| --- | --- |
| テネシス | 窓口・融資審査・資産運用・IT・事務 |
| MAGITA | 製造ライン・品質管理・研究者・技術者・事務 |
| カーオーナー | 営業・整備士・事務 |
| ジンクス | 店舗スタッフ・物流・仕入れ担当・事務 |
| DAIZIN | コンシェルジュ・企画・事務 |
| シティーワーク・スピーディード | 営業・エンジニア・サポート |
| Dtrade | エンジニア・カジノ運営・トレーディング・サポート |
| RIRU・Ice Smoker | プログラマー・アーティスト・プランナー・プロデューサー・QA・運営 |

役職（一般・主任・係長・課長・部長・役員）があり、上司の能力がチームのやる気に効きます。

### 8.3 勤務

§5.2の時間割で働きます。体力は勤務と残業で減り、休憩と睡眠で戻ります。残業は会社が忙しいときと勤勉な人ほど増え（残業代は1.25倍）、ストレスがたまると病欠や離職につながります。

### 8.4 働きぶり → 会社の数字

- 1人の1時間の働き ＝ 職種の能力 × やる気 × 体力 × 経験（入社直後は低い）。
- 会社の**働き指数** ＝ 社員全員の働きの合計 ÷ 基準（有効にした日の社員で1.00）。
- 指数の効き方（例。数字は試作で調整）：

| 会社 | 効くところ |
| --- | --- |
| カーオーナー・ジンクス・DAIZIN | 売上の上限 ×指数^0.5、接客の質 → リピート率 |
| MAGITA | 生産台数 ×指数^0.7、不良（修理キットの需要が増える）、研究（A1・T1・MOL1・RIMU TAG）の速さ ×研究者の指数、T1の成功率（70%前後）に研究者の能力 |
| RIRU・Ice Smoker | 開発の進み ×開発チームの指数、ゲームの品質に「チームの平均能力」（今の固定の`skill`を置き換え）、クランチは速いが燃え尽きる |
| テネシス | 審査担当の能力で貸し倒れが減る、運用担当でその他業務利益がぶれる |
| シティーワーク・スピーディード・Dtrade | 売上の上限、システムの安定（Dtradeのカジノと取引） |
| 全社 | 事務の能力で「その他の経費」が減る |

- 指数はふつう±15%くらいで動きます。優秀な人が辞める・新人が多い・クランチ明け、などで本当に業績が上下します。

### 8.5 給料

- **月給＝年収÷12を毎月25日**にテネシスの預金へ。会社は社会保険などの会社負担（例：テネシスは1人年$7.0M−$4.8M）も払う。
- 今の企業の帳簿は「年収を16に分けて、12を毎月・4を6月と12月の賞与」です。ご希望の「年収÷12」にすると賞与がなくなるので、**会社が業績予想を超えた年だけ、特別賞与を上乗せ**するのがおすすめです（§16）。
- 昇給は毎年4月（会社の業績と本人の評価）、昇進は評価と年数で。

### 8.6 満足度・離職・転職

- 満足度は「給料が相場より高いか」「賞与」「残業とストレス」「会社の好調」「上司」で上下します。
- 月の離職確率 ＝ 会社の基本の離職率 × e^(−k×(満足度−0.5))。
- 辞めた人は待機の社員枠に戻るか、ほかの会社へ転職します。転職が求人2社経由なら**人材紹介料**（初年度年収の約30%）がシティーワーク・スピーディードの売上になります。

### 8.7 採用

- 会社の採用目標（今の企業の計算の`target`）に合わせて、**中途は毎月1日・新卒は4月**に採用します。
- 候補は待機の社員枠・ほかの会社の社員・その年に22歳になった学生。会社は能力の基準と提示年収で選び、本人は年収・会社の評判・やりがいで受けるかを決めます。
- 社員枠4万を使い切ると**人手不足**になり、採用できない・給料が上がる、という本物の動きになります。

### 8.8 余った社員枠

採用されていない社員枠（今は12,250人）は、ふだんは働かない住民と同じ時間割で暮らします（家事・学生・フリーターなど）。バイトをする人もいます。会社の採用があると入社します。

### 9.3 暴走しないための仕組み

- **テネシスの金利**（§7.8）で景気を整える。
- **上限**：1日35Mの投資、借りられる額、1回のカジノの資金。
- **監視**：運営サイトに物価・失業率・平均年収・お金の総量・ジニ係数・貯蓄率を出し、決めた範囲を外れたら運営に知らせる。おかしいときはNPCの経済だけを止めるスイッチ。

## 10. 株価をNPCの売買で作る

- 今の株価 ＝ 会社の価値の中心 × 1秒ごとの揺れ × 市場の気分 × プレイヤーの注文の影響、です（[handbook/37.md](handbook/37.md)）。
- これを、中心と気分の部分を**NPCの売買**に置き換えます。
  - 1分ごとに、その1分のNPCの注文（買いと売り）をまとめる。
  - 買いと売りの差 ÷ 市場の厚み（RIRU $40M・Ice Smoker $150Mで1%、今と同じ）で、次の1分の株価が動く。
  - 割安買いの人は「この値段なら売る/買う」という注文を置いておくので、行き過ぎると反対の注文が増えて戻る。
  - 1秒ごとの細かい揺れは今までどおり。
- 決算発表や業績予想の修正は、NPCの見通しを変えるニュースになり、反応の速い人から順に売買するので、**発表直後に動いて数日かけて落ち着く**本物らしい動きになります。
- **出来高**（NPCとプレイヤーの売買の量）をチャートに出せます。
- 公平さ：NPCの判断は秘密の鍵から作る乱数を含むので、プレイヤーが「25日にNPCが積立で買う」を狙い撃ちしにくいよう、日にちや量をばらつかせます。

## 11. 技術の設計

### 11.1 データの持ち方

- 全員の同じ項目を1本の型付き配列にする（例：預金は`Float64Array(100000)`）。JavaScriptのオブジェクトを10万個作らない（メモリとガベージコレクションが重くなるため）。
- 保存はSQLiteに：
  - **写し**：全部の列をまとめたバイト列を、1行2MB以下の塊に分けて数行（10万人で約12MB＝約12行）。6時間ごとに書き直す。
  - **差分**：前の保存から変わったところ（誰の・どの項目が・いくつに）を、数分ごとに**1行**にまとめて書く。
  - 起動したら「最新の写し＋その後の差分」を読めば、止まる直前と同じ状態に戻る。
- 1人ごとの行は作らない（10万行の書き込みを避ける）。今の`users`表にも入れない。

### 11.2 時計とイベント

- 1つの時計で、株（1秒ごと）・NPC（1分ごと）・会社（1日ごと）を順番に進めます。
  - 1分：その分に予定のある人が行動 → 株の注文をまとめる → 次の分の株価に反映。
  - 1日の終わり（日本時間9:00）：NPCの1日の集計（会社ごと・商品ごと）を会社の1日の締め（`server/core/corp-model.js`）に渡す → 採用・昇給などを翌日に反映。
  - 毎朝4:00：その日の予定。25日：給料。
- 予定は「分ごとの箱」に入れ、1時間分ずつ作ります（1日分を一度に作るとメモリが約15MB増えるため）。

### 11.3 乱数

1日1回、サーバーの秘密の鍵から（`keyFrom(secret, 'npc')`）その日の鍵を作り、そこから1人ずつの速い乱数を作ります。同じ日・同じ人は何度計算しても同じ結果で、鍵を知らなければ予想できません。

### 11.4 追いつきと待ち時間

- 誰かが見たとき（株・お店・運営サイト）、6時間ごとの定期処理（入れれば1時間ごと）のときに、止まっていた時間をまとめて計算します。
- NPCに関わる操作（例：最後の1台の車を買う）の前には、その時刻まで追いつけてから判断します。6時間分の追いつきは10万人で約1.5秒の見込み（1時間ごとなら約0.25秒）。
- 長い計算は数十ミリ秒ずつに区切り、間にほかの人のスピンやチャットを通します。
- NPCが要らない操作（チャットなど）では、NPCのデータを読み込みません。

### 11.5 今の仕組みとのつなぎ方

| 今の仕組み | つなぎ方 |
| --- | --- |
| `server/core/corp-model.js`（会社の1日） | NPCの購入をプレイヤーのお金と同じ流れで受け取る。今の「お客の需要」は「街のNPC＋街の外」に分け、外の分は残す。社員の給料は1人1人の年収の合計に、働き指数を売上・経費・研究・品質へ |
| `server/core/stocks.js`（株価） | 1分ごとのNPCの注文の差を、今のプレイヤーの注文の影響と同じしくみで株価に入れる。出来高をローソク足に |
| `server/core/corp.js`（保存と表示） | NPCの集計を1日1行で記録、運営サイトの表示 |

| 人数を増やす途中 | NPC 1人を「何人分」と数える重み（人数が少ない間は1人で数人分）。10万人で1人分に |

### 11.7 テスト

- 1分ずつ進めても、6時間まとめて進めても、同じ結果になる。
- 写し＋差分から戻した状態が、止まる前と1バイトも違わない。
- お金がどこからも湧かない（NPC・会社・テネシス・外の世界の合計が帳簿と合う）。
- 1日35Mの上限、未成年はカジノ・投資なし。
- 10万人で1日の計算時間・メモリが上限以内（負荷の試験）。
- 失敗した操作（トランザクションの取り消し）でNPCの状態が残らない。

## 12. 負荷の見積もり（試作の実測）

手元の試作（Node.js、使い捨て）で、予定づくり・行動の選択（欲求の減り方・8つの行動の効用・ロジットの選択）・買い物・カジノ・株の注文と1分ごとの株価・給料を測りました。本番は考える中身が多いので、**計算時間は約3倍**と見込みます。

| 人数 | 1日の行動 | 1日の計算（試作） | 1日の計算（本番の見込み） | 6時間の追いつき（見込み） | 列のメモリ・写し | 差分/日 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 1万 | 10.4万回 | 0.22秒 | 約0.7秒 | 約0.2秒 | 1.2MB | 2.5MB |
| 5万 | 51.8万回 | 0.92秒 | 約2.8秒 | 約0.7秒 | 5.8MB | 13.5MB |
| **10万** | **103.6万回** | **1.95秒** | **約6秒** | **約1.5秒** | **11.5MB** | **24.9MB** |
| 20万 | 207.3万回 | 3.87秒 | 約12秒 | 約2.9秒 | 23.1MB | 49.4MB |

- 1回の行動は約1.4マイクロ秒。人数に比例して増えるだけで、急に重くなることはありません。
- メモリ：今のサーバーは起動後に約15MB。10万人の列（約12MB）と1時間分の予定（約2MB）を足しても、Durable Objectの上限128MBに十分収まります。
- 保存：差分は数分ごとに1行（月最大約8,600行）、写しは1日4回×約12行（月約1,400行）。日ごとの統計を足しても**月4万行程度で、込みの5,000万行の0.1%未満**。保存量は30MB前後（込みの5GBの1%未満）。
- 動いている時間：1日約6秒の計算は、込みの40万GB秒の0.01%未満。
- リクエスト：NPCからは0。1時間ごとの見回りを入れても月720回（込みの100万回の0.07%）。

## 13. 画面

### 13.1 プレイヤー（どれも任意。ラベルと数字だけ）

- 投資：**出来高**、買いと売りの勢い、（あとで）板（NPCの注文の並び）。
- Car Owner：今週の売れ筋、（在庫を入れたら）残り台数、中古車。
- SHOP：人気の品。
- 「街」：人口・平均年収・失業率・景気などの数字。

### 13.2 運営サイト

- **「住民」アプリ**：名前・会社・資産で検索、1人の性格・欲求・今日の予定（時間割）・最近の行動・お金の動き・株・車・職歴。
- 企業の公式サイトに**「社員」タブ**：部署ごとの人数、能力の分布、残業、満足度、離職、採用の状況、給料の分布、働き指数と業績への効き方。
- **「街」ダッシュボード**：物価・失業率・平均年収・お金の総量・ジニ係数・テネシスの金利・時間帯ごとの活動量。
- 開発者用のつまみ：人数、行動のしやすさ、NPCの経済の一時停止。

## 15. リスクと対策

| リスク | 対策 |
| --- | --- |
| 計算が重くなる | 予定の時刻にだけ動かす・区切って計算・人数を段階的に増やす・重すぎたら自動で人数の重みを上げて計算を減らす |
| メモリが足りない | 列で持つ・予定は1時間分ずつ・使わない操作では読み込まない |
| 経済の暴走（インフレ・お金の偏り・倒産の連鎖） | 消費のルール・テネシスの金利・上限・監視・NPCの経済だけ止めるスイッチ |
| 計算のずれ（同じにならない） | 決まった乱数・決まった順番・追いつきの一致テスト |
| プレイヤーが不利（限定車の取り合い） | プレイヤーの優先枠、品切れの予約 |
| NPCの行動を読まれる | 秘密の鍵の乱数、日付や量のばらつき |
| 作るものが大きい | 段階ごとに出す。最初はプレイヤーに見えない部分から |

## 16. 決めてほしいこと（おすすめつき）

1. **人数の増やし方**：おすすめは「社員枠4万 → 住民2万 → 住民6万」。社員から入れると、会社の業績と給料がすぐ本物になります。
2. **給料と賞与**：「年収÷12を毎月25日」にすると今の賞与（年収の4/16を6月と12月）がなくなります。おすすめは「年収÷12を毎月＋会社が業績予想を超えた年だけ特別賞与」。
3. **住民のバイト**：学生・フリーター・待機の社員枠の人が求人2社でバイトをするか。おすすめは「する」（求人2社の売上の一部が本物になる）。
4. **NPCのカジノ使用料（月$1M）**：おすすめは「NPCにはかけない」（かけるとDtradeの売上が何倍にもなる）。
5. **NPCの株の売買**：NPCどうしの売買（会社の株数は変わらない）、プレイヤーの買いだけ新株、のままでよいか。おすすめは「そのまま」。
6. **在庫の取り合い**：車やSHOPの在庫をNPCと取り合うか。おすすめは「取り合う、ただしプレイヤーの優先枠つき」。
7. **NPCを画面に出すか**：おすすめは「プレイヤーには数字だけ（出来高・売れ筋・街の数字）、名前や1人1人は運営サイトだけ」。
8. **税金と年金の出どころ**：おすすめは「最初は『外からの収入』で代用し、あとで市役所（税金と年金）を作るか決める」。
9. **1時間ごとの見回り**：おすすめは「入れる」（月720回で、6時間分の追いつきがなくなり、運営サイトの数字も1時間以内に新しくなる）。
10. **未成年のNPC**：おすすめは「18歳以上だけカジノと投資」。
