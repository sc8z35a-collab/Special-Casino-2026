## 実装で変えたこと

- **5つの区は本体の部屋の中で動かす**：1分の計算が5万人で約2〜3ミリ秒・メモリ約40MBに収まったため、区ごとのDurable Objectは作らず、本体の中で5つの区を動かしている（区へ分ける形は、重くなったときの次の段階として残す）。
- **頭の深さ**：1人1日の計算は計画の約500msより軽い（判断はユーティリティAI、大きな判断は1年先を256通り＝標準。深い1,024・いちばん深い4,096）。思い出は最近16件と人生の本（有名な人）、人間関係は12人。人の列は約400バイト×5万人。
- **見回りは1分ごと**（30秒ごとへの自動切り替えは入れていない）。
- **国の外とのお金**：入るのはプレイヤーのお金と、国が始まる前の売掛金の回収だけ。出るのはMAGITAの材料の輸入（とプレイヤーへの支払い）だけ。会社の経費は国の中の会社（MAGITAの設備・Dtradeのデータセンター・求人サイトの広告・ジンクスのゲーム販売）と地元の商店へ流れる。
- **テネシスの本業**：国の古い借金（国債$3T・年1%）・住宅ローン・口座管理手数料・テネシス・モバイル。外の貸出と預金は国が始まった日に整理した。
- 市民の購買は、国が始まった時点で各社の今の売上の規模になるよう一度だけ合わせ、そのあとは市民しだい（固定の式は使わない）。

## 0. 結論

- **5万人を、1人1人ずっと深く動かせます。** 街を**5つの地区**（1地区1万人）に分け、地区ごとに専用のDurable Object（サーバーの部屋）で動かします。今のサーバー（本体）は、**国**・10社・市場・在庫・プレイヤーを受け持ち、**1分ごとに5地区とやり取り**します。
- **1人あたりは第2版の数倍**です。

  | | 第2版（20万人） | 第3版（5万人） |
  | --- | --- | --- |
  | 1人の容量 | 約790バイト〜2.5KB | **約38KB**（メモリ約8KB＋保存約30KB） |
  | 思い出 | 32件 | **最近1,000件＋倉庫2,000件＋人生の本** |
  | 人間関係 | 30人 | **300人**（親しい20人は「心のモデル」つき） |
  | 1日の判断 | 40回（1回 約4µs） | **約100回＋会話とメッセージ15回**（1回 平均約4ms、大きな判断は約1秒） |
  | 1人1日の計算 | 約0.2ms | **約500ms**（標準。深くすると最大約1.5秒） |
  | やり取り | 1分ごと・小さな集計 | 1分ごと（余裕があれば30秒ごと）・**運ぶ量は約5倍**（街ライブ用の全員の今・地区をまたぐ会話・注文・組合と運動） |

- 使用量（NPCが使う分。標準の深さ）：

  | 使用量 | ご指定の上限 | 見込み |
  | --- | ---: | ---: |
  | リクエスト（Durable Objects） | 8〜9割 | 約28%（余裕があれば30秒ごとにして約54%） |
  | 書き込み行 | 8〜9割 | 約49% |
  | 保存量 | 8〜9割 | 約70%（1年目） |
  | 動いている時間（CPU） | 8〜9割 | 約25%。**ゲーム全体で75%になるまで自動で頭を深くする**（最大 約72%） |
  | 読み取り行 | 8〜9割 | 約1〜3% |

  今のゲーム自身も使います（本体を起こしておく見回りが最大で月25万回＝25%、遊ばれている間の本体の動いている時間）。だから**NPCは「残りの枠」で動き**、考える深さとやり取りの間隔を毎晩自動で決めます（§2）。
- **18歳以上だけの街**です。平均寿命は80歳。亡くなった人の枠は、**18歳の新しい人生**として始まり直します（5万人を保つ）。
- **国**があります。10社の法人税・社会保険料、個人の所得税・住民税・年金・保険料がすべて国（と地区）に入り、国は年金・医療・失業手当・生活保護・公務員・公共事業（10社への発注）に使います。**年金は現実と同じしくみ**（18歳から納め、60歳から受け取る。額はこの世界に合わせる）。
- **政治**：5つの地区で、それぞれ**区長を1人選挙で選び**、区長の公約と力が地区の景気・活気を上下させます。5人の区長が**街の議会**になって、国の予算と制度を決めます。
- **労働**：10社に**労働組合**があり、**春闘**で賃上げを求め、状況がそろえば**ストライキ・デモ・大量退職**が起きます。結果は会社の帳簿（給料・社員数・売上）に本当に効きます。
- **市民が制度を変える**：不満や疑いを持った人が話し、投稿し、署名を集め、デモをし、規模が大きくなれば**市民投票**で、**国・企業・経済の決まりを、運営が決めた範囲の中で**変えられます（税率・年金・最低賃金・MAGITAの値上げやDtradeの手数料の上限など）。
- **街ライブ**：プレイヤーが、5万人が今どこで何をしているかを地図の上の点で見られ、区長・選挙・ストライキ・署名・国の財布もリアルタイムで見られるアプリです。

## 2. 使用量の予算

込みの分（Workers Paid、1か月）：Durable Objectsのリクエスト100万回・動いている時間40万GB秒・読み取り250億行・書き込み5,000万行・保存5GB。1か月は30日（43,200分）で数えます。

### 2.1 今のゲームが使う分（前提）

- **本体を起こしておく見回り**（`server/cloudflare/awake.js`）：遊ばれている間、8秒ごと。月に最大25万回（リクエストの25%）。
- **本体の動いている時間**：遊ばれている時間で決まります。今の設計の考え方では、本体1つが1か月ずっと起きていても約32万GB秒（約81%）です。
- プレイヤーのAPI（スロット・投資・チャットなど）のリクエストと書き込み。
- これらは月ごとに違うので、**第0段階で今月の実際の数字**（運営サイトの「サーバー」タブ、トークンがあればCloudflareの集計）を確かめ、NPCは毎晩「残りの枠」に合わせて動きます（§2.5・§2.6）。

### 2.3 リクエストは「地区の数×回数」で決まる

| 構成 | 1分ごと | 30秒ごと | 2分ごと | 5分ごと |
| --- | ---: | ---: | ---: | ---: |
| 5地区×1万人（第3版） | 約28% | 約54% | 約15% | 約7% |
| 10地区×5,000人（参考） | 約50% | 約97% | 約26% | 約12% |

- 呼び出しの回数は人数ではなく**地区の数**で決まります。1回の呼び出しで運ぶ量（データの大きさ）は料金に関係ないので、**やり取りの中身は約5倍**に増やしても、リクエストは増えません。
- 地区を少なく大きくした分、今のゲームの見回り（最大25%）と合わせても余裕があります。余裕がある月だけ、自動で30秒ごとにします（街ライブと株の反応が速くなる）。

### 2.4 1人あたりの計算と、考える深さ

| 深さ | 中身 | 1人1日の計算 | 動いている時間 |
| --- | --- | ---: | ---: |
| 浅い | 先読みは大きな判断だけで短く・思い出は最近の分だけ | 約100ms | 約6% |
| **標準** | §9のすべて（先読み1,024通り×1年） | 約500ms | **約25%** |
| 深い | ふつうの判断でも先読み・心のモデルを二段で・思い出の倉庫をすべて探す | 約1秒 | 約48% |
| いちばん深い | 先読み4,096通り・毎晩1週間の計画と家族全員の計画を作り直す | 約1.5秒 | 約72% |

- 計算：（1人1日の計算×1万人＋地区の決まった仕事 約300秒）×5地区×0.125GB×30日。例：標準は（5,000秒＋300秒）×5×3.75＝約9.9万GB秒。
- 1回の呼び出しの計算は、標準で平均約3.7秒（にぎやかな時間は約9秒）、いちばん深いで平均約10秒（同 約26秒）。1回の上限時間は設定で延ばします（最大5分）。

### 2.5 自動調整（残りの枠で動く）

- **毎晩**、振り返りのあとに、今月のゲーム全体の見込みを見ます。
- **考える深さ**：動いている時間の見込みが75%より低ければ1段深く、高ければ1段浅く。
- **やり取りの間隔**：リクエストの見込みが60%より低ければ30秒ごと、70%を超えたら1分ごと（さらに多ければ§2.6のブレーキ）。
- 目標（75%・60%）と線（85%）は運営サイトで変えられます。

### 2.6 使用量の自動ブレーキ

- **見るもの**：NPCが自分で使った量（呼び出しの回数・書き込んだ行・保存量・計算の時間）は正確に数えます。ゲーム全体の使用量は、今の運営サイトの「サーバー」タブの見積もりと、70%・90%の通知（`server/core/usagealert.js`）、Cloudflareの集計（トークンがあれば）で見ます。
- **予測**：今月の使用量 ×（月の日数 ÷ 経過日数）。

| 段階 | 条件（どれか1つの項目の月末の見込みが） | NPCの動き |
| --- | --- | --- |
| 0 | 75%未満 | 標準。深さと間隔は自動調整（§2.5） |
| 1 | 75〜80% | 1分ごとに戻し、深さを1段下げ、上げない。会話の記録を半分に |

## 3. 全体のしくみ（本体と地区）

### 3.1 役割分担

| 部屋 | 受け持つもの |
| --- | --- |
| **本体**（今のサーバー） | プレイヤー全員・**国の帳簿と制度**・10社の帳簿（`server/core/corp-model.js`）・株の板と約定・車とSHOPの在庫・求人と社員名簿・組合と春闘・街の議会・市民投票・ニュース・街ライブの配信・地区とのやり取りと時計 |

- 引っ越し（§4.5）で、人は地区から地区へ移れます（1人分の約38KBを本体を通して運ぶ）。

### 3.2 1分ごとのやり取り（運ぶ量は第2版の約5倍）

| 本体 → 地区 | 地区 → 本体 |
| --- | --- |
| 今の値段（株・車・SHOP）とセール、在庫 | その1分の買い物（商品ごとの数と金額） |
| ニュース（決算・新作・値上げ・ストライキ・選挙・議会の決定） | カジノの結果（賭け金・払い戻し・手数料） |
| 国の決まり（税率・保険料・年金・最低賃金・手当） | 納めた税と保険料・受け取った年金と手当 |
| 求人・面接の結果・内定・組合の呼びかけ | 応募・退職・転職の届け・組合への加入・ストライキへの参加 |
| 給料・配当・約定の結果・ローンの審査結果 | 株の注文（指値・成行）とキャンセル |
| 他の地区からの会話・メッセージ・署名・運動の広がり | 地区をまたぐ会話・メッセージ・署名・デモの参加者 |

- **本体を待たせない**：地区は、呼ばれたら**前の1分の結果をすぐ返し**、この1分の計算は返事のあとで行います。本体の待ち時間は約0.05秒で済みます。この形がCloudflareで使えるかは第0段階で確かめます。使えないときは、本体が地区を待つ時間を見込みに足します（標準で+約5%、いちばん深いで+約14%の動いている時間。ただしプレイヤーがいて本体がもともと起きている時間は重ならない）。

### 3.3 順番と、同じ結果になること

- 1分（m分目）ごとに、①本体がm分目の状態を送る → ②地区はm−1分目の結果を返し、m分目に予定のある人を動かす → ③本体は受け取った行動を反映する（在庫は「プレイヤーが先、NPCは決まった順」）→ ④NPCの株の注文をその1分でまとめて約定し、次の1分の株価に反映。
- NPCは「1〜2分遅れで値段を知り、1〜2分遅れで動く」ので、株の反応にも人間らしい遅れが出ます。
- 日本時間9:00（UTC 0:00）に、その日の地区の集計で会社の1日と国の1日を締めます（今の企業の仕組みと同じ）。
- 乱数はサーバーの秘密の鍵から作ります。地区は受け取ったメッセージを記録しているので、同じ計算をやり直すと同じ結果になります（止まったときの復旧にも使います）。

### 3.5 うまくいかなかったとき

- 地区が答えないときは、本体はその地区を待たずに進みます。次の呼び出しで、地区は止まっていた分をまとめて計算して返します（番号付きで、同じものが二重に入らない）。
- 地区の計算が1分に収まらなくなったら、自動で深さを1段下げます。

### 3.6 メモリ（1部屋128MB）

- 1万人×約8KB＝約80MB＋作業用・プログラムで約25MB＝**約105MB**。保存に置く分（1人約30KB）はメモリに入れず、考えるときに必要な行だけ読みます（読み取りは込みの分がとても多いので、ここで使います）。
- 第0段階で本物に近い形で測り、足りなければ「最近の思い出」を少し減らします（倉庫と人生の本はそのまま）。
- 1人ずつのオブジェクトにはせず、全員の同じ項目を1本の列（型付き配列）に並べます。

- **国債**：国の収入が足りない年は国債を出し、テネシスと積立金が買います。借金が増えすぎると金利が上がり、不満も増えます。

### 5.6 公務員と公共事業

- **公務員**：役所・学校・病院・警察で約1,500人。給料は国から（公務員にも組合がある）。
- **公共事業**：国と地区が10社に発注します。例：シティーワークに職員の採用、MAGITAに公用車、ジンクスに備品、Dtradeに国のシステム、カーオーナーに公用車の整備。会社の売上の新しい流れになります。

### 5.7 国が決めること（つまみ）

| 分野 | つまみ | はじめ | 範囲（運営が決める） |
| --- | --- | --- | --- |
| 税 | 所得税の全体の上げ下げ・住民税・消費税・相続税 | 上の表 | 所得税±5ポイント・住民税6〜12%・消費税0〜15% |
| 年金 | 保険料率・受け取る年齢・額の見直しの強さ | 18.3%・60歳・標準 | 15〜22%・55〜65歳・±10% |
| 働く | 最低賃金・残業の上限 | 年$1.8M相当・月45時間 | 年$1.2M〜$2.4M・30〜80時間 |
| 保障 | 失業手当・生活保護・医療の負担 | 上の表 | ±30% |
| 予算 | 公務員・公共事業・地区への交付金の配分 | | 予算の範囲 |
| 企業 | MAGITAの値上げ（$3M）の上限・Dtradeの手数料（勝利金6%・交換$40K・株1.8%）の上限・求人サイトの掲載料（25%）の上限 | 今のまま | 今の半分まで下げられる |

- 変わった決まりは、ニュースで知らせて**翌月1日から**。同じつまみは1四半期に1回まで。
- 企業の上限が下がると、プレイヤーの手数料や車の値段も同じだけ変わります（§16で、プレイヤーに効く変更をどうするか決めてください）。

## 6. 政治（区長・議会・運動・市民投票）

### 6.1 区長選挙（地区ごとに1人）

- **任期6か月**。4月と10月に選挙（2週間の選挙運動のあと、日曜日に投票）。
- **立候補**：野心・外向性・評判・管理のスキルが高いNPCが、2〜4人立候補します。今の区長も再選をめざします。
- **公約**：減税（住民税）・商店街の応援・会社を呼ぶ・公共事業・お年寄りと失業者への福祉・お祭りとイベント・治安・家賃の補助などから、地区の不満と自分の考えで選びます。
- **選挙運動**：演説・街の声への投稿・支持者の口コミ（会話とメッセージで広がる）・討論会。
- **投票**：1人1人の大きな判断です。公約が自分の得になるか・自分の考えに合うか・候補者を信頼できるか・友達や家族の意見・今の区長の成績で決めます。投票に行くかどうかも、関心・気分・天気で変わります（投票率は地区で違う）。
- **結果**：得票率・投票率・地区ごとの年齢別の票をニュースと街ライブに出します。

### 6.2 区長が地区に与える影響

区長は、地区の**景気・活気**を上下させる要因の1つです。

| 区長がすること | 効き方 |
| --- | --- |
| 地区の財布（住民税・法人の地方税・国の交付金）の使い道を決める | 公約どおりに配分 |
| 減税 | 手取りが増えて買い物が増える。財布は減る |
| 商店街の応援・お祭り | 買い物と気分（活気）が上がる |
| 公共事業 | 10社への発注で、その会社と社員がうるおう |
| 福祉 | お年寄りと失業者の不安と不満が減る |
| 会社を呼ぶ・家賃の補助 | 人が引っ越してくる |

- 効き方は、区長の**管理の力**で大きくなり、**誠実さ**が低いと汚職（不祥事）が起きることがあります。
- **支持率**を毎月出します。支持率が低いと、リコール（解職）の署名が始まることがあります（地区の3分の1の署名でリコールの投票）。

### 6.3 街の議会（5人の区長）

- 5人の区長が**街の議会**です。毎月1回、国の予算と制度のつまみ（§5.7）を、運営が決めた範囲の中で多数決（3票）で決めます。
- 区長は、自分の地区の得になるように動きます（川沿い区は交付金を増やしたい、工業区は法人税を下げたい、など）。区長どうしの取引（「交付金に賛成するから、公共事業に賛成して」）もあります。
- 議会の決定はニュースになり、国民の満足と不満に効きます。

### 6.4 不満から運動へ

1. **不満**：1人1人が、テーマごとの不満を持ちます（税が高い・年金が足りない・物価・給料が安い・格差・MAGITAの値上げ・Dtradeの手数料・区長への不信など）。自分の体験（払った額・損・失業）・ニュース・友達の話・性格（正義感・開放性）・制度への信頼で上下します。
2. **話す・投稿する**：不満は会話と街の声で広がります（うわさや間違いも混ざる）。
3. **リーダーが生まれる**：不満が強く、外向的で、知り合いの多い人が呼びかけ人になります。
4. **署名**：呼びかけ人が署名を始め、メッセージと口コミで集まります。
5. **集会・デモ**：参加するかは、まわりがどれだけ参加しているかで決まります（人ごとに「何割が参加したら自分も行く」というしきい値がある。小さな集まりが一気に大きくなることがある）。デモの日は、その地区の店や会社の動きが少し止まり、ニュースになります。
6. **ボイコット（不買運動）**：会社への不満なら、その会社の商品を買わない運動になり、売上に本当に効きます。
7. **反対の運動**：今の決まりで得をしている人たちは、反対の署名や投稿をします。
8. **会社と議会の対応**：会社は値下げ・譲歩・広告で、議会は先に決まりを変えて、運動をしずめようとすることがあります。

暴力や暴動は扱いません（署名・集会・デモ・ストライキ・ボイコット・投票だけ）。

### 6.5 市民投票で制度を変える

| 種類 | 始まる条件 | 決まる条件 | 変えられるもの |
| --- | --- | --- | --- |
| 国の市民投票 | 60日以内に全市民の10%（5,000人）の署名 | 投票率40%以上で賛成が過半数 | §5.7のつまみ（範囲の中で） |
| 地区の住民投票 | 60日以内に地区の20%の署名 | 投票率40%以上で賛成が過半数 | 地区の財布の使い道・住民税（範囲の中で） |
| リコール | 60日以内に地区の3分の1の署名 | 投票率40%以上で賛成が過半数 | 区長を辞めさせて選挙をやり直す |

- 投票の2週間前から、賛成と反対の運動があり、1人1人が大きな判断として投票します。
- 決まった変更は翌月1日から。運営はいつでも範囲を変えたり、つまみを固定したりできます（ゲームのバランスを守るため）。

### 6.6 プレイヤーとのかかわり

- プレイヤーは街ライブで、選挙・議会・署名・デモ・投票をリアルタイムで見られます。
- 決まった変更は、プレイヤーにも効きます（MAGITAの値上げの上限・Dtradeの手数料など。§16で決めてください）。
- プレイヤーが署名や投票に加われるかも、§16で決めてください（おすすめは「最初は見るだけ」）。

## 7. 労働（組合・春闘・ストライキ・大量退職）

### 7.1 労働組合

- 10社と公務員にそれぞれ組合があります。加入率は会社で違います（工場のMAGITAは高く、IT系は低い）。
- 組合員が組合の代表を選びます。代表の性格（強気・話し合い重視）で動き方が変わります。

### 7.2 春闘（2〜3月）

1. **要求**：組合は、物価の上がり方・会社の利益の伸び・他社の給料・組合員の不満から、賃上げ率を決めて要求します。
2. **回答**：会社（社長のNPC）は、会社の帳簿（利益・業績予想・現金）・人手の足りなさ・社長の性格から回答します。
3. **交渉**：何回かやり取りします（相手の考えを推測して、譲る・粘る）。
4. **妥結**：決まった賃上げは4月から給料に入り、会社の人件費が上がります（`corp-model.js` に会社ごとの賃上げ率を渡す）。ニュースになり、株価にも効きます。

### 7.3 ストライキ・デモ・大量退職

- **ストライキ**：交渉がまとまらず、組合員の不満が強く、組合の団結が強いとき。ストライキの日は、その会社の仕事が一部止まり（売上と生産が減る）、参加した人の給料もその分出ません。世の中の応援（街の声）が多いほど、会社は譲りやすくなります。
- **デモ**：組合と市民の運動（§6.4）が合わさることもあります（最低賃金の引き上げ、など）。
- **大量退職**：多くの社員の満足度が低く、ほかに良い求人があるとき、同僚の退職が次の退職を呼び、一度にたくさん辞めます。社員数と働き指数が下がり、会社は急いで採用します（求人サイトがうるおう）。
- **会社の対応**：賃上げ・賞与・働き方の改善・新しい人の採用。うまくいかないと社長が交代することもあります。

### 7.4 仕事のそのほか

- **求人から入社まで**：会社が採用の目標（今の企業の計算の`target`に、需要と退職を加える）から求人を出し、18歳以上の誰でも応募します（応募は大きな判断）。求人2社（シティーワーク・スピーディード）経由なら、入社が決まると人材紹介料（初年度年収の約30%）が求人サイトの売上になります。
- **勤務と働き指数**：1人の1時間の働き＝職種のスキル×やる気×体力×経験×上司の力×同僚との仲。会社の働き指数＝社員全員の働きの合計÷基準。MAGITAなら生産と研究（A1・T1・MOL1・RIMU TAG）の速さ、RIRU・Ice Smokerなら開発の進みと品質、テネシスなら審査と運用、店なら売れる量の上限と接客、に効きます。ふつうは±15%くらいで動きます。
- **給料**：**月給＝年収÷12を毎月25日**。天引き（所得税・住民税・本人の保険料）のあとの手取りがテネシスの口座へ。昇給は春闘と本人の評価で4月、昇進は評価と年数で。
- **離職・転職・定年**：満足度が低いほど辞めやすく、他社の求人がよければ転職します。60歳で定年、退職金を受け取り、65歳まで再雇用。
- **経営者NPC**：各社の社長・役員もNPCです。社長の性格が、業績予想・採用・研究への投資・配当・春闘の回答に効きます。社長は業績や年齢で交代し、ニュースになります。

## 9. 頭の中（AIのように考える）

生成AIではなく、ゲームのAIの技術（数と規則）を組み合わせて、1人1人が自分の考えで動きます。

### 9.1 1日の流れ

1. **朝**：1週間の予定から、その日の時間割を、体調・天気・気分・約束で直す。
2. **小さな判断**：食べる・休む・移動する。習慣でほぼ決まる。
3. **ふつうの判断**：自由時間が来るたびに、今いちばんやりたいことを選ぶ（§9.4）。
4. **会話とメッセージ**：家族・友達・同僚・組合や運動の仲間と話し、影響し合い、約束し、交渉する（§9.13）。
5. **大きな判断**：車・転職・大きな投資・ローン・引っ越し・結婚・投票・ストライキへの参加・立候補。1年先まで先読みして、家族と相談して決める（§9.5）。
6. **グループの動き**：組合・運動・選挙の陣営・投資仲間の集まり（§9.10）。
7. **夜**：振り返って、思い出を整理し、教訓を作り、明日の計画を立てる（§9.12）。
8. **週末・月末**：1週間の予定を作り、家計を家族で見直す。

### 9.2 判断の種類と、かける計算（標準の深さ）

| 種類 | 1人1日 | 1回の計算 | 中身 |
| --- | ---: | ---: | --- |
| 小さな判断 | 約50回 | 約0.5ms | 習慣と欲求で、ほぼ決まった流れ。たまに気まぐれ |
| ふつうの判断 | 約30回 | 約5ms | 50の行動×24の材料、思い出（倉庫も）、自分の学習、親しい人の気持ち |
| 会話とメッセージ | 約15回 | 約4ms | 話題選び・意見・うわさ・約束・説得・交渉（相手の分も） |
| 大きな判断 | 平均0.15回（週に1回くらい） | 約1秒 | 1,024通りの未来×1年の先読み、家族との相談、人生の本 |
| グループの動き | 約2回 | 約10ms | 組合・運動・選挙の陣営での役割と行動 |
| 夜の振り返り | 1回 | 約70ms | 思い出の整理・教訓・見通しと好みと考えの更新・明日の計画 |
| 週・月の振り返り | （1日あたり） | 約25ms | 目標の木・家計・人間関係・政治の考えの見直し |
| **合計** | **約100回＋会話15回** | **約500ms** | |

### 9.3 欲求と感情

| 欲求 | 満たす行動 |
| --- | --- |
| 楽しみ | ゲーム・買い物・外出・お祭り |
| 刺激 | カジノ・短期の株の売買 |
| 見栄 | 高級車・VIP・高級品 |
| 安心 | 貯金・配当株・借金の返済・年金 |
| 移動 | 車・ガソリン |
| 人づきあい | 家族や友達と過ごす・集まりに行く |
| 休息 | 睡眠・休み |
| 達成 | 仕事の成果・昇進・投資の利益・目標の達成・選挙に勝つ |
| 公正 | 不公平だと思うことに声を上げる（署名・デモ・投票） |

- 欲求は時間とともに減り、足りないものほど満たしたくなります。
- **感情**：気分・高ぶり・ストレス・幸福度・怒り・不安。出来事で動き、少しずつ元に戻ります。1日のリズム、曜日、季節もあります。まわりの気分も少しうつります。

### 9.4 ふつうの判断（ユーティリティAI＋思い出＋学習＋人）

行動ごとに「考える材料」を0〜1の数にして掛け合わせます。行動は約50種類、1つの行動の材料は最大24個です。

例：カジノに行くか

| 考える材料 | 曲線 |
| --- | --- |
| 刺激の欲求の不足・気分と高ぶり | 足りないほど・高いほど高い |
| 今月のカジノの予算の残り | 少ないと急に下がる |
| 時間帯と明日の予定 | 夜・休みの前は高い |
| 関係する思い出（大勝ち・大負け・後悔。倉庫からも探す） | 大負けの直後は低い（熱くなる人は逆に高い） |
| 自分の学習（カジノのあとの満足度） | 「楽しいけど後で後悔する」と学んだ人は低い |
| 教訓（「熱くなると負ける」） | 負けた直後に下がる |
| 友達に誘われたか・心のモデル | 誘われると高い。親友が落ち込んでいれば、カジノより食事に誘う |
| 家族の目 | 家計を気にする家族がいると下がる |
| 世の中の空気 | Dtradeへのボイコットが広がっていて、自分も不満なら下がる |

全部の行動の点数から、点数の高いものほど選ばれやすい確率で選びます（衝動的な人ほど気まぐれ）。

### 9.5 大きな判断（1年先までの先読み）

例：「MAGITA GT-Rを買うか」

1. **案を出す**：今すぐ買う・セールを待つ・ローンで買う・中古・別の車種・買わずに積立を増やす。
2. **未来を作る**：自分の見通しで乱数を振り、1年先までの未来を1,024通り作る（給料・春闘の賃上げ・ストライキ・失業の確率、家族の出費、病気、株とカジノの結果、MAGITAの値上げが続くか、市民投票で上限が下がるか、セールの時期は自分の思い出から）。
3. **点数をつける**：それぞれの未来での満足（見栄・移動・安心・家族の機嫌）を、その人の性格で点数にします。慎重な人は悪い未来を重く、損を得より約2.25倍重く感じます。
4. **家族と相談**：世帯の大人それぞれが先読みし、意見が分かれたら交渉と説得（§9.9）か先送り。
5. **決める**：いちばん点の高い案。ただし衝動的な人は先読みを途中でやめ、給料日の直後は楽観的にずれます。
6. **理由を残す**：決め手になった材料・思い出・人・先読みの結果を「決断の理由」として記録します（§9.17）。

転職、大きな投資、ローン、引っ越し、結婚、**投票**（どの候補・どの案が自分と家族の1年後をよくするか）、**ストライキへの参加**、**立候補**も同じやり方で決めます。

### 9.6 目標の木（人生 → 年 → 月 → 週 → 日）

- 人生の目標（「区長になる」「60歳で家を持って年金生活」）を、年の目標・月の目標・週の手順・今日の行動に分けます。
- 状況が変わると、木を組み直します（失業・病気・家族が増えた・株で大損・選挙に負けた）。あきらめる、別の道を探す、目標そのものを変える、もあります。

### 9.7 自分だけの学習

- **行動ごとの満足度**：やったあとの満足を覚え、次の点数に足します。人ごとに違う好みが育ちます。
- **株の見通し**：各銘柄の見通しと自信を、ニュース・決算・友達・チャート・自分の損益で直します。どの情報を信じるかも、当たり外れで変わります。
- **まねる**：うまくいっている友達のやり方を少しまねます（投資・仕事・お金の使い方）。
- **教訓**：同じことが何度も起きたら教訓にします（「セールを待つと得する」「熱くなると負ける」「区長の公約は守られない」）。

### 9.8 心のモデル（二段の推測）

- 親しい20人について、「何が好きか・今どんな気分か・何を考えていそうか」に加えて、「**その人が自分をどう思っているか**」まで推測します。会うたびに答え合わせして直します。
- 使い道：誘う・贈る・助ける・お金を貸す、家族の相談、交渉、選挙で誰に頼めば票が集まるか、運動に誰を誘うか、けんかを避ける、嫉妬する。
- 推測は間違うこともあります（すれ違い・誤解・仲直り）。

### 9.9 交渉

- **場面**：中古車の値引き、給料（転職のとき）、家族の大きな買い物、組合と会社の春闘、区長どうしの取引、運動と会社の話し合い。
- **やり方**：何回か案を出し合い、相手の考え（心のモデル）と自分の譲れる線から、譲る・粘る・条件を足す・やめる、を決めます。強気・弱気、はったりもあります。

### 9.10 グループとリーダーの生まれ方

- **グループ**：家族・友達の輪・職場・組合・運動・選挙の陣営・投資仲間・趣味の集まり。
- グループの中に役割（呼びかけ人・まとめ役・ついていく人・反対する人）が生まれ、外向的で信頼され知り合いの多い人がリーダーになります。
- グループの決定（ストライキに入る・デモの日・推す候補）は、メンバーの意見とリーダーの力で決まります。

### 9.11 考え方と議論

- 政治の考え（小さな国↔大きな国、今のまま↔変えたい）と、制度（国・会社・区長）への信頼を持ち、体験と会話で少しずつ変わります。
- 議論では「理由」をやり取りします（「年金の積立金が減っている」「手数料が高すぎる」）。信頼できる相手の、筋の通った理由ほど効きます。考えが離れすぎた相手の話は、逆に反発を強めることもあります。

### 9.12 思い出・人生の本・振り返り

- **最近の思い出**（1,000件、メモリ）、**思い出の倉庫**（2,000件、保存）、**人生の本**（保存）。
- **思い出す**：判断のたびに、話題が近い・新しい・大事な・感情が強い思い出を点数にして上位を使います。深い判断では倉庫と人生の本も読みます。
- **忘れる**：薄れたものから消え、大事なものは人生の本に移り、人生の本がいっぱいになると似た思い出をまとめて教訓にします。いい思い出は少し美化され、つらい思い出は少しずつ薄れます。
- **夜の振り返り**：今日の出来事 → 思い出の大事さを決め直す → 教訓 → 見通し・好み・考えの更新 → 自分がどんな人か（「投資が下手だ」「家族思いだ」）の更新 → 明日の計画。
- **週・月の振り返り**：目標の木、家計（給料・税・保険料・年金・使ったお金・貯金・損益）、人間関係（「最近会っていない友達に連絡しよう」）。

### 9.13 会話とメッセージ

- **相手と場面**：家族の夕食、職場の昼休み、休日の外出、組合の集まり、選挙の演説会、デモ。会わなくても、**メッセージ**（1日数通）でやり取りします。地区をまたぐ相手とも話せます。
- **話題**：車・ゲーム・株・カジノ・仕事・家族・税金と年金・選挙・ストライキ・うわさ。
- **起きること**：気分がうつる・意見が近づく（または反発する）・おすすめが伝わる・うわさが伝わる（本当とは限らない）・説得・約束・交渉・親密度と信頼が上下する。
- **記録**：1件1行（誰と・話題・意見・約束・結果）。運営サイトと街ライブでは、ひな形で会話の文にして見られます（例：「田中：MAGITAの組合、ストやるらしいよ」「佐藤：年金の保険料、また上がるの？」）。

### 9.14 知っていることには限りがある

- 1人1人が知っているのは、自分が見たニュース・自分の体験・人から聞いた話だけです。
- だから、同じ株・同じ制度・同じ候補について、人によって考えが違い、売り手と買い手、賛成と反対がそろいます。
- ニュースは、ニュースをよく見る人から会話を通って数日かけて広がります。新作のゲームや車は「最初に試す人」と「周りが買ったから買う人」で広がります（バス拡散モデル）。うわさを確かめる慎重な人もいます。

### 9.15 人間らしい思い込みと失敗

- 損を得より約2.25倍重く感じる。含み損は持ち続け、利益はすぐ確定する。
- 勝つと自信過剰、負けが続くと取り返そうとする（熱くなる）。
- 給料日の直後に使いすぎる、面倒なこと（年金の手続き）を先延ばしにする。
- 「ずっと外れているから次は当たる」と思う。みんながしていることをしたくなる。
- 最初に見た値段にひきずられる。自分の考えに合うニュースばかり信じる。

### 9.16 人生の段階・性格の変化・別れ

- 学生 → 就職 → 結婚 → 管理職 → 定年 → 年金生活、と人生の段階で、欲求・目標・お金の使い方が変わります。
- 大きな出来事で性格が少しずつ動きます（失業すると慎重に、大当たりでギャンブル気質が少し強く、選挙に勝って自信がつく）。年をとると少し落ち着きます。
- 家族や親友が亡くなると、長く悲しみ、思い出が人生の本に残ります。

### 9.17 決断の理由と心の声

大きな判断と一部のふつうの判断は、決め手を残し、ひな形で文にします。

> 4月25日（給料日）20:14　MAGITA GT-R（ホワイト）を買うのをやめた。
> 理由：MAGITAの組合がストライキに入りそうで、納車が遅れるかもしれない。来月から年金の保険料が上がる（先読みでは1,024通り中690通りで、1年後の貯金が目標を下回る）。友達の佐藤さんが「市民投票で値上げの上限が下がるかも」と言っていた。
> 代わりに：毎月の積立を$300K増やし、市民投票の日を予定に入れた。

心の声（その人の今の考えを1行で。街ライブの人のカードに出る）：「区長の公約、まだ1つも守られてない気がする」

（名前は例です。NPCの名前は乱数で作り、実在の人物にはしません。）

### 9.18 プレイヤーっぽさ

- 自由時間に**ゲームを開く**（ホーム→スロット→投資→SHOP…）。スロットは、プレイヤーと同じベットの段階から資金と気分で選び、負け幅や勝ち幅でやめる。

- セールやイベントに集まり、給料日に気が大きくなる。
- ルールもプレイヤーと同じ（2,000トークン以上で当たれば勝利金の6%がDtradeへ、トークンの交換は$40,000の手数料など）。

- **使用量ブレーキ**：今の段階、項目ごとの見込み、今の考える深さとやり取りの間隔。
- **つまみ**：深さ（自動/手動）・間隔・記録の量・NPCの経済の一時停止。

## 15. リスクと対策

| リスク | 対策 |
| --- | --- |
| 今のゲームの使用量が多く、NPCの枠が少ない | NPCは「残りの枠」で動く（§2.5）。深さと間隔を自動で下げる |
| 使用量が見込みより多い | 自動ブレーキ（§2.6）・NPCが使った量を正確に数える・段階ごとに測る |
| 深い頭が見込みより重い | 深さのつまみ（4段階）で軽くする。地区の計算が1分に収まらなければ自動で1段浅く |
| 1部屋のメモリ（128MB）が足りない | 最近の思い出を減らす（倉庫と人生の本はそのまま）・1地区の人数の上限を下げる |
| 「返事のあとで計算する」形が使えない | 本体が待つ形にする（動いている時間が+5〜14%） |
| 年金や国の財布が破たんする | 第0段階で何十年分も動かして初期値を合わせる。議会が保険料・額・年齢を見直す（本物と同じ議論が起きる） |
| 運動や市民投票でゲームのバランスが崩れる | 変えられる範囲を運営が決める・1四半期に1回まで・翌月から・運営はいつでも固定できる |
| ストライキや大量退職で会社がつぶれる | 会社の対応（賃上げ・採用）・最低限の業務は続く・国の支援 |
| 経済の暴走 | 家計の予算・テネシスの金利・上限・見張り・NPCの経済だけ止めるスイッチ |
| プレイヤーが不利（限定車の取り合い） | 在庫はプレイヤーが先に買える順番、プレイヤーの優先枠 |
| NPCとプレイヤーの見分けがつかない | 画面では必ず「住民（NPC）」と表示 |
| NPCの行動を読まれる | 秘密の鍵の乱数、日にちや量のばらつき |
| 投稿・会話・演説の文がおかしい | 決まったひな形から作る。生成AIは使うとしても少量・確認つき |

## 16. 決めてほしいこと（おすすめつき）

1. **新しい人生の形**：亡くなった人の枠は「まったく新しい18歳の人（家族の成人した子として登場）」（おすすめ）か、「同じ人が記憶をなくして18歳から」か。
2. **プレイヤーと国**：プレイヤーも税金・年金の対象にするか。おすすめは「最初は対象外（街を訪れる人）。国の決まりの変更（手数料など）は受ける」。
3. **市民が変えられる範囲**：プレイヤーに効く決まり（MAGITAの値上げの上限・Dtradeの手数料・求人サイトの掲載料）も変えてよいか。おすすめは「変えてよい。ただし今の半分まで・1四半期に1回・運営がいつでも固定できる」。
4. **消費税**：おすすめは「0%で始め、議会と市民投票で0〜15%」（今の値段と会社の売上を崩さないため）。
5. **区長の任期**：6か月（おすすめ）か1年。
6. **定年**：おすすめは「60歳で定年、65歳まで再雇用」（年金を60歳から受け取るのに合わせて）。
7. **年金の繰下げ**（70歳まで遅らせると1か月0.7%増える）を入れるか。おすすめは「入れる」。
8. **署名と投票にプレイヤーも加われるか**：おすすめは「最初は見るだけ。あとで1人1票を試す」。
9. **見回りの間隔**：おすすめは「1分ごと、余裕がある月は自動で30秒ごと」。
10. **考える深さの目標**：おすすめは「ゲーム全体の動いている時間が75%になるまで自動で深く」。
11. **給料と賞与**：おすすめは「年収÷12を毎月25日＋会社が業績予想を超えた年だけ特別賞与」。
12. **NPCのカジノ使用料（月$1M）**：おすすめは「NPCにはかけない」。
13. **プレイヤーの株の注文**：おすすめは「まずNPCの板と売買し、売りが足りない分だけ会社が新株を出す」。
14. **在庫の取り合い**：おすすめは「NPCと取り合う。ただしプレイヤーが先に買える」。
15. **NPCをどこまで見せるか**：おすすめは「街ライブで全員の点と人のカード（心の声まで）。人生の本は有名なNPCだけ、全部は運営だけ」。
16. **生成AI（Cloudflare Workers AI）**：会話・演説・心の声に使うか。おすすめは「まずはひな形で作り、あとで区長の演説など少量だけ試す」。
17. **名前**：国の名前（例：「TWO STATE国」）と、5つの地区の名前（§4.4）。
