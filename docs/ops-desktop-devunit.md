# 運営デスクトップの操作とDEV UNIT

## ウィンドウとDock

ウィンドウは上下左右にドラッグできます。画面外にはみ出してもタイトルバーの一部が残るため、戻せます。最大化したウィンドウもタイトルバーをドラッグすると元のサイズに戻して移動できます。「ウインドウをタブにまとめる」設定では独立移動を停止します。

Dockは1回タップするたびに表示・非表示（最小化）を切り替えます。デスクトップ・検索・内部リンクから開く操作は常にそのアプリを前面に表示します。入力内容は保持されます。Dockとデスクトップのアイコンを小さくし、復元・起動・ポップオーバーの動きを調整しました。動きを減らす設定は維持しています。

## DEV UNIT

- 開発者と運営者がREADMEの資料を検索・閲覧し、コメントできます。閲覧者・一般プレイヤーはコメントAPIにアクセスできません。
- 現在のリポジトリに独立したREADME DEVファイルはないため、`README.md`の全文を収録しています。`node tools/sync_devunit_readme.cjs`で更新します。ルートの`npm run dev`、`npm start`、`npm run deploy`でも自動更新します。Wranglerを直接実行する場合や外部のデプロイ設定では先に同期コマンドを実行してください。
- コメントとアカウント別既読位置はデータベースに保存され、バックアップ対象に含まれます。最新100件から以前の履歴を追加読み込みできます。
- コメント到着時は運営サイトのライブ接続で未読バッジとアプリ内通知を更新します。切断・再接続には既存の更新周期での確認も使います。「通知を許可」でブラウザー通知を有効にできます。サイトを閉じている間のWeb Push通知ではありません。
- 実際に表示しているアプリのコメントだけ既読にします。資料・コメントはHTMLとして実行せず、テキストとして表示します。

## セキュリティーホーム

専用アプリに既存の`/sec/`をiframeで開きます。認証・トークン・画面・API・権限・ロックダウンの仕組みを統合しません。独立したログインが必要です。別ウィンドウで開くリンクもあります。

埋め込み許可はセキュリティーホームだけ、同一オリジンだけに限定しています。運営サイト本体の埋め込み禁止は維持します。Cloudflareの`_headers`とNodeの静的配信の両方に適用します。
