確認対象は `codex/ui-refresh-car-viewer`。送信前に添付17枚、変更ファイル、圧縮後の実ファイル、ブラウザ表示を再点検した。

## 指示と実装の対応

| 指示 | 確認内容 |
| --- | --- |
| ホームのルール → インフォメーション | 添付の青い i を `info.webp` に変換し、ルール画面を開く既存ボタンに適用 |

| スロット枠交換・周囲の点々削除 | 添付ジャングル枠を5列3行に合わせ、絵柄の前面と背面に分離。電飾DOMの生成処理を削除 |

| 女神コイン交換 | 配当用の内部ID `statue` を維持し、添付の星模様付きコインに交換。旧女神の回転画像は読み込まない |
| CAR OWNERアイコン | 添付の白い車の後部画像を使用 |
| 詳細の点々 | 今回の17枚に三点画像がないため、既存の青い三点アイコンを使用 |
| ガイド／フィードバック／VIP／投資／開発者日記 | 添付の本／チェック／VIP看板／上昇グラフ／メモ帳を適用 |

## 検証

- `npm test`: 238件成功、失敗0件。
- 送信中にmainへ追加されたガチャ関連2コミット（`26448f3`まで）を統合し、238件を再実行して成功。競合したビルド番号は再計算し、main側の追加ファイルも保持。
- `node tools/stamp.mjs --check`: 正常。単一HTML版も最新画像から再生成。
- 画像のデコード、GLBヘッダー・全長、圧縮レポートと実ファイルサイズの一致を確認。
- JavaScript内のリテラルなメディア参照135件について欠損なしを確認（不要な最大ベット参照を除去する前の集計）。
- Chromium/WebGLのローカルブラウザ検証: ホームの画像割り当てと削除項目、詳細の画像6種、選択した車と表示モデルの一致、実際のマウスドラッグによる回転、全車デコード、固定ガレージ、メンテナンス画像、退出先を確認。
- ステージ／ガレージ建物モデルへのリクエストが発生しないことを確認。
- ブラウザの未処理JavaScriptエラー0件。

## 圧縮結果と確認範囲

| 対象 | 変換前 | 変換後 | 削減 |
| --- | ---: | ---: | ---: |
| 画像レポート90項目 | 5,849,255 bytes | 692,840 bytes | 88.16% |
| 車モデル10台 | 13,043,332 bytes | 6,226,896 bytes | 52.26% |

画像の変換前合計は、差し替え画像については添付PNG、既存画像については圧縮前WebPの合計。ゲーム全体の転送量を示すものではない。枠の前面・背面画像は別途生成している。

Androidには `TwoStateApp.exit()` → `finishAndRemoveTask()` を追加した。Android実機・APKでの終了確認は未実施。既存APKで終了APIがまだない場合、およびタブを閉じられない通常ブラウザでは、ゲーム処理を停止する独立した終了ページに移動する。既存APKを終了API対応にするには更新APKの配布が必要。

水平360度表示とブラウザ上の終了導線は検証済み。全端末での画質・性能やAndroid実機動作は、この確認だけで保証するものではない。
