# 再送・チャット・外部ログインの追加監査（2026-10-30）

基点は PR #63 を取り込んだ main `2bd98e78a9e941aef9dbe868619301fc17aa985c`。使い捨てアカウントで、通信失敗後のパスワード変更、古い抽選応答、保存途中の失敗を再現した。本番アカウントや資産を検査用に変更していない。

## 修正した11項目

| 問題 | 影響 | 修正 |
|---|---|---|
| パスワード変更でスピン・ガチャの再送情報を失う | 抽選は確定したが応答が届かなかった後にパスワードを変更すると、再送情報が旧トークンのままになり、次の操作が新しい抽選として課金される | パスワード変更の成功時だけ、同じ受付番号・内容を新しい本人のセッションへ移す。古い要求の完了処理は移行済み情報を消せない。再読み込み後も回収でき、別アカウントへは移さない |
| スピンの再送で古いアカウント状態を返す | 受付時点の残高・XP・VIP・お守り状態が返り、その後の購入や別端末の状態を画面へ反映できなくなる | 抽選結果を固定したまま、現在の残高・XP・VIP・お守り状態を返す。再抽選や追加ベットは行わない |
| グループ作成の一部だけが確定する | 最初のシステムメッセージの保存に失敗しても、グループとメンバーが残り、再試行で別グループが増える | グループ・メンバー・最初の投稿をまとめて確定し、通知は確定後に送る |
| グループ退出の一部だけが確定する | 退出通知の保存に失敗しても、参加情報と協力スロットの着席だけ消える | 退出・着席解除・退出投稿をまとめて確定する |
| チャット検知の保存失敗で投稿だけ残る | DM・グループの投稿と未読件数が確定し、運営向けの検知記録が残らない。グループではエラー前に通知も届く | 投稿・検知記録・クエスト進捗をまとめて確定し、失敗時は通知も送らない |
| NPCの応答失敗でプレイヤーの投稿だけ残る | マイクソン・ジョンソンの応答保存に失敗すると、プレイヤーの投稿と未読状態が残り、再試行で重複する | 一回の会話全体を同じトランザクションにする。マイクソンの融資・返済と進捗もその範囲に含める |
| 送信取消の監査失敗でメッセージだけ消える | エラーでも送信取消とライブ通知が確定し、監査記録を残さず再試行もできない | 取消・監査をまとめて確定し、その後に通知する |
| メッセージ通報の監査失敗で通報枠を消費する | エラーでも通報だけが保存され、再試行が重複扱いになる | 通報と監査をまとめて確定し、失敗時は一日の通報枠を消費しない |
| Google／Discordの連携が監査失敗でも残る | 連携エラーの表示後も外部IDが登録され、本人の認識とログイン手段が食い違う | 連携・手続きの消費・監査を同時に確定する |
| Google／Discordの連携解除が監査失敗でも進む | 解除エラーの表示後もログイン手段だけが消える | 解除と監査を同時に確定する。失敗時は既存の連携を保持する |
| 外部ログインの保存失敗で認証済み手続きを失う | 監査またはセッションの保存失敗で手続きだけが消え、外部サービスでの認証からやり直しになる。セッション保存失敗時は成功扱いの監査も残る | 手続きの消費・監査・端末情報・セッションをまとめて確定し、失敗時は有効期限内の同じ手続きで再試行できる |
