# 運営サイトのデスクトップUI

`/ops/` にmacOS風の表示レイヤーを追加しています。初期版では既存処理を表示レイヤーで包み、追加改修でDEV UNITとセキュリティーホームの起動機能を追加しています。
現在の追加機能と検証手順は[運営デスクトップとDEV UNIT](ops-desktop-devunit.md)を参照してください。

## 操作

- Dockはクリックで表示・非表示を切り替え、デスクトップのアイコンはダブルクリックで開きます。タッチでは1回で開きます。
- ウインドウ上部をドラッグして移動し、右下をドラッグしてサイズを変更します。
- 赤・黄・緑のボタンで閉じる・最小化・最大化を行います。Dockから再表示できます。
- 閉じる・最小化は表示の操作です。元の画面のDOMや入力欄は作り直しません。
- 「ウインドウ」メニューでタブ表示・ウインドウ一覧に切り替えられます。
- タブは左右の矢印キーでも切り替えられます。Ctrl / Command Kでアプリを検索できます。
- 「表示」メニューに予備の背景、Dockサイズ、動きを減らす設定があります。
- 運営アカウント・従来の更新頻度・ログアウトは右上のアカウントアイコンにあります。

## 既存処理との接続

`desktop.js` は元のセクションを1回だけウインドウで包み、元のタブそのものをDockに移します。
アプリの起動はそのタブの既存クリック処理を使います。ログなどからの内部遷移は
タブ・セクションの表示属性を監視して反映します。APIや認証トークンを扱いません。

表示可能なアプリは元のタブの `hidden` / `disabled` に従います。
開発者・運営者・閲覧者の権限、日次ログインの記録、開発者コードの確認、
チャット・通話、保管庫のアップロード処理は従来のコードが担当します。
背景のウインドウは最初のクリックで前面に表示し、操作は前面になってから行います。
従来のスマートフォンの横画面処理と、OSの「動きを減らす」設定にも対応しています。

## 確認

既存の運営・権限・保管庫・課金・チャットのテスト:

```sh
node --disable-warning=ExperimentalWarning --test server/test/ops.test.js server/test/dev7.test.js server/test/dev8.test.js server/test/dev9.test.js server/test/vault.test.js
```

PlaywrightとChromiumを用意した開発環境では、次のブラウザースモークテストも実行できます。
使い捨てのローカルデータベースのみを使い、本番のアカウントやデータには接続しません。

```sh
node tools/check_ops_desktop.cjs
OPS_DESKTOP_MOTION=full node tools/check_ops_desktop.cjs
```

`OPS_BROWSER_EXECUTABLE` で既存のChromium実行ファイルを指定できます。
`OPS_DESKTOP_SCREENSHOTS` を指定した場合のみ、そのディレクトリに画面写真を保存します。
