基点は PR #66 を取り込んだ main `ecb37c4ec3dc5da13f3829a79dcf64cff5209445`。今回は決済や車の画面以外を調べ、R2待機中の権限変更、期限切れ、監査記録の保存失敗、日記コメントの応答順序を使い捨て環境で再現した。本番アカウントや資産は検査用に変更していない。日付は日本時間。

## 修正した12項目

| 問題 | 影響と修正 |
|---|---|
| 停止・期限切れになった共有リンクから、R2待機中だった本文が返る | R2の取得後にリンクの停止状態と期限を再検査し、無効なら本文を返さない |
| 実装済みへ移した・削除したファイルの本文が、待機中の共有リンク要求へ返る | ファイルの公開条件と保存世代を取得後に確認する。単独ファイルのリンクでは親ファイルも再検査する |
| 運営権を取り消されても、待機中の保管庫要求へ本文が返る | 生データとJSONの両経路で、取得後にセッション、運営権、保管庫へのアクセス権を再検査する |
| R2に本文がない失敗した取得でも、配布枠と成功件数が消費される | 同時取得の上限保護のため配布枠は先に予約し、失敗時に返却する。成功件数は検証完了後に記録する。復元前の要求から復元後の枠を変更しない |
| リクエスト本文の受信中に解除チケットが切れても、保管庫を変更できる | 既存の本文受信後の認証確認へ保管庫の追加条件を合成する。改名、メモ、フォルダ作成、共有リンク発行で期限境界を検査する。リクエスト制限を二重加算しない |
| 運営権の付与がエラーでも、昇格・端末固定・閲覧セッションの終了が残る | 監査記録を同じトランザクションへ含め、失敗時は変更前の権限とセッションを保持する |
| 運営権の取消がエラーでも、権限剥奪と強制ログアウトが確定する | 取消・セッション終了・監査記録をまとめて確定する。確定前に強制ログアウト通知を送らない |
| 閲覧者の付与・取消が、監査記録に失敗しても確定する | 権限、閲覧セッション、監査記録を同じトランザクションへ入れ、通知は確定後に送る |
| 日記の古いコメント一覧が、送信後に取得した新しい一覧を消す | 一覧の表示先ごとに要求順を管理し、最新の要求だけを反映する |
| 日記の送信待ち中に書いた次の下書きが、送信成功で消える | 送信時の文字列と編集回数を保持し、その後に編集された下書きを消さない。同じ文字列を打ち直した場合も保持する |
| 日記コメントの送信待ち中に、同じ送信イベントが重複成立する | 送信中はフォームの再送信を拒否する。現在の送信が完了したら通常どおり次を送れる |
| 閉じた日記や描画し直したカードの古いエラーが、現在の画面へ出る | 日記の表示世代と対象要素の接続を確認する。古い送信・一覧・画像要求から現在の画面へエラーや入力変更を反映しない |
