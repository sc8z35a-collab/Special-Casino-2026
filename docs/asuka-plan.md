# アスカ国 計画案 — 「海外」を実在する別の国として作り直す

ヴェルノア共和国の企業がいま「海外」と呼んでいる、あいまいな売上と支出を、実在する国「アスカ国」として作り直すための計画案です。ご提案の2つの案を検討したうえで、おすすめの形・数字・Cloudflareの負荷・既存のシステムとの衝突・実装の順番・決めていただきたいことをまとめました。数字はすべて手元の計測（5万人の国をそのまま動かした結果）に基づきます。

### 0-2. 今回すでに直したこと（この計画の第0段階・PR #84に含めます）

- **「海外」を閉じた口座に**：海外が持っているお金は、ヴェルノアが輸入で払った分だけ。海外はそれを約30日かけて使い、ヴェルノアの輸出品（YOSIDA・WAZIMAの車、種、ゲーム）を買います。計画の額まで買い足す仕組み（`outside`、テネシスの海外事業）は廃止しました。
- **プレイヤーが受け取るお金に必ず払う人を**：ゲームからの贈り物（ログインボーナス・毎日の無料トークン・協力プレイのボーナス・アップデートのお礼・功績・日記・金の生る木の収穫・ジョンソンと運営からの贈り物）は国庫が払います。バイトの給料・車の貸し出しの売上・マイクソンの融資は地元の商売が払い、返済も地元の商売に戻ります。
- **転生したNPCにも「生まれたときのお金」**：国の始まりの人たちと同じ式（18歳・地区で決まる）で、虚空から作られます。これまでの「国の若者支援金」は廃止しました。
- **お金の検算**：「NPCの初期資金＋転生した人の初期資金＋プレイヤーの出入り」以外にお金が増減しないことを、テストで毎回確かめています。

## 1. ご提案の検討

### 1-1. 案A：国有化した銀行がお札を一度だけ刷り、国営の職場で働く

- **良い点**：作りが単純で、アスカ国民がすぐに給料を得られます。
- **問題1（お金の原則）**：「お札を刷る」は、NPCとプレイヤーの初期資金以外は虚空から作らないという原則の例外になります。ただし、**刷る代わりに同じ額を「アスカ国民が生まれたときに持っているお金」として配れば原則の範囲内**です。
  - ヴェルノアのお金の総額は約$8.6兆なので、2.1倍は約$18兆、1人あたり約$1.2億です。ヴェルノアの1人あたり約$1.58億とほぼ同じ水準です。
- **問題2（ご指摘のとおり一方通行）**：アスカ国がヴェルノア企業から買い、ヴェルノアがアスカ国から何も買わなければ、お金はヴェルノアへ流れ続けます。
  - 支出は持っているお金に比例するので（ヴェルノアの市民はそう動いています）、ある日突然崩壊するのではなく、ゆっくり枯れます。年$7,700億を使い、戻りが輸入の年約$600億だけなら、アスカのお金は年約4%ずつ減ります。15年で約半分、30年で約3割になり、ヴェルノア企業のアスカでの売上も同じ速さで縮みます。
  - 国営の職場の給料は、国にお金が入らない限り刷ったお金を食いつぶすだけなので、国庫は数年で尽きます。給料が払えなくなった時点が「経済崩壊」です。
- **結論**：アスカ国が持続的に収入を生まない限り崩壊する、というご懸念は正しいです。

### 1-2. 案B：ヴェルノア企業がアスカ国に積極展開し、国は地代や協力費で稼ぐ

- **正しい方向です。** 国の収入が「ヴェルノア企業がアスカで払うお金」から来るので、お札を刷る必要がありません。
- **残る矛盾**：支店の売上のうち、アスカに残る分（社員の給料・地代・協力費・税・現地の仕入れ）はアスカ国内で回ります。しかし残りの「ヴェルノアで作った品物の代金と、本社への利益」は毎年ヴェルノアへ出ていきます。
  - 地代や協力費は支店の売上から払われ、その売上はアスカ国民のお金なので、**国の収入は増えても、アスカ全体から出ていくお金は減りません**（国内での付け替えです）。ヴェルノアからアスカへ戻る流れがなければ、案Aと同じくゆっくり枯れます。
- **「労働者5万人で飽和・消費の選択肢も十分」** は、ヴェルノアのことだと解釈しました（アスカ国には企業も消費の選択肢もない、という対比として）。違っていたら教えてください。

## 2. おすすめ案：案B ＋「ATSUKA Vision＝稼ぎ頭の国営事業」＋自動で釣り合う仕組み

### 2-1. アスカ国の基本

- **人口15万人。** 働く年齢の人は約9.3万人です。
- **アスカ国籍の企業は置きません**（ご希望どおり）。ヴェルノア企業の支店と、国営の事業（ATSUKA Vision）と、地元の小さな店（飲食・小売・家主・医療。ヴェルノアの「地元の商売」と同じ扱いの一つの口座）だけです。

### 2-4. 崩壊しない仕組み（3つ）

**(a) アスカに残る割合を高く設計する**

- 支店の社員はすべてアスカ国民にします。店舗と倉庫はATSUKAから借ります。
- アスカでの利益にはアスカの法人税がかかり、ヴェルノアでは同じ利益に二重にかけません（外国税額控除）。本社へ送る利益には源泉税をかけます。
- これで、支店の売上（目標の合計 年約$4,900億）の約6割がアスカに残ります（社員の給料・地代・税・現地の仕入れ）。ヴェルノアへ出るのは約4割、年約$1,900億です（ヴェルノアで作った品物の代金と、本社の利益）。

**(b) ヴェルノアからアスカへ戻る流れ**

- 2-2の①〜④で、年約$1,500〜2,000億です。
- 支店の新設・改装の工事費（ATSUKAが請け負う）も加わります。

**(c) 自動で釣り合う仕組み（これが崩壊を防ぎます）**

- **両国とも、支出は持っているお金に比例します。** ヴェルノアの市民はすでにそう動いています。お金が減った側は使う額が減り、増えた側は増えます。
- **アスカの物価と賃金は、アスカのお金の量で動きます。** 両国ともドルなので為替はありません（ユーロ圏と同じ状況）。その代わり、お金が流れ出ると物価が下がります。アスカが安くなると、ヴェルノアの旅行と素材の購入が増え、アスカの人の買い物は減って、収支が戻ります。
- **アスカ国の財政ルール**：対外収支が3か月続けて赤字なら、地代・協力費・源泉税を少し上げます。黒字なら下げるか、余剰をヴェルノア国債で運用します（政府系ファンド）。

計算で確かめると、出ていく率をa、戻る率をbとしたとき、両国のお金の比率は「アスカ：ヴェルノア＝b：a」に向かって指数的に近づきます。設計値（a≒年1%、b≒年2%）なら、今の比率（約2.1：1）がそのまま保たれます。設計が外れても、新しい釣り合いへ20〜30年かけて近づくだけで、急な崩壊は起こりません（第3段階で長期シミュレーションして確かめます）。

### 2-5. テネシスの扱い（要判断）

- テネシスの「海外」の売上 年$4,290億を、持続できる形でアスカに置くことはできません。
  - 年$4,000億を超える利息を毎年払うには、アスカ国が約$10兆を借りる必要があります。その利息だけで、国の収入（年約$3,600億の見込み）を上回ります。

## 3. 軽量なNPC（15万人）とCloudflareの使用量

- **今の構成**：ゲーム全体（プレイヤー・会社・ヴェルノアの5万人）が1つのDurable Objectで動いています（Workers Paid）。効いてくる上限は、メモリ（1つで128MB、ヴェルノアで約40MB）と稼働時間（月40万GB秒込み）です。ヴェルノアは1分ごとに計算しています（5万人で1分約2〜3ミリ秒）。
- **アスカ国の「一段軽い」NPC**：
  - 計算は1日1回です。分単位の行動・感情・人間関係・政治はありません。
  - 1人あたり約40バイトの列（年齢・地区・仕事・勤め先・給料・お金・借金・好み）で、15万人で約6MBです。
  - 1日の計算は推定10〜30ミリ秒、保存は1日1回（約6MB）です。
  - 名前は番号と世代から都度作ります（保存しません）。
- **使用量の見込み**：
  - 追加は、稼働時間で1日0.1秒未満、保存量が+6MB、書き込みの行数が月数百です。込みの分の1%未満なので、「月の9割までNPCに使ってよい」という枠には大きな余裕があります。
  - メモリも、ヴェルノア約40MB＋アスカ約6〜10MBで、上限の半分以下です。
  - 実際の今月の使用量は運営サイトの「サーバー」で見られます。そこでの見え方は、実装後に確認します。
- **自動調整**：今の「考える深さ」の自動調整（今月の使用量が75%を超えたら浅く）に、アスカ国も加えます（75%を超えたら2日に1回の計算）。

## 4. 既存のシステムとの衝突・矛盾（調査結果と対応）

1. **会社の「海外」の扱い**（`corp-model.js` の海外向けの流れ・スタジオの海外販売・種・テネシス）→ すべて「アスカ国の買い物」に置き換えます。今回作った「海外の口座」は、アスカ国の口座の仮の形です。移行時にその残高はアスカ国へ移し、お金は失いません。
2. **会社の人員と給料**：今は、会社の社員＝ヴェルノアの市民の列です。支店の社員はアスカの列にいるので、会社の人数・給料・採用・削減を国ごとに分けます（決算は合算し、運営サイトでは国別に表示）。
3. **税金**：アスカの法人税と、ヴェルノアの外国税額控除を足します（二重課税なし）。
4. **車の在庫**：カーオーナーのロット仕入れの在庫を、アスカの店と分けるか共有するか → 共有をおすすめします（作りが単純）。
5. **カジノ**：ヴェルノアのスロットの勝ち分は国庫が払います（国営）。アスカのカジノはDtradeの私営なので、勝ち分はDtradeが払い、胴元の取り分で黒字にします。
6. **銀行**：テネシスの帳簿は、ヴェルノアの全員の預金と借金を映しています。アスカの預金と貸出は別の口座にして、ヴェルノアの検算を崩さないようにします。
7. **株式**：アスカの人は、最初はヴェルノア株を売買しません（市場が複雑になるため）。政府系ファンドはヴェルノア国債だけを持ちます。
8. **プレイヤー**：最初はアスカ国に関わりません（プレイヤーのお金の流れはヴェルノアのまま）。将来、旅行や出店を検討します。
9. **地元の企業32社**：アスカには出ません。輸入（燃料・原料）の相手が素材・エネルギー公社になるだけです。
10. **破産と運営権**：破産した会社のアスカ支店網も、管財人が事業として売るか閉じます（閉じたらアスカの社員は失業）。
11. **新事業（会議室の「新事業の立ち上げ」）**：アスカの社会実験特区で先に試す形にします（ご提案の「社会実験場」）。
12. **街ライブ・3D化の将来計画**：街ライブはヴェルノアのままです。アスカ国は将来の3Dで「行ける2つ目の街」の候補になります。
13. **時間**：アスカの1日も、9:00（日本時間）の締めで同じ日に進みます。
14. **お金の検算**：アスカの国民・国・地元の店・支店の口座も検算に入れて、テストで毎日確かめます。
15. **画面と文書の「海外」**：「海外・法人向け販売」などの名前、ハンドブック、Devニュースを「アスカ国」に合わせて直します。
