# アスカ国 計画案 V2 — お金は「建国の一度」と「プレイヤーの始まり」でしか生まれない

ヴェルノア共和国の「海外」を実在する国「アスカ国」として作り直す計画の第2版です。V2では、お金の大原則（途中で生まれない・消えない・必ず循環する）を何より優先します。会社が最悪で10分の1に縮んでも構わない、というご指示に沿っています。数字は、5万人の国（本番と同じ大きさ）を実際に動かした計測に基づきます。

---

## 実装の状況（2026-11-02）

ご判断（転生とプレイヤーの初期資金は国庫から、コインのVIPは$を生まない、アイコンはMY WAY、13兆の配分はこのまま、テネシスも破綻の対象で国の援助もありうる）に沿って、第0.5段階・第1段階・第2段階と運営サイトを実装しました。詳しくは `docs/handbook/41.md` にあります。

- お金が生まれるのは、2つの国の建国のときだけです。プレイヤーの初期資金も国庫から出ます（R1）。
- マネー台帳は本番でも毎日の締めで数え、ずれたらDiscordに知らせます。
- 5万人＋アスカ15万人の国を8か月動かした結果は次のとおりです。
  - **台帳のずれは毎日$0**でした。
  - 13社の売上は月$300億から$900億に戻り、うち約$140億がアスカ国からです。
  - テネシスはほぼ収支均衡になりました。
  - アスカ国のお金は、年に約0.4%ずつヴェルノアへ移っています。4-7の予想どおり緩やかで、崩壊の兆しはありません。
  - 両国の1日の計算は約0.25秒です。
- 第3段階の自動で釣り合う仕組み（財政ルールによる地代・源泉税の調整、物価と旅行、政府系ファンド）も実装しました。
- 小さな国（2,000人＋アスカ6,000人）を5年動かした結果は次のとおりです。
  - 両国のお金の合計は、始めと終わりで1ドルも違いませんでした。
  - アスカ国のお金は年に約0.7%ずつヴェルノアへ移りました。財政ルールは地代10%・源泉税15%まで上がって流出を抑えましたが、止めてはいません。
  - 失業率は約7%、物価は建国時の0.99倍で、崩壊はありません。
  - これ以上の釣り合い（地代と税の上限、ATSUKA Visionの調達の割合など）は、本番の様子を見て調整できます。

## 0. V1からの変更点

- **お金の大原則を最優先**にしました。会社の売上を「海外」の額に合わせることはやめ、各社の大きさは市場が決めます（大きく縮むこともあります）。
- **アスカ国のお金は建国時の13兆ドルだけ**です。一度だけ刷り、国民・国庫・国営事業・国立銀行・企業誘致の資金などに配ります。そのあとは一度も刷りません。
- **途中で生まれたり消えたりしているお金を調べ直しました**（2章）。すぐに直せるものと、決めていただきたいものに分けています。
- **V1の誤りを訂正します。** V1で「テネシスの自己資金は約3.4兆」と書きましたが、そのうち約3兆は国債（国への貸付）に入っています。自由に使える自己資金は **約$2,200億** です。

## 1. お金の大原則（保存則）

| | 決まり |
| --- | --- |
| **R1 生まれるのは3つだけ** | ① ヴェルノア建国時の初期状態（市民・国・会社・銀行。総額約$8.4兆）② アスカ建国時の13兆ドル（一度だけ）③ プレイヤーが始めたときのお金（登録ごと）。これ以外では、お金は絶対に生まれません。 |

| **R3 マイナスは借金だけ** | 口座がマイナスになるのは、銀行の自己資金から借りたときだけです。銀行は自分のお金しか貸しません（預金を又貸しして、お金を増やすことはしません）。貸すお金がなければ、払えないものは払えません（未払い・延滞・破産になります）。 |

## 2. 調査結果：まだ途中で生まれたり消えたりしているお金

5万人の国を3か月動かし、全員の持ち分の合計（借金を差し引かない額）を毎月測りました。結果、**転生した人の初期資金を除けば、合計は月ごとに一定でした。** 残っている箇所は次のとおりです。

| 箇所 | 今の動き | 規模（5万人） | V2での扱い |
| --- | --- | --- | --- |
| 転生した人の「生まれたときのお金」 | 虚空から生まれる（前回のご指示どおり実装済み） | 年約$150億増える | 亡くなった人の遺産から払い、足りなければ国庫から（**要判断1**） |
| 地元企業の借越し（マイナスの口座） | 取引銀行は、破産のときまでお金を減らさない | 3か月で約$6.5億 | 借越しは取引銀行の自己資金からの貸付にする。貸せなければ払えない |
| テネシスの貸出（市民・国・会社） | 帳簿上は自己資金から出ているが、上限がない | 自己資金は約$2,200億で、月$50〜120億ずつ減っている | 自己資金の範囲だけ貸す。底をつきそうなら貸出を止めて人員を減らし、最後は国の一時国有化（**要判断5**） |
| 動いている本番の国の「海外の客の売掛金」 | 最初の締めで一度だけ現金にする（第0段階で実装） | 各社の売上の約20日分 | 現金にせず、貸倒れとして消す（すぐ直します） |
| アイコン（アバター）の購入代金 | 誰にも入らず消える | プレイヤーしだい | 受け取り手を決める（**要判断3**） |
| 金の生る木の肥料の6割 | YOSIDAに4割が入り、残りは消える | プレイヤーしだい | 残りは国庫へ（収穫を払うのは国庫なので、その財源にします。すぐ直します） |
| コインで払ったVIP | DAIZINに$が生まれる（コイン1枚＝$10万） | プレイヤーしだい | R4に合わせる（**要判断2**） |
| 端数（丸め） | 6か月で約$200 | ごくわずか | すべての取引で、端数は地元の商売へ |

始まりの日の扱いも、正しく説明しておきます。国が始まった日に、テネシスの帳簿は国の古い国債（3兆）と市民の借金（約$1,500億）を貸付として取り込みます。このため、テネシスの「自由に使える自己資金」は約3.4兆から約$2,300億になります。お金が消えたのではなく、最初から貸付だった分が帳簿に正しく載っただけです。

## 3. 会社は売上に合わせて伸び縮みする（10分の1もありうる）

- **毎月**：直近3か月の売上をもとに、予算（施設・研究・広告・その他・設備）を決め直します。目標の営業利益率を保ち、1か月の変化は±10%までにします。
- **四半期ごと**：売上で養える人数に合わせて、採用または削減します（自然減を優先し、急ぐときは希望退職）。
- **値段**：売れ残りや品切れに応じて上げ下げします（今の会議の「値下げ・値上げ」を、毎月の自動の判断にします）。
- **業績予想と株価**：実際の売上から作ります（計画の売上からは作りません）。
- **破産**：今の手続きのまま（債務超過6か月、または支払不能）です。
- **テネシス**：自己資金の範囲でしか貸しません。閉じた経済では赤字なので、大きく縮むことになります。
- **今の見込み**：アスカがない閉じた経済では、13社の売上は「海外」があった頃の約半分（月約$500億）です。テネシス以外は2か月目から黒字に戻りました。アスカができると、売上は戻る方向に動きます（4-8）。

## 4. アスカ国 V2

### 4-1. 建国資金13兆ドルの配分（一度だけ刷る）

| 行き先 | 額 | 割合 | 使い道 |
| --- | ---: | ---: | --- |
| 国民（15万人） | $7.8兆 | 60% | ヴェルノアと同じ式（年齢・仕事・地区）で配ります。1人平均約$5,200万（ヴェルノアは約$1.58億で、アスカは若い商業国として少なめ） |
| ATSUKA Visionの事業資金 | $1.95兆 | 15% | 国営事業の建設・運転資金・給料 |
| 国庫（一般会計） | $1.3兆 | 10% | 年金・失業手当・医療・公務員以外の国の支出 |
| アスカ国立銀行の自己資金 | $0.91兆 | 7% | アスカでの貸付の原資（R3：これ以上は貸せません） |
| 企業誘致のブースト資金 | $0.52兆 | 4% | ヴェルノア企業がアスカに支店を開くときの補助（開業費の3割・3年まで） |
| 年金の積立金 | $0.26兆 | 2% | アスカの年金 |
| 地元の商売の運転資金 | $0.26兆 | 2% | アスカの飲食・小売・家主・医療の手元資金 |
| **合計** | **$13兆** | 100% | ヴェルノアの約1.55倍 |

### 4-2. 人口と仕事

- 人口15万人。働く年齢の人は約9.3万人です。
- 仕事は、ATSUKA Visionが約4.5万人、地元の商売が約3.5万人、ヴェルノア企業の支店は進出しだい（4-4）です。
- アスカ国籍の企業はありません（ご希望どおり）。

### 4-3. ATSUKA Vision（国営事業で、アスカ国の稼ぎ頭）

株式会社ではなく、国の事業部門です。ヴェルノアからお金を得るのは次の5つで、いまの「海外」への支払い（輸入）は、ここの売上に変わります。

1. **素材・エネルギー公社**：ヴェルノアの会社の原料、地元企業の輸入、発電の燃料。
2. **国際港・物流ハブ**：両国の間の品物の港湾・通関の手数料。
3. **アスカ・デジタル**：ゲームの配信手数料、ヴェルノア企業のサーバー。
4. **アスカ・リゾート**：ヴェルノア市民の旅行。
5. **フリーコマースゾーンと社会実験特区**：ヴェルノア企業の支店の地代・協力費。新事業はまずここで試します。

ATSUKA Visionが重機・車両・システムを買う相手は、ヴェルノア企業です。

### 4-4. ヴェルノア企業の進出は採算で決める

- 支店の数を「海外」の額に合わせることはやめました。各社が四半期ごとに、アスカの需要（アスカの人の支出の分野別の額）と、自社の利益率・開業費・ブースト資金の補助を見て、支店を開くか、増やすか、閉じるかを決めます。
- 支店の社員はアスカの人です。店舗は、ATSUKAから土地を借ります（地代）。
- アスカでの利益にはアスカの法人税がかかり、ヴェルノアでは同じ利益に二重にかけません。本社へ送る利益には源泉税をかけます。
- 進出しやすい会社の見込み（目安）：カーオーナー（ディーラー）、ジンクス（店）、Dtrade（カジノ・証券窓口）、DAIZIN（ラウンジ）、シティーワーク・スピーディード（採用）、MY WAY（ミュージアム）。MAGITA・YOSIDAは、国の調達とディーラーへの卸です。ゲーム会社は配信です。テネシスは決済と、自己資金の範囲での貸付です。

### 4-5. アスカ国立銀行（国有）

- アスカの人と国営事業への貸付は、自己資金（$0.91兆）の範囲で行います。返済と利息で、自己資金は回復します。
- 預金は預かりますが、又貸しはしません（R3）。
- テネシスは、両国の間の決済の手数料と、自己資金の範囲の貸付だけを行います。

### 4-6. アスカ国の財政ルール

- **お金は刷りません**（建国の一度だけ）。
- 国庫が足りないときは国債を出し、国民か国立銀行が自分のお金で買います。
- 景気が悪いとき（失業率・支出の落ち込み）は、ATSUKA Visionの事業を前倒しして雇用を支えます。財源は国庫と事業資金です。
- 対外収支（アスカから出ていくお金−入ってくるお金）が3か月続けて赤字なら、地代・協力費・源泉税を少し上げます。黒字なら下げるか、余剰を政府系ファンドとしてヴェルノア国債で運用します。

### 4-7. 崩壊しないこと（両国のお金の行き来）

- お金の総額は「ヴェルノア約$8.4兆＋アスカ$13兆＝約$21.4兆（＋プレイヤー）」で、ずっと変わりません。行き来するだけです。
- **アスカから出ていくお金（目安：年に持ち分の約1.5%）**：ヴェルノアで作った品物の代金、支店の利益、テネシスへの利息、アスカの人のヴェルノア旅行。
- **アスカへ入ってくるお金（目安：ヴェルノアの持ち分の約1.2%）**：素材・エネルギー、港、デジタル、リゾート、支店の地代と税。
- 両国とも、支出は持っているお金に比例します。アスカの物価は、アスカのお金の量で上下します。このため、お金の比率は一定の釣り合いへ、ゆっくり近づきます。

| 経過 | アスカのお金 | ヴェルノアのお金 |
| --- | ---: | ---: |
| 建国時 | $13.0兆 | $8.4兆 |
| 10年後 | 約$12.2兆 | 約$9.2兆 |
| 30年後 | 約$11.1兆 | 約$10.3兆 |
| 釣り合い（数十年先） | 約$9.5兆 | 約$11.9兆 |

アスカは少しずつヴェルノアへお金を渡しますが、ゼロに向かう道はなく、崩壊はしません。釣り合いの位置は、4-6の財政ルール（地代・税）で動かせます。正確な値は、第3段階の長期シミュレーションで確かめます。

### 4-8. 見込みの数字（目安）

- アスカの人の支出：年約$3,500億（持ち分の約4.5%で、ヴェルノアの市民と同じ割合）。うち約4割（年約$1,400億）が、ヴェルノア企業の支店で使われる見込みです。
- ATSUKA Visionからヴェルノア企業への調達：年約$1,000億前後（事業資金と国営事業の売上から）。
- 合わせて、ヴェルノア企業がアスカから得る売上は年約$2,500〜3,500億です。閉じた経済での13社の売上（年約$6,000億）と合わせると、設計の大きさ（「海外」があった頃の年約$1.17兆）の約7〜8割まで戻る見込みです。

## 5. 軽量なNPC（15万人）とCloudflare

- アスカの人は1日1回だけ計算します（分単位の行動・感情・人間関係・政治はありません）。1人約40バイトで、15万人で約6MBです。1日の計算は推定10〜30ミリ秒、保存は1日1回です。
- 込みの分への影響は1%未満の見込みで、「月の9割までNPCに使ってよい」枠に十分収まります。メモリも上限（128MB）の半分以下です（ヴェルノア約40MB＋アスカ約10MB）。
- 今月の使用量が75%を超えたら、アスカの計算を2日に1回にします（今の自動調整に加えます）。

## 6. 既存のシステムとの衝突（V1の15項目に追加）

V1の15項目（会社の海外の扱い、社員と給料の国別、税、在庫、カジノ、銀行の帳簿、株式、プレイヤー、地元企業、破産、新事業、街ライブ・3D、時間、検算、画面と文書の「海外」）に、次を加えます。

- **銀行の帳簿**：テネシスの帳簿は、全員の預金を映した形です。R3に合わせて「自己資金＝現金−預金」を明示し、貸すたびにこれが減ることを、帳簿と検算の両方で扱います。
- **プレイヤーのお金をマネー台帳に入れる**：全プレイヤーの$とトークン（値段で換算）をデータベースから合計し、毎日の検算に入れます。コインは$ではないので入れません（R4）。
- **本番の国の移行**：PR #84を出した時点で動いている本番の国は、旧方式（海外の買い足し）の残りを持っています。移行の締めで、売掛金は貸倒れとして消し、海外の口座は0から始めます。アスカを建国するときは、海外の口座の残高をアスカの国庫へ移します（お金は消えません）。
- **アスカ建国のタイミング**：本番では、一度だけ建国の締めで13兆を配ります。二度と起きないように、記録を残します（台帳の「建国」の行）。

## 8. 決めていただきたいこと

1. **転生した人の「生まれたときのお金」**
   - (a) 同じ式の額を、亡くなった人の遺産から払う。足りなければ国庫から払う。総額は変わりません（**おすすめ**）。
   - (b) 今のまま虚空から生む。年約$150億ずつ増え、R1の例外になります。
2. **コインで払ったVIP**
