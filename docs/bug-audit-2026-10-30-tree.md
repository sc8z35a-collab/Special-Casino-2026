## 修正した12項目

| 問題 | 影響と修正 |
|---|---|
| 木を切り替えてタップしても、待機分が前の木へ送られる | 待機する各タップに木のIDを保持し、その木へ一回ずつ送る |
| 金額の変更で待機中の投資額が変わり、残高の予約額も誤る | タップ時の金額を保持する。現在選択中の金額を回数倍する計算をやめ、送信中と待機中の実額を合計する |
| 古い木一覧が、確定した投資や収穫後の状態を上書きする | 更新時刻とローカル変更の世代を確認する。古い一覧を除外し、変更後に取得された新しい一覧は引き続き反映する |
| ログインを切り替えても前の一覧読込を再利用し、新しい木が読めなくなる | ログイン変更で読込待ちを解放する。旧要求が完了しても、新しい読込の管理状態や表示を変更しない |
| 前のログインの投資結果が、新しい残高や待機列へ作用する | 成功・失敗の両方でログイン世代を検査する。旧待機分を次の口座から送らず、旧エラーで新しい待機分も消さない |
| 旧ログインの育成・収穫待ちで操作不能になり、古い結果が次の口座へ反映される | 育成・収穫の待機状態をログイン変更で解除し、旧結果の残高・通知・演出を無効にする |
| 閉じた画面や前のログインの確認画面から育成を開始できる | 確認の承認時にもログイン、画面、対象の木、送信中状態を検査する。重複した承認から二つの開始要求を送らない |
| 木を切り替えた後、前の木の収穫・成長演出が別の木へ出る | 対象の木が現在表示されている場合だけ、その要素へ演出を出す。収穫結果から別の木の次回設定も消さない |
| 競り参加後に古い「参加なし」の応答が届くと、新しい競りが消える | 競りの変更前に開始した一覧・ポーリング応答を除外する。対象ID・時刻・終了状態の既存の逆行防止も維持する |
| ログイン変更後に競りへ参加できず、旧参加結果が戻ってくる | 参加・入札・ポーリングの待機状態を解除し、旧要求の成功・失敗・確認結果を無効にする。落札した木への遅延した画面移動も現在のログインだけに反映する |
| 観戦ベットが進捗保存失敗でも成立し、再試行できなくなる | 賭け金、ベット枠、進捗、VIP昇格に伴う給与精算を同じトランザクションへ入れる。失敗時は枠と賭け金を保持し、確定通知を送らない |
| ハブ参加が進捗保存失敗でも成立し、招待が消える | 招待の消費、新規ハブ、所属の変更、参加者と招待者の進捗をまとめて確定する。どちらの進捗が失敗しても、招待と所属を保持して再試行できる |
