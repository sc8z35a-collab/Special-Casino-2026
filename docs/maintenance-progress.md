# 既存機能の保守修正（2026-10-27）

対象は依頼された12項目。追加ゲーム、メダル、称号は対象外。この文書は前段の検証記録。追加対応と配信用ビルドは [最新の全対応表](optimization-progress-2026-10.md) を参照。

| # | 項目 | 対応 |
|---|---|---|
| 1 | パスワード変更時の失効 | 自分・運営・CLIからの変更で全旧セッションと旧引き継ぎコードを失効。接続も終了。変更元には新トークンと新コードを返す。別プロセスのCLI変更もNodeのハートビート（最大25秒）で接続へ反映。並行変更や古い401で新ログインが消える競合も防止。 |
| 2 | RTP・配当の検算 | 全16,807通り×全10ベット額を通常・ハブ双方で列挙し、別計算の二項分布による期待配当と一致させる。抽選境界、複数当たりの加算、演出区分、通信時の圧縮・復元も確認。 |
| 3 | 軽量演出 | 既存の全演出オフとは別に保存可能な軽量設定を追加。描画30fps、リール解像度上限0.8、当たり演出上限0.75、粒子数約1/4。物理更新・停止・結果・配当は維持。 |
| 4 | 石碑の増分検証 | 検証済みアンカーを永続化。以降最大20区間と、以前の抜き打ち3区間・接続確認を検査。日次全量読み直しを廃止。名前の一覧による欠損検知と、手動の全量検査・復旧は維持。 |
| 5 | HTTP専用ルート | `js/net/transport-policy.js` をブラウザーとサーバーの両方が読み込む。認証・課金・LINE・Vault書き込みのHTTP固定と、チャットの同一フィルターを維持。 |
| 6 | messages／transfers | 下記の保存期間・保護条件を実装。退避中も履歴画面から参照可能。バックアップにも退避表・IDカウンターを含める。 |
| 7 | 通話の動的品質 | ゲームと運営通話が同じ制御器を利用。3秒ごとのローカル統計から損失・RTT・帯域を評価。悪化時に段階的に削減、安定3回で段階的に復帰。VIP／TURBO上限、通話終了時の解放を維持。 |
| 8 | スピンの冪等性 | アカウント＋受付番号で結果を永続化。ベットと結果保存を同じトランザクションで処理。重複はレート制限より先に保存結果を返し、金額変更は拒否。現行クライアントは再送時に同じ番号・内容を利用。 |
| 9 | アカウント別ロック | 正規化した名前ごとに15分で5回失敗すると15分ロック。IPを変えても再起動しても保持。正しい認証・引き継ぎコードで解除。既存のIP制限も維持。 |
| 10 | 課金専用テスト | 既存7件を `pay.test.js` へ移動し、Vaultテストを分離。並行通知・通知順序・返金・識別情報・署名の生バイト等を追加。不一致のユーザー識別情報で付与されるケースを修正。 |
| 11 | 起動時の重複検出 | ルート登録を集約。coreの定義内重複とモジュール間重複を全件列挙して起動を拒否。既存6件の意図的ラップは明示して記録。302ルートに重複なし。 |
| 12 | バージョン単一ソース | 既存のDEV番号元 `js/game/news.js` を継続利用し、生成される `version.json` と `BR.VERSION` に同じ値を収録。APKの公開情報・コミット・公開表示はGradleが出力したバージョンを利用し、CIでの再計算を廃止。 |

## 保存期間

| データ | 通常表 | 退避表を含む保存期間 |
|---|---|---|
| メッセージ | 90日 | 原則365日 |
| ゲーム内通貨の送金履歴 | 365日 | 1,095日 |

- `message_archive`／`transfer_archive` は同じDB内の退避表。外部バックアップではない。`message_history`／`transfer_history` の読み取りビューで保存期間内の履歴を表示する。
- 未受取・保留中の報酬、未決済の車販売、未読、会話・グループの最新プレビュー、通報・検知からの参照は期間にかかわらず保護する。未知のカード種別も自動削除しない。
- 課金記録、運営・セキュリティログ、保管庫のファイルは今回の削除対象ではない。
- 退避・削除は最大500件ずつ。同一トランザクションでまとめて処理し、失敗時は元データを残す。通常は1時間に一度、残件が多い間は次のhousekeepingで続きを処理する。
- IDは退避後・削除後も再利用しない。管理画面からの文面削除は退避済みメッセージにも適用する。
- DBのバックアップ・復元には退避表とIDカウンターを含める。今後messages／transfersへ列を追加する場合は、対応する退避表にも同じ列を追加する。

## 運用上の境界

- スピンの受付番号は発行時刻付きで24時間有効。期限後は保存結果の削除後も再ベットを拒否する。古いインストール済みクライアントのキーなし要求は互換性のため従来通り受け付ける。現行クライアントは常にキーを送る。
- 基本配当の検算値は通常81.999535421%、ハブ107.746247741%。連続当たり・VIP・お守り等を含めた最終的な払い戻し率ではない。確率・配当の設定は変更していない。
- 通話で統計や送信パラメーター操作に対応しないブラウザーは、従来のWebRTC制御を継続する。下限は16kbps、上限は通話の既存設定。
- 石碑の抜き打ち検査では、変更された古い区間を必ず当日中に検出する保証はない。欠損の一覧検査・署名検証・手動全量検査は残している。
- DEV番号、配布物のビルドハッシュ、Androidアプリのバージョンは役割が異なる。今回DEV番号自体は上げていない。
