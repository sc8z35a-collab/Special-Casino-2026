# 木・車の収益・ブロック・通話・競りの追加監査（2026-10-29）

基点は PR #62 を取り込んだ main `b175d157d0fea3352e775c55a7f09154f320c790`。使い捨てアカウントで初回処理の順序、保存途中の失敗、古い要求、ブロック後の通信を再現した。本番の資産やアカウントは検査用に変更していない。

## 修正した9項目

| 問題 | 影響 | 修正 |
|---|---|---|
| ガチャを先に受け取ると無料の木を失う | 木画面を開く前に種・成熟木を使う、または成熟木を直接当てると、その木が最初の無料1本の代わりになった | 無料木の初期化を共通化し、賞品と同じトランザクションで先に確保。成熟木が上限を超える分は従来どおり在庫へ保持 |
| 車の贈与時に貸出収益が画面へ反映されない | 未受取の貸出収益は贈与時に入金されるのに、残高通知がなかった | 入金後の残高を一度通知。カード保存失敗時は資産と通知をともに戻す |
| 削除済みアカウントのガチャ応答が残る | 通常スピンの再送記録は削除されるが、名前・プロフィール・残高を含むガチャの応答は残った | アカウントデータの消去対象へガチャ再送記録を追加。他人の記録は保持 |
| 古い競りへの操作が次の競りに作用する | 遅延した入札・離脱が、その時点で参加している別の競りに適用された | クライアントが対象の競りIDを送り、サーバーが変更前に照合。確認画面と応答処理も元の競りに結び付ける |
| ブロック中でも入力中通知が届く | HTTP・ライブ接続の両方で、ブロックした相手の入力状態が届いた | 直接会話の入力通知を双方向のブロック条件で止める |
| チャット停止中でも入力通知を送れる | 直接会話・グループの入力通知にチャット停止の判定がなかった | 両経路でチャット停止を確認し、HTTPは拒否、ライブ通知は送らない |
| ホーム通話がブロックを無視する | ホームの通話信号にブロック判定がなく、接続済みの通話も続いた。他端末や再接続でブロック状態が反映されなかった | ホーム・ハブ共通で信号を遮断。本人の端末だけへ状態を通知し、その相手との接続を閉じる。他の参加者との通話を維持し、再接続にも本人のリストを適用。古い応答は状態の改訂番号で除外 |
| アカウント変更後に古いホーム通話が復活する | 全通話を終了しても、ハブ終了時に戻るホーム情報が残った | ログアウト・新しいログインで通話、復帰先、停止状態、ブロック情報を一括解除 |
| ブロック解除の途中失敗でブロックだけ外れる | 旧形式の保留送金の解放が残高上限で失敗すると、保留を残したままブロックだけ解除された | 解除・保留の解放・本人への通知を一括確定し、失敗時はブロックを保持 |
