# 功績：裏メダル（非公開）

このファイルはリポジトリにだけ置く非公開の資料です。`docs/handbook/` と `README_DEV_NEWS.md` は運営サイトのDEV UNIT用に `ops/assets/` へ写され、そこはログインなしでも取得できるため、裏メダルの名前・条件・存在はそちらに書かないでください。ゲームのファイル（`js/`・`css/`・`index.html`）のコメントにも書きません。定義の正本は `server/core/medals.js` です。

裏メダルは取得可能の一覧にもAPIにも出ず、獲得した人のコレクションにだけ、ほかのメダルと同じレア度順で現れます。画像のファイル名は意味のない16進数（`img/medals/<12桁>.webp`）で、未獲得の人に名前や画像のURLが送られることはありません。持っていない裏メダルを受け取ろうとしても、存在しないメダルと同じ答え（404 `no_medal`）になります。

## 決まり

- 抽選はサーバーの鍵（`ticket_secret` から `keyFrom(secret, 'medals')`）とアカウントIDのHMAC-SHA256で決まる、アカウントごとに一度きりの値（0.1%と0.01%は別々の値）。既存のアカウントも初回の集計で一度だけ見ます。何度計算しても同じで、鍵がなければ誰が当たるか分かりません。
- 「◯人目」はNPCを除いたアカウントの登録順（IDの順。削除済みのアカウントも順番に数えます）。初回の集計のときに一度だけ見ます。
- 周年記念メダルは、その日の0:00（日本時間）からの接続で、その日の終わりまでに登録していた人に付きます。
- ガチャの回数（`users.gacha_pulls`）はこの版から数えます（それより前の記録はありません）。無料券の分も数えます。
- 最強トレーダーのシークレットアイコンは、`js/game/config.js` の `given: true` の10種から、そのプレイヤーが持っていないものを3つランダムに選びます（3つ未満しか残っていなければ残り全部）。シークレットオーラは `users.aura` を1にし、`mini`・プロフィール・フレンド一覧で `aura` として他の人にも伝わります。
- 投資の上限が2社合計$8Mのため、$8500Mは数年単位の目標です。
- 検証は `server/test/medals.test.js`（30人目・抽選・開発者・周年・メニメニトレジャーハンター・最強トレーダーの報酬）。
