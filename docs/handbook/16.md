### LINE に通知する（LINE ボット）

Discord と **同じ内容** を LINE にも送れます（緊急停止・ロックダウン・攻撃元の自動ブロック・通報・課金・パスキーの入力ミスなど。【危険】の知らせには運営サイトと security HOME の URL が付きます）。さらに、運営の方が LINE のボットに **「パスキー」** と送ると、今日のパスキー（上の「パスキー認証を始める」）が返信されます。

LINE は **1 か月に送れる数が決まっています**（無料の「コミュニケーションプラン」は月 200 通。送信先の人数分が数えられ、**返信は数えません**。超えると LINE が送信を断ります）。そのため、危険な知らせはすぐに、ふつうの通知は数分まとめて 1 通にして送り、**ふつうの通知は枠の 6 割まで**、危険な知らせは枠の最後まで使います。送らなかった数は次の通知に添え、枠が残り少ないことは Discord に知らせます。今月の数は運営サイトの「サーバー」タブの「LINE 通知」で見られます。

設定（LINE 側はあなたの操作です。画面の名前は 2026 年 10 月時点の LINE Developers の説明に合わせています）:

1. **LINE 公式アカウントを作る**: [LINE Official Account Manager](https://manager.line.biz/) で Business ID を登録し、LINE 公式アカウントを作ります（2024 年 9 月 4 日から、LINE Developers Console だけでは Messaging API のチャネルを作れません）
2. **Messaging API を有効にする**: LINE Official Account Manager の設定から Messaging API を有効にし、プロバイダーを選ぶ（なければ作る）と、チャネルが [LINE Developers Console](https://developers.line.biz/console/) に作られます
3. LINE Developers Console で、そのチャネルを開いて控える:
   - 「チャネル基本設定」タブの **チャネルシークレット**
   - 「Messaging API設定」タブの **チャネルアクセストークン（長期）**（「発行」で作ります）
4. Cloudflare の Worker の「設定 → 変数とシークレット」で、シークレット `LINE_CHANNEL_SECRET`（チャネルシークレット）と `LINE_CHANNEL_ACCESS_TOKEN`（チャネルアクセストークン）を入れて再デプロイ
5. 「Messaging API設定」タブで **Webhook URL** を `https://（公開URL）/api/line/webhook` にして更新し、**「検証」** が成功することを確かめ、**「Webhookの利用」をオン** にします
6. 同じタブから LINE Official Account Manager を開き、**「応答メッセージ」と「あいさつメッセージ」をオフ** にします（ボットの返事と重なるため）
7. 同じタブの **QR コード** でボットを友だち追加し、LINE で **「ID」** と送ると、あなたのユーザー ID（`U` で始まる 33 文字）が返ってきます（「チャネル基本設定」タブの「あなたのユーザーID」にも出ます）
8. `LINE_STAFF_USER_IDS` に、パスキーを受け取る運営の方のユーザー ID を（複数はカンマ区切りで）入れて再デプロイ。通知は、`LINE_NOTIFY_TO` を入れなければ、その **先頭の 1 人** に届きます（送信先が増えると、その人数分、月の枠を使います）。**公開配信モードではコマンドに返信しません。** 今日の一枚・週次コイン・更新通知とガチャについては [README_LINE_FEED.md](../../README_LINE_FEED.md) を参照してください。
9. 運営サイトの「サーバー」タブの「LINE 通知」が「オン」になります。開発者は **「テスト送信」** で届くか確かめられます。LINE のボットに「パスキー」と送って、返信が来れば完了です

注意:

- チャネルシークレットとアクセストークンは人に見せないでください（漏れたら、LINE Developers Console で再発行します。アクセストークン（長期）は 1 チャネルに 1 つで、再発行すると前のものは使えなくなります）
- グループやルームには、パスキーを返信しません（ほかの人にも見えるため）。ボットとの 1 対 1 のトークで送ります
- LINE の呼び出しは、チャネルシークレットでの署名で本物かを確かめます（LINE 側の IP アドレスは公開されていないため）
- ロックダウンや緊急停止の最中も、ボットはパスキーを返信します（security HOME から解除するため）
