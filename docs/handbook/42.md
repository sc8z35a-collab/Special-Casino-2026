### 景気の波と物価・GDP・45社の日次収支・企業と国の自律

この章は、会社と国が自分で決めること、MY WAYの経営理念、ガチャの景品の負担、運営サイトの新しい統計（本日の稼ぎ・45社の日次収支・GDP・景気と物価・アスカ国のリアルタイム）をまとめます。どれもお金を新しく生みません。マネー台帳のずれは毎日$0のままです。

#### ガチャの景品は、すべて誰かが買って渡す

- ガチャは2枠です（`js/game/gacha.js` の `SLOTS`）。一連の値段は、レア$4.5M、レジェンダリー$27M、シークレット$45Mです。
- プレイヤーが払った額の8割は管理会社YOSIDAの売上、2割は国庫（`gachaShare`）です。
- 景品は、それぞれの会社が自社の費用（「ガチャ景品の提供（自社負担）」`sGacha`）で用意して、すぐにプレイヤーに渡します。
  - ロットコイン：Dtrade
  - ロイヤルコイン・VIP一週間券：DAIZIN（VIP券は原価1枚$50K）
  - 金の生る木の種・成長済みの木：YOSIDA（原価$4M・$5.5M）。木がすでに上限までそろっているプレイヤーには、代わりにYOSIDAが$3Mを払います。
  - リセットチケット：YOSIDA（原価$1.0M）
  - ガレージコイン：MAGITA（原価$1M）
- プレイヤーは景品を売れます（`POST /api/gacha/sell`）。VIP一週間券は$200K（DAIZIN）、リセットチケットは5時間$250K・24時間$350K（YOSIDA）、ガレージコインは$350K（MAGITA）です。会社の「プレイヤーからの買い取り」（`c:rebuy`）になります。
- MAGITA Garageの月額は、**使っている場所の分だけ**です（`garagebill.js`。空いている場所は数えません）。

#### 運営は値段・金利・給与を決めない

運営サイトの「国の決まり」は表示だけになりました（`POST /api/ops/npc/knob` は 410）。範囲（上限・下限）もありません。

- **国の決まり**（税・年金・予算など）：街の議会と市民投票が決めます。
- **Dtradeの手数料・求人サイトの手数料**（`corp-model.js` の `feesMonth`）：直近3か月の利益率が計画に届かなければ5%上げ、計画の1.5倍を超えたら3%下げます。
- **MAGITAの特別費用・ガレージ料金**：MAGITAが業績に応じて決めます。
- **テネシスの金利**（`npc-org.js` の `rateReview`）：毎月1日の「金利決定会合」で決めます。
  - テイラー則に向けて、1か月に最大1ポイントずつ動かします。テイラー則は、中立金利＋目標インフレ率＋（インフレ率−目標）×1.5＋景気の差×0.5です。インフレ率は、今の勢いと1年の実績の平均を使います。
  - 自動車ローンは個人向けの0.5ポイント下です。クイックローンは個人向け＋リスク分で、延滞が多いと広がり、少ないと狭まります。
- **給与**：会社が決めます。春闘、MY WAYの毎月の昇給、人手不足の上乗せがあります。

#### 人手不足の会社は、ほかの職場から人を採る

`npc-labor.js` の `shortage`：

- 失業者のほとんどいない国では、あとから来た会社（MY WAY・WAZIMA）が採用できずにいました。
- 人が足りない会社と地元企業は、足りない日が続くほど提示する給与を上げます（1日0.2%ずつ・上限なし）。
- 採る相手は、小さな商店で働く人・自営業・パート（今より1割以上よい場合）、家事中心の人（22〜59歳）、まだ元気な退職者（60〜69歳・給与は65%）です。
- 地元企業の社員数は毎日数え直します。

#### MY WAYの経営理念（`CORP.myway.philosophy`）

- **社員を一番に大切にする**
  - 赤字が4四半期続くまで、給料を下げません（予算も削りません）。
  - 売上が伸びると毎月昇給し、景気がよいほど速く上げます。上げ幅は社員ごとに違います（0.5〜1.5倍）。
- **利益をため込まない**
  - 配当性向は90%で、景気に関係なく一定です。
  - 計画の利益率の4割をめざして、投資トレード・社員還元・福祉・設備・研究・宣伝・事業運営に使います。予算は1か月に最大30%、最初の12倍まで増やします。
- **MY WAY経済圏を支援する**（`mywaySphere`）
  - 毎月、利益の25%（少なくとも経済圏の企業の売上の1割）を、経済圏の地元企業に支援します（売上が落ちた会社ほど多く）。
  - 経済圏の企業は社員を解雇しません。支援を受けた月は採用目標を増やし、3か月分の費用を超える手元資金の2割を毎月成長に投資します。

#### 本日の稼ぎ（運営サイトの各社のトップ）

- 「本日の収入（売上高＋投資＋その他の利益）」を表示します。内訳は次の3つです。
  - 売上高：経営陣の見込みを経過時間で積み上げ、プレイヤーと市民のお金は実額で数えます。
  - 投資で入った資金：プレイヤーがその日に買った新株・自己株式の処分の実額です（`s.liveIn`）。
  - その他の利益：受取利息・配当・子会社の利益・援助金・売却益など。直近30日の平均の1日分を、経過時間で積み上げます。
- 投資で入った資金は純資産に入るお金なので、営業利益・当期純利益には入れません。その他の利益は当期純利益に入ります。
- 日の行（`corp_days`）にも `invest`（投資の入金）・`back`（買い戻し）・`other`（営業外収益＋特別利益）を記録します。

#### 日次収支レポート（45社）

- 運営サイトの「企業」フォルダーの「日次収支レポート（45社）」から開きます（`GET /api/ops/corp/report`。締めごとに変わり、`rev` で `{ same: true }`）。
- 13社は日の行から、地方企業32社は毎日の記録（`npc-local.js` の `report`）から表示します。地方企業の記録は、売上・費用・社員の年収の日割り・営業損益・MY WAYからの支援・手元資金です。
- 表示するもの：前日の売上・費用・営業損益・売上の前日比・純利益・現金、14日分の営業損益の棒、ひとこと（増収・減収、黒字・赤字、投資の入金、支援）、45社の合計。
- 「全45社」「上位13社」「地方企業」「前日赤字の会社」で絞り込めます。

#### GDP（国内総生産）

`server/core/npc-gdp.js`：両国のGDPを毎日、支出面（消費＋政府＋投資＋輸出−輸入）で数えます。

- **消費（C）**：市民が買ったもの（消費税込み）＋プレイヤーが会社で使ったお金です（`npc-econ.js` の `pay` で数えます）。
  - 年金・健康保険の保険料とカジノの賭け金は、買い物ではないので数えません。カジノは「負けた分＋手数料」を数えます。
- **政府（G）**：公務員の給与・医療・区の購入です。
- **投資（I）**：13社の設備（アスカ国の拠点の建物はアスカ国の分）・ゲームの開発（コンテンツ）・地元企業の投資・公共事業です。
- **輸出・輸入（X・M）**
  - 輸入は買ったときに数えます。アルタス・アスカ・デジタルへの未払いの増減を含め、ツケの支払いは輸入にしません。
  - アスカ国の支店の生産はアスカ国の分です。支店がアスカで買った資源は、アスカ国内の取引です。
  - ヴェルノアの輸入とアスカ国の輸出は1ドルまで一致します。
- **実質**：建国時の物価で数えます。ヴェルノアは物価指数、アスカ国は物価（`policy.price`）を使います。
- 直近400日を日ごとに、5年分を月ごとに国と一緒に保存します。
- 運営サイトの「街」→「国」と「アスカ国」に表示します。表示するもの：前日・今月・前月・今年（暦年）・前年、直近365日、直近12か月の前年比、直近30日の年率、1人あたり、直近90日の棒。

#### 景気の波と物価（インフレ・デフレ）

`server/core/npc-macro.js`：誰も決めない「世の中の景気」（`mood` −1〜1、支出への効き `boom` 0.7〜1.65）と物価指数（`W.cpi`）・家賃指数（`W.rentIdx`）を、毎日動かします。

- **景気をふくらませるもの**（それぞれ効きすぎないよう頭打ちあり）
  - 消費の勢い：1年の平均と比べます。物価だけで増えた分は除き、1年分そろうまでは控えめにします。
  - 株価の90日の上昇、借入の伸び、失業率が1年平均より低いこと、景気自身の噂（群れ）。
- **しぼませるもの**
  - 中立より高い金利と、上のものの逆です。
  - 長く続いた好景気・不景気の「疲れ」（直近4か月の景気）もしぼませます。
- **物価**：予想インフレ率（見えたインフレに1年かけて近づき、同じ速さで目標に引き戻されます）に、需要・雇用・景気・アルタスの資源価格の勢いを上乗せして動きます。デフレもあります。家賃は好景気でより上がります。
- 物価は次のところに効きます。
  - 生活費・光熱費・家賃
  - 市民の会社での支出（`spendAt`。高いと少し控えます）
  - 地元企業の費用
  - 国の物価（`stats.prices`）、春闘とテネシスの金利
- **好景気・バブルのとき**（不景気のときは逆。不景気が減らす分は、好景気が増やす分より小さめ）
  - 市民：収入のより多く（最大110%）と貯金から使い、カジノ・遊び・株への投資が増えます。大胆な人・ニュースに流される人ほど強く、慎重な人はほとんど変わりません（`budgetOf`）。
  - 会社：低い利益率で満足して予算を速く増やし、配当性向を上げます（`payoutOf`。MY WAYは理念どおり）。月末には、手元資金のうち（6か月÷景気）分の費用を超える分の一部を設備に投資します（`boomSpend`）。投資するのは自分のお金だけで、純資産の1割までです。銀行（預金者のお金）は投資しません。
  - 国：国庫の余裕を早く使い、手元に残す額を減らし、交付金も増やします（`publicWorks`）。
  - 地元企業：6か月分の費用を超える手元資金の一部を投資します。
  - MY WAY：昇給を速めます。
- 1,500人の国（アスカ国4,500人）を3年動かすと、次のような波になりました。
  - 好景気でインフレ率は年10%近くに上がり、テネシスは金利を16%台まで上げました。
  - その後の景気後退・恐慌でデフレ（−4%前後）と失業率5%台になり、金利は0まで下がって、ふたたび回復しました。
  - マネー台帳は$0のままです（株価を整数にした検証）。
- 運営サイト：「街」→「国」の「景気の波と物価」、「企業」フォルダーの見出しの「世の中の景気」に表示します。

#### アスカ国のリアルタイム

`server/core/asuka.js` の `tick`：アスカ国の人も、ヴェルノアの人と同じ1分ごと・同じ時間帯（平日11:00〜22:00、休日9:00〜22:00）に動きます。

- **1日の動き**
  - 平日：ATSUKA Visionと地元の商売と支店の人は仕事に行き、昼食を外でとります。学生は学校に行きます。
  - それ以外の人と休日：買い物・レジャー・家で過ごします。22時までに家に帰ります。
- **お金**
  - 1日の初めに、その日に要るもの（生活費）・使うつもりのお金・拠点が売れる量を決めます。
  - 外出のたびに、要るものを払い、使うつもりのお金の一部で買い物をします。1ドル単位で、その場でお金が動きます。
  - 締めでは、外出しなかった人の生活費も払います。使わなかったお金は手元に残ります。
- **保存**：その日のうちに動くもの（お金・何をしているか・残りの予算）は、ヴェルノアの人と同じく保存のたびに記録します（`asukahot`）。以前に保存された国も、そのまま読めます（新しい列は0から始まります）。
- 運営サイトの「街」→「アスカ国」に「アスカ国の今（リアルタイム）」を表示します（`GET /api/ops/npc/asuka`。10秒ごと）。内容は、区ごとに何をしている人が何人いるか、今日の生活費・買い物・消費税・外出の回数、国民の預金・国庫・ATSUKA Visionなどです。

#### 市民の株の注文の修正（`npc-market.js`）

- 同じ人が同じ株に売り注文を何本も出していると、それぞれが持ち株までしか売らない確認しかしていませんでした。そのため、合計で持ち株を超えて売れていました。
- 持ち株がマイナスになると、取得単価の加重平均と譲渡益税が天文学的な額になり、2年目に国が止まっていました（main の頃からの不具合）。
- 1人の注文の合計を、持ち株・手持ちの現金までに抑えるようにしました。相続・国庫に帰属する株もマイナスにならず、保存されていた国のマイナスの持ち株は読み込み時に0にします。
