## オンライン機能

| 機能 | 内容 |
| --- | --- |
| 登録 | ユーザー名（2〜12 文字）とパスワード（4 文字以上）を決め、アイコンを選ぶだけ。**ほかの人と同じ名前は使えません**（大文字・小文字や全角・半角の違いも同じ名前として扱います）。入力中に「使えます / すでに使われています」がわかります |
| ログイン | 機種変更やデータ削除のあとは **ユーザー名＋パスワード** でログインすると、残高・フレンド・車がそのまま戻ります。パスワードを忘れたときは登録時の **引き継ぎコード**（16 文字）でもログインできます（ログイン画面・新規登録画面の「引き継ぎコード」から。自分のプロフィールの「コードでログイン」でほかのアカウントに切り替えも可） |
| 端末ごとの上限 | **1 つの端末で作れるアカウントは 2 つまで**。3 つ目を作ろうとすると「前に作ったアカウントの引き継ぎコードを入力して」と引き継ぎコードの画面になります。端末は、ブラウザの 4 か所（localStorage・Cookie・IndexedDB・Cache Storage）に保存したランダムな ID と、端末の特徴（画面・CPU・メモリ・言語・時間帯・GPU・文字の描画）から作る指紋で見分けます（指紋は同じ回線からのときだけ照合）。`ACCOUNTS_PER_DEVICE` で変更可 |
| Google / Discord ログイン | 新規登録の画面とログインの画面に **「Googleで続ける」「Discordで続ける」**（本物のロゴ）。**新しく始める人**はそれで認証したあと、ユーザー名とアイコンだけ決めます（パスワードなし。引き継ぎコードは今までどおり出ます）。**すでに遊んでいる人**は、プロフィール →「ログイン」の中の **Google / Discord のマーク** から連携でき（連携済みは緑のチェック・もう一度押すと解除）、次からそれでログインできます。**Google や Discord の側の名前・メールアドレスは受け取らず**、それぞれの「見分けるための番号」（と Discord の表示名）だけを持ちます。**1 つの Google / Discord は 1 人のプレイヤーだけ**、1 人のプレイヤーに付けられるのは Google・Discord それぞれ 1 つずつ。**端末ごとの上限はそのままです**（Google / Discord で新しく始めるときも、同じ端末で作れる数に数えます。連携やログインは数えません）。BAN・削除されたアカウントは、Google / Discord でも入れません。設定は下の「Google / Discord ログインを始める」（未設定のうちはボタンが出ません）。 |
| 利用停止 | 運営サイトから **アクセス禁止**（1 週間で自動解除）・**BAN**（30 日で自動解除）・**永久BAN**（解除するまで）。どれもいつでも解除できます。BAN・永久BAN のたびに、そのプレイヤーが使った端末のほかのアカウントもアクセスできなくなり（新しいアカウントも作れません）、運営は個別に外せます。止められた人はすぐにログアウトされ、ログイン画面に理由と期限が表示されます |
| アイコン | 提供画像の14種類。緑背景の旅人だけ無料。青 $100K・紫 $350K・金色 $600K・赤 $950K・水色 $1.2M・グラデーション背景のシークレット $2.1M の固定価格。プロフィールの「アイコン変更」で購入できます。アイコンのセール・鎖・ロック表示は廃止。既存プレイヤーのアイコンと旧アイコンの所有情報は初回移行時に緑の旅人へ統一されます。以後の購入・選択は再起動しても保持されます |
| 通貨の見た目 | ロイヤルコインは赤い宝石付きの金色コイン、スロットコイン（スピントークン）は赤白のコイン、ドルは緑色の札束。残高・報酬・購入確認など共通の通貨アイコンに適用 |
| フレンド | 最初は 0 人。フレンドタブの検索で **ユーザー名をそのまま入力**（完全一致）→「フレンド申請」。相手が承認すると「〜さんからフレンド承認されました」と通知が届き、会話できるようになります。お互いに申請した場合はその場でフレンドになります。一覧とメッセージではアカウントを大きく表示し、**アイコンをタップするとその人の名刺（プロフィール）**。各行のボタンは「一緒に稼ぐ」だけで、ほかの操作（観戦・対決・メッセージ・プロフィール）は **「⋯」** にまとめています |
| 初心者ガイド | プレイ時間 30 分未満で、まだガイドを終えていない人には、最初に遊び方の案内（約 2 分）が表示されます（ホーム画面のボタン → SPIN を実際に回す → メニューの各タブ → 戻る）。右上の「スキップ」を 2 回タップすると終わりにできます。メニュー →「詳細」からいつでも見直せます |
| メニュー | 三本線のボタンから。フレンド・メッセージ・Car Owner（ガレージ）・Shop（所有）・バイト・詳細（初心者ガイド・フィードバック・投資・Dev News）。「戻る」はどこからでも 1 回でホームに戻ります |
| メッセージ | 文字を打つときは **画面はそのまま**（青空の背景・文字の大きさも同じ）で、入力欄がキーボードのすぐ上に出ます（会話の終わりが入力欄の上に見えるように、ゲーム画面がその分だけ上がります。キーボードをしまうか「←」で元に戻ります。ハブやホームのチャットのように画面に置き場のない会話は、入力欄の上にすりガラスで出ます）。フレンドとの 1 対 1 チャットと **グループチャット**（「＋ グループを作る」で名前とフレンドを選ぶ、20 人まで）。相手が読むと自分のメッセージに「既読」（グループは「既読 2」のように人数）、相手が書いている間は「○○さんが入力中…」。メッセージの通知をタップするとそのチャットが開きます。送金・アイテム・車のカードは送った側に寄せて表示。メッセージは 6,000 文字まで（超えると送る前に「送信できません。大きすぎます。」）。チャットを開いている間も上のボタンはすべて残り、「‹ 一覧 メッセージ」で一覧に戻ります。未読数はメニューボタン（三本線）とタブにバッジで表示。メッセージの下の **「⋯」**：コピー、自分のメッセージは **送って 1 時間以内なら何度でも送信を取り消し**（相手の画面からも消える。運営サイトとログには元の文が残る。お金・車・アイテム・プレゼントは取り消せない）、相手のメッセージは **そのメッセージだけを通報**（DEV9） |
| 受け取り（DEV9） | 友達・Ice Smoker公式・ジョンソンから届く **お金・車・アイテムは、チャットのカードをタップして初めて受け取れます**（送った側には「まだ受け取られていません」→「受け取られました」）。車はタップまで誰のものでもなく、ガレージがいっぱいなら空きを作ってから。アイテムは上限まで。アップデートの感謝料もお知らせの「受け取る」で。受け取らないまま相手のデータがプレイヤーアーカイブから削除されると、送った人に戻ります（カードに「あなたに戻りました」と出ます）。Ice Smoker公式・マイクソン・ジョンソンには何も送れません |
| 自動フィルタリングシステム（DEV9） | チャット（メッセージ・グループ・ホームのチャット・即席チャット・報告・意見案・通報）に **テキスト以外のもの**（ゲームが送らない項目、文字ではないデータ、data: URL、base64 の長い列、大量の制御文字、大きすぎるデータ）を無理やり送ろうとすると、**サーバー本体に届く前**（Cloudflare の Worker / Node の入口）にブロックし、**ログの「緊急」** にわかる限りの情報（送信先・理由・項目名・大きさ・ハッシュ・IP・端末）を書いて、**その人のチャットを止めます**（開発者は止めない）。運営サイトのプレイヤーに **「チャット停止」バッジ**、詳細の「チャット停止を解除」で戻せます。止まっている間も Ice Smoker公式へは送れます（中身は保存しません） |
