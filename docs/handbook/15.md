### Discord に通知する

（LINE にも同じ内容を送れます。次の「LINE に通知する」）

開発者がすぐ知りたいことを、Discord のチャンネルに送ります：**緊急停止とロックダウン（とその解除）・セキュリティシールドによる攻撃元の自動ブロック・自動フィルタリングによるチャット停止・通報・報告／意見案・開発者支援の入金と返金と確認が必要な注文・不正な決済通知・開発者コードの入力ミス・運営権の付与と剥奪・自動バックアップの失敗・共有保管庫の容量の申請（開発者の承認待ち）・新しい版の本番反映**（反映のあと最初のアクセスで届きます）。
**ゲーム・運営サイト・サーバーが危険な状況**（緊急停止・ロックダウン・攻撃元の自動ブロック・画面を見る機能の強制終了）のときは **【危険】** を付け、何がどれだけふだんを超えたか・理由・多いアドレスや API などの状況をできるだけ詳しく書き、**運営サイトと security HOME（`/sec/`）の URL を両方** 添えます。ふつうの通知は運営ログと同じ 1 行の要約と運営サイトへのリンクだけ（チャットの文面は送りません）。近い時間のものは 1 通にまとめ、1 分に 20 件を超えた分は件数だけ知らせます。誰かへのメンション（@everyone など）にはならず、リンクのプレビューも出ません。

1. Discord で通知を受け取るサーバーの **サーバー設定 → 連携サービス → ウェブフック → 新しいウェブフック**。チャンネルを選んで **ウェブフック URL をコピー**
2. Cloudflare の Worker の「設定 → 変数とシークレット」で、シークレット `DISCORD_WEBHOOK_URL` にその URL を入れてデプロイ
3. 運営サイトの「サーバー」タブの「Discord 通知」が「オン」になります。開発者は「テスト送信」で届くか確かめられます

Webhook の URL を知っている人は誰でもそのチャンネルに書き込めるので、人に見せないでください（漏れたら Discord でそのウェブフックを削除して作り直します）。
