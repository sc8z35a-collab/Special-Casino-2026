### Google / Discord ログインを始める

新規登録とログインに「Googleで続ける」「Discordで続ける」を出すための設定です（コードは入っています。**設定が入るまでボタンは出ません**）。ゲームの公開 URL を `https://blockbuster-reels.sc8z-35a.workers.dev` として書きます（別の場所で公開しているときは、そのアドレスに読み替えてください）。**戻り先（リダイレクト URI）は、両方とも `https://blockbuster-reels.sc8z-35a.workers.dev/api/oauth/callback`** です（1 文字違っても動きません。最後に `/` は付けません）。

**1. Google（Google Cloud）**

1. <https://console.cloud.google.com/> を開いて Google アカウントでログインし、上のプロジェクト選択から「新しいプロジェクト」を作ります（名前は何でも構いません）。
2. 検索欄で「Google Auth Platform」を開き、「始める」を押します。アプリ名（例: `Two state Casino RP`）・ユーザーサポートメール・対象は **「外部」**・連絡先メールを入れ、同意して「作成」。
3. 左の「クライアント」→「クライアントを作成」。アプリの種類は **「ウェブ アプリケーション」**、名前は何でも構いません。**「承認済みのリダイレクト URI」に上の戻り先を 1 つ追加**して「作成」。表示される **クライアント ID** と **クライアント シークレット** を控えます（シークレットは後から見られない画面もあります。控え忘れたら新しいものを作れます）。
4. 左の「対象」を開き、**「アプリを公開」（本番環境にする）** を押します（「テスト」のままだと、あなたが登録したテストユーザーしかログインできません）。使う権限は「openid」だけなので、Google の審査は要りません。

**2. Discord（Discord Developer Portal）**

1. <https://discord.com/developers/applications> を開き、パスキー認証に使っているボットのアプリがあればそれを開きます（なければ「New Application」で作ります）。
2. 左の「OAuth2」を開きます。**Client ID** をコピーし、**「Reset Secret」で Client Secret** を出してコピーします（ボットのトークンには影響しません）。
3. 「Redirects」→「Add Redirect」に上の戻り先を入れ、「Save Changes」。

**3. Cloudflare に入れる**

Cloudflare のダッシュボード → Workers & Pages → `blockbuster-reels` → 設定 → 「変数とシークレット」に、次の 4 つ（まだなければ 5 つ）を追加して「デプロイ」します。シークレットは「タイプ: シークレット」にします。

| 名前 | 値 | タイプ |
| --- | --- | --- |
| `GOOGLE_CLIENT_ID` | Google のクライアント ID | テキスト |
| `GOOGLE_CLIENT_SECRET` | Google のクライアント シークレット | **シークレット** |
| `DISCORD_CLIENT_ID` | Discord の Client ID | テキスト |
| `DISCORD_CLIENT_SECRET` | Discord の Client Secret | **シークレット** |
| `PUBLIC_URL`（決済でもう入れていれば不要） | `https://blockbuster-reels.sc8z-35a.workers.dev` | テキスト |

入れたら、ゲームを開き直して新規登録の画面に **「Googleで続ける」「Discordで続ける」が出れば設定できています**（片方だけ入れた場合はその片方だけ出ます）。Android アプリは作り直さなくても使えます（アプリの中では、Google・Discord のログインは **スマホのブラウザ**で開き、終わったらアプリに戻ります。Google がアプリの中の画面でのログインを認めないためです）。

仕組みと安全:

- ログインは「認可コード + PKCE + state」（Google はさらに nonce）。ブラウザの住所に残るのは、一度しか使えず 15 分で切れる `state` だけで、ログインの結果を受け取れるのは、**始めたページ（同じ端末）だけ**です（そのページしか持たない秘密の合言葉をサーバーは「ハッシュ」でしか持ちません）。ほかの端末や別のアカウントで続きをしようとしても断られます（テスト `server/test/oauth.test.js`）。
- 受け取るのは Google の `sub`（Discord は ユーザー ID と表示名）だけです。メールアドレスは頼まず、Google・Discord のトークンも使い終わったら捨てます。
- 連携した Google / Discord を外しても、引き継ぎコードで必ず入れるので、ログインできなくなることはありません（プロフィールのマークをもう一度押す）。
- 運営サイト（`/ops/`）・security HOME（`/sec/`）のログインは今までどおり（パスワード・パスキー・追加認証）で、Google / Discord では入れません。
- 端末ごとの上限（`ACCOUNTS_PER_DEVICE`、既定 2）はそのままで、Google / Discord で新しく始めるときも同じ数に数えます。**ちょうど 1 つにしたいときは、`ACCOUNTS_PER_DEVICE` を `1` にしてください。**
