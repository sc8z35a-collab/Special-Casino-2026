# 運営サイトの追加最適化

比較元は `9322c2d`。認証・権限・通信経路・画面の配置・更新頻度を保ち、同じデータで作り直していた表示部品とガラス効果の監視を減らしました。

| 同じデータで20回更新した対象 | 変更前に追加されたHTML/SVG要素 | 変更後 |
|---|---:|---:|
| デスクトップの通報・サーバー小窓 | 260 | 0 |
| サーバー画面のDiscord・LINE・点検・石碑カード | 280 | 0 |

- 小窓の相対時刻だけを更新し、同じ一覧を作り直しません。グラフの目盛り・線・数値欄も再利用します。
- 小窓のリサイズや再配置で、表示中の窓と入力中の下書きを再利用します。ログアウト時は窓・保持データを消去します。
- サーバー画面は、保持済み応答のうち変わらなかった状態カードを再利用します。値の変更、通知設定の変更、開発者権限の違いは再描画します。
- ガラス効果は、Dockなどの無関係なクラス変更では全パネルを再計測しません。モード・スマホ境界の変更には追従します。
- 一度も表示されなかった窓も監視を解除し、外した小窓の監視・フィルターを直ちに解放します。SVGレンズ非対応環境では不要なResizeObserverを開始しません。

実ブラウザで、グラフのSVG座標の一致、数値と経過時刻の更新、下書きの保持、ログアウト時の破棄を検証します。測定値はゲーム全体のCPU削減率を表すものではありません。

画像の削減記録は `docs/icons-compression.json` と `docs/line-gacha-optimization.json`、画面の比較記録は `docs/ops-optimization.json` に保存します。

## タブ・デスクトップ・背景の追加見直し

ここからの比較元は、前回の最適化を含む `9bc269d` です。新しい依存ライブラリを加えず、実行中の部品の作り直し、位置計測、定期確認を減らしました。

| 同じ操作で測った対象 | 変更前 | 変更後 |
|---|---:|---:|
| 3窓を開いて20回切り替えたとき、アプリのタブ欄に追加された要素 | 180個 | 0個 |
| 3ファイルを開いて20回切り替えたとき、保管庫のタブ欄に追加された要素 | 80個 | 0個 |
| 1フレーム内のマウス移動イベント100回でのDockボタン18個の位置計測 | 1,800回 | 18回 |
| 1フレーム内のリサイズイベント20回での窓領域の幅の読み取り（3窓） | 80回 | 4回 |
| 背景の切り替え期限前、約10分間の設定読み取り | 78回 | 0回 |
| 同じ期間の背景用Imageオブジェクト生成 | 39回 | 0回 |
| 非表示の20分間の背景設定読み取り | 160回 | 0回 |

画像用オブジェクトの生成回数は、ネットワーク転送回数ではありません。これらは指定した操作での処理数であり、サイト全体の速度や通信量の削減率を示す値ではありません。

- アプリと保管庫のタブは、追加・削除された分だけ変更し、切り替え時は選択状態を更新します。イベントはタブ欄でまとめて受け取ります。元の表示内容・下書き・パネルID・矢印キー操作・閉じるときの後片付けを保ちます。保管庫の更新時もキーボードフォーカスを維持します。
- Dockは1描画フレームにまとめて位置を読み、その後で拡大率を書き込みます。画面外へマウスが出たら待機中の処理を取り消します。ウインドウのリサイズ処理もフレームごとにまとめます。
- 背景は15秒ごとの確認をやめ、次の10分の切り替え時刻に予約します。非表示中は予約を解除し、戻ったときに期限を確認します。全画像の一巡・周回の境界での重複防止・手動選択を保ちます。別タブで変えた設定にも追従し、古い画像の読み込み完了が最新の選択を上書きする競合を防ぎます。
- セキュア通信の表示確認は、ログアウト時に初回の待機処理も取り消します。ログアウト後のオンライン復帰や画面復帰では通信しません。前のセッションの応答が、新しいセッションの通信や確認済み表示に干渉しないようにします。TLS・サーバーの身元・署名などの検証条件は維持します。
- スマホの「切替」画面が、既存CSSの非表示指定で開いても見えなくなる不具合を修正しました。スマホで実際に開いたときだけ表示します。

全447件のテストに成功しました。既定の並列実行では、既存の150連打テストが時間窓をまたいで1件失敗したため、判定や制限値を変更せず、並列数4で同じ全件を再実行しています。
